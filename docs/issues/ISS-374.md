## Description
Group the smaller diagnostics that prove whether mgstudio composes the
volumetric-fog pass output into the same render target, color space, and
downstream postprocessing order as Bevy for the real
`examples/3d/volumetric_fog` frame.

## Design
Complete the leaf diagnostics in render-graph order:

- ISS-381 aggregates the smaller source-owner maps for Bevy graph anchors,
  Bevy target handoff, mgstudio camera execution, and mgstudio postprocess
  anchors.
- ISS-382 proves target format, sample count, and load/store state.
- ISS-383 proves pass ordering from main pass through fog and postprocess.
- ISS-384 proves exposure, tonemapping, color-space, and final copy behavior.

Do not tune colors or add local postprocess branches. If a wrong target,
ordering, load/store op, format conversion, or exposure/tonemap owner is
proven, assign the exact repair to ISS-375.
