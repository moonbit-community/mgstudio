## Description
`examples/3d/occlusion_culling/reference.png` can now serve as a nontransparent
visual baseline, but the example is not source-level faithful to Bevy. The
current MoonBit source explicitly states that Bevy reads indirect draw
parameters back from the GPU while mgstudio uses a scene-space heuristic to
approximate culled counts.

Bevy's `examples/3d/occlusion_culling.rs` installs render/PBR debug flags,
uses `OcclusionCulling`, `DepthPrepass`, GPU preprocessing support, indirect
parameter buffers, staging buffers, GPU-to-CPU map/copy readback, and render-app
systems to report the number of meshes actually rendered. Mgstudio needs that
render-app source shape or precise blockers for the missing GPU/API pieces.

## Design
Audit and port Bevy `examples/3d/occlusion_culling.rs` as the migration unit:

- preserve `RenderDebugFlags::ALLOW_COPIES_FROM_INDIRECT_PARAMETERS` behavior;
- expose or port the required GPU preprocessing support and indirect parameter
  buffer owners;
- implement the staging-buffer copy/map readback path used by
  `ReadbackIndirectParametersPlugin`;
- display real GPU-derived rendered/culled counts instead of scene-space
  heuristic counts;
- keep the `Space` toggle, depth prepass, occlusion-culling component, and
  rotating cube scene source-shaped.

Do not count the current heuristic counter path as source parity. If wgpu_mbt,
wgpu-native, or mgstudio render-app APIs cannot expose the needed readback
surface yet, record the exact blocker and the deletion condition for the
heuristic path.

## Acceptance Criteria
- [x] Every source-shape anchor in Bevy `examples/3d/occlusion_culling.rs` is
      classified as complete, partial, facade, blocked, or intentionally
      excluded.
- [ ] The example installs Bevy-equivalent render debug flags and render-app
      readback systems.
- [x] Indirect parameter data and count are copied/read back from the GPU, or a
      precise dependency/API blocker records why that cannot be implemented.
- [x] The scene displays real rendered/culled counts rather than heuristic
      scene-space estimates.
- [x] The approximation note in
      `examples/3d/occlusion_culling/main.mbt` is removed or replaced by
      precise blocker references.
- [x] `examples/3d/occlusion_culling/reference.png` remains visually valid
      after the source parity fix.
