## Description
`examples/3d/bloom_3d` renders a plausible bloom scene, but it is not a
symbol-level port of Bevy's `bevy/examples/3d/bloom_3d.rs`.

The main behavior is present: a bloom camera, four materials, a 10x10 bouncing
sphere grid, keyboard-controlled bloom settings, and a reference screenshot.
The strict gaps are source-shape problems: setup does not expose Bevy-shaped
asset system params, the camera is tracked with a local `BloomCamera` marker,
the instruction text is a `Text2dBundle` plus resource instead of UI `Text` and
`Node`, sphere material selection uses a custom arithmetic hash instead of
Bevy's `DefaultHasher`, and `update_bloom_settings` mutates components through
`current_world()` rather than `Commands` plus `Single<&mut Bloom>`.

## Design
Port the Bevy example owner directly. Preserve the existing visual behavior
only when it follows Bevy's symbols. Replace local scaffolding with
source-shaped ECS params and component mutation wherever the mgstudio ECS API
can express it.

## Acceptance Criteria
- [x] `setup_scene` uses Bevy-shaped asset parameters or records a precise ECS
      system-param gap if that cannot be expressed yet.
- [x] The camera spawn tuple matches Bevy's camera, clear color, tonemapping,
      transform, and `Bloom::NATURAL` ownership without local marker
      scaffolding.
- [x] The sphere mesh preserves the `Sphere::new(0.4).mesh().ico(5)` anchor or
      records a precise mesh-builder blocker.
- [x] Material bucket selection matches Bevy's deterministic `DefaultHasher`
      mapping for `(x, z)`.
- [x] Instruction text uses UI `Text` plus absolute `Node`, not a world-space
      `Text2dBundle`.
- [x] `update_bloom_settings` uses Bevy-shaped query/text/commands/input/time
      params and in-place bloom mutation semantics.
- [x] Display text uses the same two-decimal formatting as Bevy.
- [x] Local-only `BloomCamera`, `BloomInstructions`, and helper lookup state
      are removed from the parity path unless a real ECS blocker is recorded.
- [x] The reference screenshot is refreshed after the source-shaped port still
      renders correctly.

## Close Notes
- 2026-06-18: Rebuilt `examples/3d/bloom_3d` around Bevy-shaped system params:
  `setup_scene(Commands, Assets<Mesh>, Assets<StandardMaterial>)`,
  `update_bloom_settings(Single<(Entity, Optional<Bloom>), With<Camera>>,
  Single<Write<Text>>, Commands, ButtonInput<KeyCode>, Time)`, and
  `bounce_spheres(Time, Query<Write<Transform>, With<Bouncing>>)`. Removed the
  local `BloomCamera` and `BloomInstructions` state, switched instructions from
  `Text2dBundle` to UI `Text` plus absolute `Node`, used the icosphere
  primitive path matching `Sphere::new(0.4).mesh().ico(5)`, and replaced the
  local arithmetic bucket hash with the deterministic `DefaultHasher` mapping
  for the Bevy `-5..5` sphere grid. Validation: `moon -C mgstudio-engine check
  --target native`, `moon -C mgstudio-engine fmt`, `moon -C mgstudio-engine
  info`, and refreshed `examples/3d/bloom_3d/reference.png`.
