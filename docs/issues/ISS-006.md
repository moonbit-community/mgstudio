## Description
Skin extraction costs about `5.652 ms/frame` in the main system and
`5.619 ms/frame` in the render queue. It walks many joints and writes staging
data every frame for animated skins.

## Design
Align skin extraction with Bevy's dirty-skin collection and staging-buffer
semantics. The optimized path should have strong invariants for skin metadata,
direct staging indexing for joint matrices, and no hot-loop repair fallback.

## Acceptance Criteria
- [ ] Skin extraction is split into add/delete handling, dirty-skin collection, joint extraction, staging writes, and upload preparation spans.
- [ ] The report records skins, joints, dirty skins, staging rows, and upload bytes.
- [ ] Per-frame metadata repair paths are removed from the hot loop once invariants are established.
- [ ] Joint transform fetch state is shared with or made consistent with skinned-bounds fetch state where source-equivalent.
- [ ] At `1000` foxes, skin extraction is reduced below `2.5 ms/frame` or a follow-up issue documents the remaining blocker.
- [ ] Relevant PBR skinning tests pass with `--release`.
