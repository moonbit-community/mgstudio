## Description
Map the mgstudio fragments that currently execute the camera main pass,
volumetric fog draw, render-pass state transitions, and target/depth resource
selection for the real 3D camera path.

## Design
Use the Bevy anchors from ISS-389 and ISS-390 as the comparison shape. Record
the mgstudio paths and symbols for camera execution, main-pass completion,
volumetric fog pass launch, renderer pass-state ownership, color target
selection, depth texture selection, and volumetric fog bind group inputs. Mark
local missing or partial anchors precisely, but do not repair them here.

- [x] Mgstudio volumetric fog draw/pass-state anchors are listed with paths and
      symbols.
- [x] Mgstudio color/depth resource selection anchors are listed or marked

- [x] No production behavior is changed.

## Notes
- 2026-07-05: Split from ISS-381 so mgstudio's camera/render-pass map can be
  reviewed separately from Bevy source reading.
- 2026-07-05: Camera execution anchor:
  `mgstudio-engine/pbr/render_execute_camera.mbt::render3d_execute_camera`.
  The local camera owner begins the main-pass trace, prepares
  `render3d_prepare_camera_volumetric_fog_state`, calls
  `render3d_execute_camera_main_pass`, then starts the volumetric-fog trace and
  calls `render3d_execute_camera_volumetric_fog_pass`, and only after that calls
  `render3d_execute_camera_postprocess`. This matches the Bevy order from
  ISS-389 at the camera execution boundary, but the source shape is still a
  function-call camera runner rather than Bevy's render-graph/Core3d schedule
  node ownership.
- 2026-07-05: Main-pass anchor:
  `mgstudio-engine/pbr/render_execute_camera_main_pass.mbt::render3d_execute_camera_main_pass`.
  The camera runner passes `scene_target_id`, MSAA sample count, prepass depth,
  normal, motion-vector, deferred, lighting-pass-id texture ids, shadow
  bindings, environment map state, light probe state, fog state, and
  transmission state into this owner. This is the local main-pass completion
  point that volumetric fog currently depends on.
- 2026-07-05: Volumetric fog prepare anchors:
  `mgstudio-engine/pbr/volumetric_fog_execute.mbt::render3d_prepare_camera_volumetric_fog_state`
  builds a Bevy-shaped mesh pipeline view key from MSAA, prepass, atmosphere,
  tonemap-in-shader, environment map, irradiance volume, and SSR flags, then
  prepares both textureless and textured volumetric fog pipelines for
  `scene_target_id`. `render3d_prepare_camera_volumetric_fog` writes
  `ViewVolumetricFog` and the uniform buffer for the current render view.
- 2026-07-05: Volumetric fog draw/pass anchors:
  `mgstudio-engine/pbr/volumetric_fog_execute.mbt::render3d_draw_volumetric_fog`
  reads `ViewVolumetricFog` and `ViewVolumetricFogPipelines`, converts fog
  volumes to `HostMesh3dVolumetricFogVolume`, and calls
  `@render.host_gpu_draw_mesh3d_volumetric_fog`. The outer
  `render3d_execute_camera_volumetric_fog_pass` calls
  `@render.host_gpu_end_pass` after the draw, which clears the renderer's saved
  pass state via the normal renderer end-pass path.
- 2026-07-05: Renderer pass-state anchors:
  `mgstudio-engine/render/renderer/pass_types.mbt::GpuPassState` is the local
  state carrier for `target_id`, `target_layer`, prepass texture ids,
  `view_depth_texture_id`, `view_depth_view`, MSAA sample count, viewport, light
  inputs, tonemapping inputs, and PBR LUT ids. It is written by
  `mgstudio-engine/render/renderer/pass_begin.mbt::GpuBackend::begin_pass_3d`
  after selecting the pass color/depth attachments and before draw calls.
- 2026-07-05: Renderer color/depth selection anchors:
  `mgstudio-engine/render/renderer/texture.mbt::target_color_attachment`
  chooses the active render attachment and optional MSAA resolve target for the
  main pass, while `target_view` returns the non-MSAA surface or texture view
  for later color-load passes. `ensure_depth_view_for_target` creates the local
  sampled render depth view with render-attachment, texture-binding, and copy-src
  usages. `GpuBackend::begin_pass_3d` stores that depth view in
  `GpuPassState.view_depth_view`.
- 2026-07-05: Renderer volumetric-fog draw anchors:
  `mgstudio-engine/render/renderer/mesh3d_volumetric_fog_pass.mbt::GpuBackend::draw_mesh3d_volumetric_fog`
  requires the saved `GpuPassState`, gets the color view through
  `target_view(self, pass_state.target_id, pass_state.target_layer)`, gets the
  sampled depth view through `pass_state.view_depth_view`, ends the active main
  pass while preserving `GpuPassState`, then opens one color-load render pass per
  fog volume with no depth attachment and binds the Bevy-shaped view and
  volumetric fog bind groups.
- 2026-07-05: Local partial, not external blocker: mgstudio does not currently
  have a Bevy-style `ViewTarget` owner with explicit `main_texture_view`,
  `post_process_write`, and ping-pong state at this boundary. The fog color
  target is selected indirectly through `GpuPassState.target_id` and
  `target_view`, and postprocess handoff must be audited separately in ISS-392.
  This is a local source-shape gap/facade, not an upstream dependency blocker.
