# ISS-089: Port pcss widget controls and shadow source parity

- Type: bug

- Assignee: unassigned

## Description
`examples/3d/pcss/reference.png` can now serve as a nontransparent visual
baseline, but the example is not source-level faithful to Bevy. The current
MoonBit source explicitly notes that Bevy widget radio buttons are mapped to
keyboard controls, and the setup path contains repeated camera component
insertions that do not mirror Bevy's source shape.

Bevy's `examples/3d/pcss.rs` uses shared widgets/radio buttons for light type,
shadow filter, and PCSS enablement; installs camera-side `ShadowFilteringMethod`,
`TemporalJitter`, `Msaa::Off`, `DepthPrepass`, `MotionVectorPrepass`, and
`Skybox`; switches directional/point/spot light component sets; and updates TAA
state when the temporal filter is selected. Mgstudio needs the same source
shape or precise blockers for missing widget/UI or render feature support.

## Design
Audit and port Bevy `examples/3d/pcss.rs` as the source owner:

- preserve the Bevy widget/radio-button UI message flow instead of keyboard
  substitutions;
- remove repeated local component insertion paths and align camera setup with
  Bevy's single component tuple/insert chain;
- preserve light-type switching, shadow filter switching, temporal jitter/TAA,
  depth and motion-vector prepass, skybox, and soft-shadow toggling;
- verify the visual reference still shows the palm scene and soft-shadow signal.

Do not count keyboard-only controls or duplicate setup code as source parity. If
the widget path or a render feature is blocked by a real engine/API gap, link
that precise blocker.

## Acceptance Criteria
- [x] Every source-shape anchor in Bevy `examples/3d/pcss.rs` is classified as
      complete, partial, facade, blocked, or intentionally excluded.
- [x] PCSS controls use Bevy-shaped widget/radio-button message flow or link a
      precise UI blocker.
- [x] Camera setup is source-shaped and has no repeated local component
      insertion approximations.
- [x] Directional, point, and spot light switching preserves Bevy's component
      set and shadow parameter behavior.
- [ ] `examples/3d/pcss/reference.png` remains visually valid after the source
      parity fix.
