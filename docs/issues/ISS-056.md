## Description
`examples/2d/wireframe_2d` is a visual example and should be a useful reference
for `Wireframe2dPlugin`, global wireframe configuration, per-entity wireframe
color, and UI text updates. The example passes `moon check`, but native capture
exits without producing a blob.

Latest run log:

```text
Error: Command exited without a return code
```

## Design
Diagnose the real early-exit boundary before editing rendering behavior:
system-param validation, `Wireframe2dPlugin` setup, required GPU features,
mesh2d wireframe pipeline creation, and screenshot-capture exit handling. Do
not replace the example with a non-wireframe scene or add a screenshot-specific
fallback.
