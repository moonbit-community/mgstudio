## Description
`scrolling_fog` needs a narrow runtime gate proving that the volumetric fog pass
uses the Bevy-shaped shader variant validated by ISS-254 through ISS-256.

## Design
Read Bevy's volumetric fog pipeline and shader-definition source first, then
verify the mgstudio runtime path without adding fallback behavior. The evidence
should identify the active volumetric fog pipeline variant used by
`examples/3d/scrolling_fog` and tie it to the composed WGSL import closure and
shader definitions already validated by the earlier issues.

## Acceptance Criteria
- [ ] A focused white-box test or equivalent runtime artifact identifies the
      active `scrolling_fog` volumetric fog pipeline variant.
- [ ] The evidence proves the active variant uses the validated composed WGSL
      path and shadow-related shader definitions.
- [ ] The validation runs with
      `moon -C mgstudio-engine test examples/3d/scrolling_fog --target native --release`
      or a narrower `--filter` command.
- [ ] No renderer-local workaround, fallback, or non-Bevy shader variant is
      introduced to make the evidence pass.
