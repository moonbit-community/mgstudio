## Description
Classify whether mgstudio's volumetric-fog pipeline and pass descriptor use the
same target format, blend state, color attachment, resolve behavior, and
depth/no-depth semantics as Bevy.

## Design
Compare Bevy's volumetric-fog specialized pipeline descriptor and render-pass
setup against mgstudio's renderer pipeline build and pass-begin fragments.
Cover additive alpha blending, color write mask, cull mode if it is part of the
same descriptor evidence, color target format, MSAA resolve handling, and the
absence or presence of depth attachments for the fog pass.

## Acceptance Criteria
- [x] Bevy blend state and color target format are mapped to mgstudio symbols.
- [x] Color attachment and MSAA resolve semantics are classified.
- [x] Depth/no-depth attachment semantics are classified.
- [x] Any render-pass descriptor divergence is linked to ISS-370 for final
      assignment.

## Close Notes
Closed on 2026-07-05 after auditing the volumetric-fog pipeline descriptor and
draw-pass attachment semantics against Bevy.

Bevy owner anchors:

- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs:523` uses
  `ColorTargetState { format: key.target_format, ... }`.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs:528-539` uses additive
  alpha blending: color `(One, OneMinusSrcAlpha, Add)` and alpha
  `(Zero, One, Add)`.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs:516-518` sets
  back-face culling on the volumetric-fog hull pipeline.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs:391-402` begins the pass
  with one color attachment, `view_target.main_texture_view()`,
  `resolve_target: None`, load/store ops, and `depth_stencil_attachment: None`.

Mgstudio implementation fragments:

- `mgstudio-engine/render/renderer/mesh3d_pipeline_build.mbt:1582` sets the
  color target format from the forwarded `color_format`, matching Bevy's
  `key.target_format`.
- `mgstudio-engine/render/renderer/mesh3d_pipeline_build.mbt:1481-1490` stores
  the Bevy blend tuple, and `:1591-1598` applies it to the pipeline builder.
- `mgstudio-engine/render/renderer/mesh3d_pipeline_build.mbt:1610-1614` uses
  triangle-list topology, back-face culling, and a single-sample volumetric
  color pipeline. MSAA still selects shader and bind-group variants, but not
  the color attachment sample count, because the Bevy pass writes to
  `ViewTarget::main_texture_view()`.
- `mgstudio-engine/render/renderer/mesh3d_volumetric_fog_pass.mbt:367` begins
  each volumetric-fog draw with `begin_render_pass_color_load(color_view)`.
  This path does not call the resolve wrapper or attach a depth-stencil target.
- The resolve-capable wrapper is separate:
  `mgstudio-engine/render/renderer/wgpu_wrapper.mbt:85-120` explicitly requires
  both a resolve view and depth view; volumetric fog does not use that path.

Classification:

- Complete: color target format forwarding, Bevy additive blend factors,
  back-face culling, single-color load/store pass, no resolve target, and no
  depth-stencil attachment for the volumetric-fog draw pass.
- Facade: none for this issue.
- Partial: none proven in this issue.
- Blocked: none.
- Local divergence: none to assign to ISS-370.
