# ISS-065: Port Bevy AtmospherePlugin render resource owner

## Metadata
- Type: task
- Status: blocked
- Priority: 0
- Labels: parity, pbr, atmosphere, render-app, bind-groups, luts
- Assignee: unassigned
- Created: 2026-06-10
- Updated: 2026-06-11
- External ref: none

## Description
`examples/3d/atmosphere` enables the PBR `ATMOSPHERE` mesh pipeline key, so the
mesh view layout includes bindings 31, 32, and 33. The renderer cannot bind
those entries because mgstudio has not ported Bevy's atmosphere render resource
owner. The local `pbr/atmosphere` package currently contains embedded WGSL,
component facades, and small state structs, but not the render-side systems that
create atmosphere LUT textures, prepare uniforms, build bind groups, write the
`AtmosphereBuffer`, run LUT compute passes, or render the sky pass.

## Design
Use Bevy source owners as the migration unit, not the current mgstudio file
shape. The primary owner is `bevy/crates/bevy_pbr/src/atmosphere/mod.rs`, with
required implementation fragments in `resources.rs`, `node.rs`,
`environment.rs`, and the WGSL files under `bevy_pbr/src/atmosphere`. Port the
logic directly into Bevy-shaped mgstudio owners. Do not use placeholder
textures, identity atmosphere buffers, fake LUTs, constant white transmittance,
or logic that silently drops the `ATMOSPHERE` layout bit while claiming
atmosphere support.

## Acceptance Criteria
- [ ] `AtmospherePlugin` installs the same render-side resource lifecycle as
      Bevy: shader registration, capability checks, render resources,
      extraction, prepare systems, bind group preparation, LUT passes, and
      Core3d sky pass ordering.
- [ ] `ExtractedAtmosphere`, `GpuAtmosphere`, `GpuAtmosphereSettings`,
      `AtmosphereTextures`, `AtmosphereSampler`, `AtmosphereBindGroupLayouts`,
      `RenderSkyBindGroupLayouts`, `AtmosphereLutPipelines`,
      `AtmosphereTransforms`, `AtmosphereBindGroups`, and `AtmosphereBuffer`
      have explicit mgstudio mappings or documented language/dependency
      blockers.
- [ ] The mesh view bind group receives real Bevy-equivalent atmosphere
      bindings: transmittance LUT texture at 31, filtering sampler at 32, and
      read-only `GpuAtmosphere` storage buffer at 33.
- [ ] `examples/3d/atmosphere` no longer logs `unsupported binding 31`, renders
      a non-black capture, and saves `examples/3d/atmosphere/reference.png`.
- [ ] `moon -C mgstudio-engine check --target native`, `moon -C
      mgstudio-engine fmt`, `moon -C mgstudio-engine info`, and focused
      atmosphere/PBR tests or visual gates pass.
