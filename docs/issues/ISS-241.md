## Description
Bevy executes the volumetric fog pass after the main 3D pass and before early
postprocess, binding the mesh view group, volumetric fog group, depth texture,
optional density texture, and fog hull mesh draw data. Mgstudio must audit the
final pass and draw execution owner after prepared data is classified.

## Design
Use this issue as the parent for pass/draw audits:

- ISS-283 audits Bevy `volumetric_fog` query/resource gates and pass ordering.
- ISS-284 audits bind groups, dynamic offsets, fog hull draw, color-load pass,
  and additive blend behavior.
