## Description
`examples/animation/morph_targets` still has a transparent checked-in
`reference.png`. Retrying the standard native capture failed to produce an
engine-native RGBA8 blob: the 90-frame run aborted with `Abort trap: 6`, and
the script's 1-frame retry also exited without a blob.

The local example is also no longer source-shaped against current Bevy. Bevy's
example uses `models/animated/MorphStressTest.gltf`, plays
`GltfAssetLabel::Animation(2)`, observes `WorldInstanceReady`, walks
descendant children to find `AnimationPlayer`, and logs morph target names
for every mesh asset that reports names. Mgstudio still uses
`models/morph_targets/morph_targets.gltf`, plays animation `0`, and only tries
to find an animation player directly on the scene entity.

## Design
Fix the source drift before accepting any refreshed reference. Port the current
Bevy example shape directly, then debug the morph target render/capture path
with the standard native capture command. Do not keep the old asset path or
single-entity animation-player lookup as a local approximation.

## Acceptance Criteria
- [x] `mgstudio-engine/examples/animation/morph_targets/main.mbt` uses the
      current Bevy asset path and animation index.
- [x] Scene-ready handling follows Bevy's descendant traversal so the
      `AnimationPlayer` child receives the animation graph handle and starts
      playing.
- [x] Morph target name logging follows the current Bevy event shape as closely
      as mgstudio's asset events allow.
- [x] The standard native capture completes without `Abort trap`, timeout,
      missing blob, validation, fatal, missing-resource, unsupported, or error
      output.
- [x] The refreshed `reference.png` is accepted only after manual review
      confirms visible morph-target scene content.

## Close Notes
- Closed on 2026-06-13 after restoring the example's current Bevy source shape
  and fixing the morph render storage path.

  Changes:
  - `examples/animation/morph_targets` now loads
    `models/animated/MorphStressTest.gltf`, plays animation `2`, traverses scene
    descendants to find the `AnimationPlayer`, and logs morph target names from
    loaded mesh assets.
  - The morph target GPU path now uses storage-buffer resources instead of the
    stale texture-shaped binding model. Current and previous morph weights bind
    as storage buffers, morph target deltas bind through a per-mesh storage
    buffer, and the mesh draw bind group includes the descriptor buffer binding
    required by the Bevy-shaped shader layout.
  - The native validation failure was caused by morph descriptor buffer capacity
    growth producing a 45-byte storage binding size. Storage buffer bindings
    must be 4-byte aligned; descriptor capacity now grows in whole descriptor
    strides and draw bind group cache revisions track descriptor buffer
    replacement.
  - `examples/animation/morph_targets/reference.png` was refreshed with the
    standard 90-frame native capture command and manually reviewed as visible
    morph-target scene content.
