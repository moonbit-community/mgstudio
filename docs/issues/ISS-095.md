## Description
`examples/animation/morph_targets` still has a transparent checked-in
`reference.png`. Retrying the standard native capture failed to produce an
engine-native RGBA8 blob: the 90-frame run aborted with `Abort trap: 6`, and
the script's 1-frame retry also exited without a blob.

The local example is also no longer source-shaped against current Bevy. Bevy's
example uses `models/animated/MorphStressTest.gltf`, plays
`GltfAssetLabel::Animation(2)`, observes `WorldInstanceReady`, walks
descendant children to find `AnimationPlayer`, and logs morph target names
for every mesh asset that reports names. Mgstudio still uses
`models/morph_targets/morph_targets.gltf`, plays animation `0`, and only tries
to find an animation player directly on the scene entity.

## Design
Fix the source drift before accepting any refreshed reference. Port the current
Bevy example shape directly, then debug the morph target render/capture path
with the standard native capture command. Do not keep the old asset path or
single-entity animation-player lookup as a local approximation.

## Acceptance Criteria
- [ ] `mgstudio-engine/examples/animation/morph_targets/main.mbt` uses the
      current Bevy asset path and animation index.
- [ ] Scene-ready handling follows Bevy's descendant traversal so the
      `AnimationPlayer` child receives the animation graph handle and starts
      playing.
- [ ] Morph target name logging follows the current Bevy event shape as closely
      as mgstudio's asset events allow.
- [ ] The standard native capture completes without `Abort trap`, timeout,
      missing blob, validation, fatal, missing-resource, unsupported, or error
      output.
- [ ] The refreshed `reference.png` is accepted only after manual review
      confirms visible morph-target scene content.
