## Description
Bevy installs `volumetric_fog` in the `Core3d` schedule after
`Core3dSystems::MainPass` and before `Core3dSystems::EarlyPostProcess`.
Mgstudio needs an explicit local representation of this boundary before moving
or validating the draw path.

## Design
Audit Bevy `bevy_pbr/src/volumetric_fog/mod.rs` and the current mgstudio
3D render execution flow. Add or update the smallest internal test/inventory
that proves mgstudio has a named boundary equivalent to
`volumetric_fog.after(MainPass).before(EarlyPostProcess)`.

## Acceptance Criteria
- [x] The Bevy source owner and exact schedule relation are documented in the local issue close notes or test name.
- [x] Mgstudio has a named pass-order boundary that distinguishes main pass,
      volumetric fog, and early postprocess.
- [x] A focused test or static white-box assertion catches accidental reordering
      of the volumetric fog boundary.
