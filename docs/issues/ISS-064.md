# ISS-064: Port Bevy Wireframe3d phase and pipeline source owners

## Metadata
- Type: task
- Status: in_progress
- Priority: 1
- Labels: parity, pbr, wireframe, render-phase, pipeline
- Assignee: unassigned
- Created: 2026-06-10
- Updated: 2026-06-11
- External ref: none

## Description
`examples/3d/wireframe` now captures a usable reference, but mgstudio's 3D
wireframe implementation is still not source-level equivalent to Bevy's
`bevy/crates/bevy_pbr/src/wireframe.rs`. The current mgstudio path converts
triangle meshes into generated line-list meshes and draws them through the
regular PBR main pass. Bevy owns a dedicated `WireframePlugin`,
`Wireframe3d` binned phase, thin and wide wireframe draw commands, specialized
wireframe pipelines, extracted render resources, and a `wireframe_3d` Core3d
node that runs after the main pass and before early postprocess.

## Design
Audit the Bevy source owner symbol by symbol before editing mgstudio. Replace
the local generated-line-list approximation with Bevy-shaped ownership where
the current MoonBit renderer can express it. If an exact symbol requires a real
backend or language capability that does not exist, record that blocker
explicitly; do not classify local approximations as blockers.

## Acceptance Criteria
- [ ] Every in-scope struct, resource, component, system, render command,
      pipeline key, and plugin hook in `bevy_pbr/src/wireframe.rs` is classified
      as complete, partial, blocked, facade, or intentionally excluded.
- [ ] `WireframePlugin` installs Bevy-equivalent main-world and render-world
      resources and systems instead of only initializing `WireframeConfig`.
- [ ] `Wireframe3d` is represented as its own render phase or an explicitly
      documented equivalent phase boundary, not as extra regular main-pass
      mesh draws.
- [ ] Thin and wide wireframe pipeline specialization are ported or blocked
      with exact missing backend capability notes.
- [ ] `examples/3d/wireframe` still captures a nonblank checked-in
      `reference.png` after the source-owner migration.
