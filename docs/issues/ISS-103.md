## Description
`ISS-101` wired the renderer binding-array group so reflection probes and
irradiance volumes receive the correct texture arrays and samplers. The
remaining Bevy source-owner mismatch is that reusable helper ownership from
`bevy_pbr/src/light_probe/environment_map.rs`,
`bevy_pbr/src/light_probe/irradiance_volume.rs`, and
`bevy_pbr/src/render/mesh_view_bindings.rs` is still split across mgstudio's
`pbr/light_probe` facade helpers and `render/renderer/mesh3d_bind_groups.mbt`.

This is not a rendering workaround, but it makes source parity audits hard:
`add_cubemap_texture_view`, environment-map bind-group entry selection,
irradiance-volume bind-group entry selection, and binding-array usability are
not yet owned by source-shaped modules.

## Design
Rehome helper ownership without changing shader assets or runtime behavior:

- make environment-map and irradiance-volume bind-group entry selection
  source-shaped in the `pbr/light_probe` owner;
- keep renderer code responsible for raw `wgpu` object construction, but stop
  embedding Bevy PBR light-probe policy directly in renderer-local branches;
- map `add_cubemap_texture_view` and the corresponding irradiance-volume 3D
  texture helper to reusable MoonBit functions with Bevy-equivalent single and
  binding-array behavior;
- align `binding_arrays_are_usable` ownership with Bevy's feature/limit checks,
  recording a blocker only for dependency capabilities that cannot be expressed
  through current `wgpu_mbt`.

## Acceptance Criteria
- [x] `RenderViewEnvironmentMapBindGroupEntries` and
      `RenderViewIrradianceVolumeBindGroupEntries` are concrete source-shaped
      helpers rather than facade-only structs.
- [x] Renderer bind-group construction consumes policy decisions from the PBR
      light-probe owner and only performs raw backend object binding.
- [x] Binding-array usability behavior is classified as complete or blocked
      with a concrete dependency limitation.
- [x] Existing PCCM and light-probe tests remain unchanged in output.
- [x] `moon check --release`, targeted tests, `moon fmt`, and `moon info` pass
      for the touched packages.
