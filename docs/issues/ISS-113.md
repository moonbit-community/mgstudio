## Description
`examples/3d/depth_of_field` is not a source-shaped port of Bevy's
`bevy/examples/3d/depth_of_field.rs`.

The current mgstudio example implements a depth-of-field control demo, but it
does so with a local procedural scene, a global `DofState`, one tracked camera,
and a `Text2dBundle` help overlay. Bevy's owner uses an `AppSettings` resource,
the `DepthOfFieldExample.glb` scene plus `tweak_scene` lightmap/material edits,
UI `Text` and `Node`, separate/chained update systems, `From<AppSettings> for
Option<DepthOfField>`, and all-camera DOF insertion/removal through `Commands`.

## Design
Replace the local procedural approximation with a direct port of the Bevy
example owner. Any ECS limitation that prevents the exact resource/query/system
shape must be recorded as a precise blocker; local global state and procedural
scene substitutions are not blockers.

## Acceptance Criteria
- [x] `AppSettings` is represented as a resource with Bevy's fields and default
      values.
- [x] `main` preserves the window title, startup system, `tweak_scene`, and the
      chained update systems.
- [x] `setup` loads `models/DepthOfFieldExample/DepthOfFieldExample.glb` through
      the Bevy-shaped scene root owner and does not add local procedural floor,
      cube, directional-light, or point-light substitutes.
- [x] Help text uses UI `Text` plus absolute `Node`, not a world-space
      `Text2dBundle`.
- [x] `adjust_focus`, `change_mode`, `update_dof_settings`, `tweak_scene`, and
      `update_text` preserve Bevy's system parameter and mutation shape where
      expressible.
- [x] `tweak_scene` enables changed directional-light shadows, detects
      `GltfMeshName == "CircuitBoard"`, updates material lightmap exposure, and
      inserts the HDR `Lightmap`.
- [x] `From<AppSettings> for Option<DepthOfField>` semantics are represented
      directly, including max depth and default field preservation.
- [x] Help text formatting and focal-length calculation match Bevy's
      `PhysicalCameraParameters`, `PerspectiveProjection`, and `dof` helper
      anchors.
- [x] Local global `DofState`, tracked text/camera handles, extra clamps, and
      local procedural scene code are removed from the parity path.
- [x] The reference screenshot is refreshed after the source-shaped port still
      renders correctly.
