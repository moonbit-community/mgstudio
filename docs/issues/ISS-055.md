# ISS-055: Fix fog example capture blob production

## Metadata
- Type: bug
- Status: closed
- Priority: 2
- Labels: examples, screenshots, capture, pbr, fog, source-parity
- Assignee: unassigned
- Created: 2026-06-07
- Updated: 2026-06-19
- External ref: none

## Description
The curated fog examples build and launch under the native screenshot harness,
but they do not produce `MGSTUDIO_PARITY_CAPTURE_RGBA8_BLOB` before the capture
timeout. The latest logs are empty, so this is not currently explained by an
example-level abort.

Affected packages:

- `examples/3d/fog`
- `examples/3d/fog_volumes`
- `examples/3d/volumetric_fog`

## Design
Debug the render/capture path for these examples from the engine boundary:
window creation, camera extraction, render graph execution, surface readback,
and app exit. Do not add fake screenshots, alternate render paths, or local
example fallbacks. If the issue is the screenshot runtime rather than fog/PBR,
attach this issue to the screenshot-capture ownership work.

## Acceptance Criteria
- [x] Each affected fog package either produces `reference.png` through the standard native capture script or has a precise engine-level blocker recorded.
- [x] Empty run logs are replaced by actionable diagnostics at the failing capture boundary.
- [x] The fix does not add example-local screenshot workarounds.
- [x] Relevant checks and targeted runs pass with `--release`.
