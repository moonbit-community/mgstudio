## Description
Bevy `SpecializedRenderPipeline for VolumetricFogPipeline` constructs the
render pipeline descriptor from `VolumetricFogPipelineKey`, including shader
defs, view layout key, vertex position layout, target format, culling,
multisampling, and additive alpha blend.

## Design
Audit the specialization descriptor branch-by-branch against Bevy. Backend
pipeline creation can remain renderer-owned, but the descriptor semantics must
come from the Bevy-shaped key.

## Acceptance Criteria
- [x] Pipeline key fields and construction are classified.
- [x] Shader defs for shadows, MSAA, atmosphere, and density texture are
      classified.
- [x] Vertex layout, primitive state, multisample state, color target, and
      blend state are classified.
- [x] Fallback descriptors or inferred layout state are removed or filed as
      follow-up ISS.

## Close Notes
Closed 2026-07-09. `VolumetricFogPipeline::specialize` now owns the
Bevy-shaped render pipeline descriptor: shader path, shader defs, mesh view
layout, volumetric bind-group layout variant, vertex buffer layout, back-face
culling, fragment target, single-sample multisample state, and additive alpha
blend. Renderer backend now consumes the descriptor and materializes the
selected bind-group layout slot instead of deriving shader defs, blend state,
shader path, or cull mode locally.
