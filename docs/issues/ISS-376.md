## Description
Map the exact Bevy source owners and mgstudio fragments that prepare the
light and shadow data consumed by `volumetric_fog.wgsl` for the real
`examples/3d/volumetric_fog` frame.

## Design
Read the Bevy owners before judging mgstudio:

- `bevy/crates/bevy_pbr/src/render/light.rs`.
- `bevy/crates/bevy_pbr/src/render/mesh_view_types.wgsl`.
- `bevy/crates/bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl`.
- any directly referenced shadow sampling owner needed by those files.

Then map each source anchor to the corresponding mgstudio file and symbol.
This issue records ownership only; numeric proof belongs to ISS-377 through
ISS-379.

## Acceptance Criteria
- [x] Directional, ambient, point, spot, cascade, and shadow-map source anchors
      are listed with their Bevy paths and symbols.
- [x] Each anchor is mapped to an mgstudio path and symbol or explicitly marked
      missing.
- [x] Missing anchors are not called blockers unless they are caused by a real
      dependency or language limitation.
- [x] No production behavior is changed.

Bevy source anchors and mgstudio fragments:

- Directional light host layout:
  Bevy `bevy/crates/bevy_pbr/src/render/light.rs::{GpuDirectionalCascade,
  GpuDirectionalLight,GpuLights}` maps to
  `mgstudio-engine/pbr/render/light.mbt::{GpuDirectionalCascade3d,
  GpuDirectionalLight3d,GpuLights3d}` and
  `render3d_gpu_lights_uniform_bytes`.
- Directional light preparation:
  Bevy `light.rs::prepare_lights` directional-light loop maps to
  `mgstudio-engine/pbr/render/light.mbt::render3d_collect_gpu_lights`,
  `render3d_directional_light_flags_for_gpu`, and
  `render3d_directional_light_shadow_state`.
- Ambient light preparation:
  Bevy `light.rs::prepare_lights` `GpuLights.ambient_color` and
  `ambient_light_affects_lightmapped_meshes` fields map to
  `render3d_collect_gpu_lights` using
  `@light.ecs_key_global_ambient_light` and `render3d_scale_color`.
- Clustered point and spot light host layout:
  Bevy `bevy/crates/bevy_pbr/src/render/mesh_view_types.wgsl::ClusteredLight`
  maps to `mgstudio-engine/pbr/render/light.mbt::render3d_lights_push_clustered_light`
  and `render3d_gpu_cluster_buffers`.
- Clustered point and spot light preparation:
  Bevy `light.rs::prepare_lights` clustered-light loop and
  `PointLightFlags` map to
  `render3d_clustered_light_flag_limits`,
  `render3d_clustered_point_light_flags`, and
  `render3d_lights_push_clustered_light`.
- Cluster index lists and offsets:
  Bevy `mesh_view_types.wgsl::{ClusteredLights,
  ClusterableObjectIndexLists,ClusterOffsetsAndCounts}` maps to
  `render3d_gpu_cluster_buffers` and renderer upload through
  `mgstudio-engine/render/lib.mbt::host_gpu_prepare_mesh3d_cluster_buffers`.
- Directional cascade host values:
  Bevy `light.rs::prepare_lights` cascade fill of
  `GpuDirectionalCascade { clip_from_world, texel_size, far_bound }` maps to
  `mgstudio-engine/pbr/render_execute_camera_directional_shadow.mbt::render3d_directional_shadow_cascades`,
  `render3d_directional_shadow_cascade_data`, and
  `mgstudio-engine/pbr/render/light.mbt::render3d_gpu_lights_with_directional_shadow_cascades`.
- Directional and spot shadow target binding:
  Bevy directional/spot shadow depth-texture preparation inside
  `light.rs::prepare_lights` maps to
  `render_execute_camera_directional_shadow.mbt::render3d_prepare_camera_directional_shadow_pass`
  and the `Render3dDirectionalShadowBinding` carried through
  `mgstudio-engine/pbr/render_shadow_view.mbt`.
- Main-pass light uniform handoff:
  Bevy `GpuLights` is bound through mesh-view bind group data; mgstudio maps
  this to `mgstudio-engine/pbr/render/view.mbt::render3d_mesh3d_lights_uniform_bytes_for_pass`
  and `render3d_begin_pass_3d`, with bytes reaching
  `mgstudio-engine/render/renderer/mesh3d_draw_pass_data.mbt::mesh3d_lights_uniform_bytes`.
- Fog shader light reads:
  Bevy `bevy/crates/bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl`
  reads `lights.directional_lights`, `lights.n_directional_lights`,
  `clustered_lights`, point/spot flags, and
  `lights.spot_light_shadowmap_offset`. The mgstudio shader asset at
  `mgstudio-engine/pbr/volumetric_fog/volumetric_fog.wgsl` has the same read
  anchors.
- Directional shadow helper reads:
  Bevy `bevy/crates/bevy_pbr/src/render/shadows.wgsl::{get_cascade_index,
  world_to_directional_light_local}` and
  `bevy/crates/bevy_pbr/src/render/shadow_sampling.wgsl::{sample_shadow_map_hardware,
  sample_shadow_map,sample_shadow_cubemap,SPOT_SHADOW_TEXEL_SIZE}` map to
  `mgstudio-engine/pbr/render/shadows.wgsl`,
  `mgstudio-engine/pbr/render/shadow_sampling.wgsl`, and the generated
  embedded sources `shadows_wgsl.mbt` and `shadow_sampling_wgsl.mbt`.

No missing source anchor was found in this inventory. This issue does not claim
numeric parity: ISS-377 owns directional and ambient GPU values, ISS-378 owns
directional cascade and depth-texture values, and ISS-379 owns clustered point
and spot light values.
