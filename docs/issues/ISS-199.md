## Description
After light flags and shadow bindings are proven, `scrolling_fog` still needs
shader-input parity. This group tracks the remaining Bevy-owned inputs to
`volumetric_fog.wgsl`: shader source and specialization definitions, dynamic
uniform layout and offsets, 3D density texture binding and animation, view-depth
texture binding and reconstruction, and a final capture proving those inputs
produce the expected visual signal.

## Design
Keep each input family independently auditable. Child issues must compare
mgstudio against Bevy `bevy_pbr/src/volumetric_fog/render.rs` and
`volumetric_fog.wgsl`, fix local divergence source-faithfully, or record a
precise external blocker when parity is not expressible with current
dependencies. Preserve Bevy shader text unless a real upstream parser blocker is
recorded.

## Acceptance Criteria
- [x] ISS-201 verifies WGSL source identity and pipeline specialization inputs.
- [x] ISS-202 verifies uniform host layout and dynamic offsets.
- [x] ISS-203 verifies 3D density texture binding and animated offsets.
- [x] ISS-204 verifies view-depth texture binding and depth reconstruction.
