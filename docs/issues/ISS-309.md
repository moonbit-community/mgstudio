## Description
Bevy's glTF node loader applies mesh conversion transforms and inserts
primitive bounds used by visibility and render extraction. Mgstudio must prove
that the `VolumetricFogExample.glb` Cube primitive receives equivalent
conversion and bounds data, or fix the local divergence. This issue is only a
grouping issue; the executable work is split into source-owner, local-fragment,
component-write, and runtime-proof issues.

## Design
Use these child issues as the working sequence:

- ISS-311 maps the Bevy glTF primitive bounds and mesh conversion source
  anchors.
- ISS-312 maps and verifies mgstudio's glTF mesh conversion transform path.
- ISS-313 audits and ports the glTF primitive bounding-box payload path.
- ISS-314 audits and ports scene-spawn AABB component insertion.
- ISS-315 proves the `VolumetricFogExample.glb` Cube primitive transform and
  bounds at runtime.

Close this issue only after the child issues either prove source alignment or
assign a concrete local divergence to ISS-305.
