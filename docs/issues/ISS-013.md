## Description
Bevy's `RenderGraph` is a dedicated root render graph schedule with
`Begin -> Render -> Submit -> Finish` systems, driven once per frame by
`render_system`. Mgstudio currently exposes a `RenderGraph` shell in
`mgstudio-engine/render/schedule.mbt`, but it is effectively an alias over the
canonical render schedule rather than a real render graph owner.

## Design
Port the ownership shape from `bevy/crates/bevy_render/src/renderer/mod.rs`:
`RenderGraph`, `RenderGraphSystems`, and the schedule that is run from the
render system. Keep MoonBit package boundaries as needed, but the runtime owner
semantics should match Bevy instead of remaining renderer-local.

## Acceptance Criteria
- [ ] `RenderGraph` has explicit `Begin`, `Render`, `Submit`, and `Finish` system sets.
- [ ] The render backend drives the `RenderGraph` schedule once per frame instead of treating it as a passive alias.
- [ ] Existing render systems are moved or bridged to the correct Bevy-shaped graph phase with no compatibility fallback path.
- [ ] Screenshot, readback, command-buffer submission, and present ownership are no longer hidden inside broad renderer-local execution.
- [ ] Render schedule tests prove the ordering matches Bevy's `RenderGraph::base_schedule`.
