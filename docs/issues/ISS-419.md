## Description
Texture, sampler, mesh, and mesh-allocation registries are the final backend-owned resource roots. Surface ownership is closed with the frame/surface owner area in ISS-415. Complete teardown also needs an end-to-end resource-count oracle rather than only area-level tests.

## Design
Release every remaining registry entry according to its explicit ownership contract, release queue/device/adapter/instance last, and add a full create/use/shutdown GlobalReport regression that audits every WGPU resource category exposed by the report.

## Acceptance Criteria
- [ ] Texture, sampler, mesh, and mesh-allocation registries release every owned reference.
- [ ] Queue, device, adapter, and instance are released last in dependency order.
- [ ] A full create/use/shutdown test returns all observable WGPU live-handle categories to baseline.
- [ ] Repository-native checks and the complete renderer test suite pass.
