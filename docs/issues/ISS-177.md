# ISS-177: Remove source-world discovery from volumetric fog prepare

## Metadata
- Type: task
- Status: closed

- Assignee: unassigned

## Description
The current camera render path still discovers volumetric lights and fog
volumes from the source world while preparing camera volumetric fog data. Bevy
does this earlier through extraction and render-world prepare systems, so the
camera pass should consume extracted render-world state only.

## Design
Change the volumetric fog camera-prepare path to read the render-world state
created by ISS-176. Remove the source-world argument and any local discovery
helpers from this path unless they remain only inside the extraction system.

## Acceptance Criteria
- [ ] Camera volumetric fog prepare no longer accepts or reads `source_world`.
- [ ] Fog volume and light counts used by prepare come from render-world extraction state.
- [ ] Tests prove source-world changes after extraction do not affect the same frame's prepare output.
- [ ] Existing atmosphere and volumetric fog focused tests continue to pass.
