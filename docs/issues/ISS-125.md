## Description
`mgstudio-engine/examples/3d/light_textures/main.mbt` is a heavy local
adaptation of `bevy/examples/3d/light_textures.rs`.

The current example preserves the rough feature name and some light-texture API
surfaces, but replaces Bevy's `AppStatus` resource, `Selection`/`DragMode`
components, widget-message UI, visibility components, gizmos, shadow-hiding
system, child hierarchy, exact light texture assets, and accumulated mouse
motion systems with global state, keyboard shortcuts, proxy meshes, direct light
intensity mutation, and `branding/icon.png` fallback textures.

The underlying clustered decal capability gate is tracked separately by
ISS-098. This issue covers the example-level source-shape repair that can be
done locally once the required ECS/UI/input owners are available.

## Design
Restore the example by following `bevy/examples/3d/light_textures.rs`
symbol-by-symbol:

- Use an ECS `AppStatus` resource with `selection` and `drag_mode`.
- Use `Selection` and `DragMode` as components with Bevy's default/display
  semantics.
- Use a `HelpText` marker component and UI `Text`/`Node` ownership instead of a
  tracked world-space text handle.
- Restore the full Bevy system list and ordering, including widget interaction
  systems, gizmos, hide-shadows, button state updates, directional-light
  updates, drag-mode switching, help text updates, and button visibility.
- Restore Bevy's exact constants for move, scale, roll, and rotation speeds.
- Restore exact asset paths:
  `lightmaps/caustic_directional_texture.png`,
  `lightmaps/torch_spotlight_texture.png`,
  `lightmaps/faces_pointlight_texture_blurred.png`, and
  `models/Faces/faces.glb`.
- Restore Bevy's parent/child hierarchy for directional, spot, and point light
  texture entities, including the Faces scene root and emissive sphere child.
- Use `Visibility` components for show/hide behavior rather than mutating light
  intensity to zero.
- Restore Bevy's `AccumulatedMouseMotion` drag math, spherical-coordinate move,
  multiplicative scale, and Euler `YXZ` roll writeback.
- Keep ISS-098 as the external blocker for exact clustered decal capability
  gating; do not keep proxy mesh or fallback texture workarounds.

If a missing widget/message/input/ECS API prevents a source-shaped port, create
a focused engine issue instead of adding another local workaround.

## Acceptance Criteria
- [x] The example uses an `AppStatus` resource, `Selection`/`DragMode`
