## Description
Bevy has distinct glTF camera-node import behavior. Mgstudio must prove whether
`VolumetricFogExample.glb` contains relevant imported camera content and, if it
does, whether the import path matches Bevy.

## Design
Inspect the source asset and compare Bevy's glTF camera import branches against
mgstudio's loader and scene spawner. Focus on camera projection fields, node
placement, transform behavior, names/extras, and whether the example uses or
intentionally ignores imported cameras.
