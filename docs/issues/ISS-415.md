## Description
Frame state, surface attachments, sprite, UI, shadow UI, slice UI, Mesh2d, and line-gizmo caches contain long-lived native handles that must participate in backend shutdown.

## Design
Give each existing aggregate/cache entry an exact release operation, drain arrays and optional fields, and connect the area release operation to the backend lifecycle root without changing render behavior.

## Acceptance Criteria
- [x] Active and retired frame resources and surface attachments are released in dependency order.
- [x] Sprite and all UI pipeline, buffer, bind-group, texture, view, and sampler owners are released.
- [x] Mesh2d material/pipeline caches and line-gizmo caches release every owned handle.
- [x] Native WGPU report coverage exercises this owner area.

## Notes

`GpuBackend.surface` and `GpuBackend.frame` are active aliases of entries in `surfaces`; shutdown releases only the owning `GpuSurfaceState` entries. Likewise, Mesh2d pending-batch pipeline and material-bind-group fields are borrowed cache aliases and are not released separately.

## Close Notes

The 2D owner shutdown now covers active/retired frame objects, depth/MSAA attachments, sprite resources, UI/shadow/slice UI resources, Mesh2d layouts and caches, and line-gizmo pipelines and retained buffers.
