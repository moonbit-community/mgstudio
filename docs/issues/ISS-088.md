## Description
`examples/3d/pccm/reference.png` is still an unusable transparent baseline. A
standard native capture of the current example produced a numerically nonblank
image, but manual review rejected it: the output was only the default dark
background, not Bevy's parallax-corrected cubemap scene with an outer cube room,
reflective inner cube, reflection probe, and UI controls.

Bevy's `examples/3d/pccm.rs` loads a remote glTF outer-cube scene and remote
KTX2 diffuse/specular cubemaps, installs `FreeCameraPlugin`, spawns a reflective
inner cube, configures a `LightProbe` with `EnvironmentMapLight`, toggles
`ParallaxCorrection::Auto`/`None` through shared radio-button widgets, and uses
an HDR camera. Mgstudio currently substitutes local geometric room content,
different environment maps, keyboard controls, and `Text2d` help text, and the
capture shows no visible PCCM scene.

## Design
Audit and port Bevy `examples/3d/pccm.rs` as the migration unit:

- preserve the Bevy outer-cube glTF scene asset path or provide a checked-in
  exact asset mirror with the same content;
- load the correct PCCM diffuse/specular cubemap assets;
- use Bevy-shaped `FreeCameraPlugin`, HDR camera, and widget/radio-button UI
  flow;
- preserve `LightProbe`, `EnvironmentMapLight`, and
  `ParallaxCorrection::Auto`/`None` updates;
- render a visible PCCM room and reflective inner cube before refreshing the
  reference.

Do not accept a default-background capture or local geometric room substitute as
source parity. If remote asset loading or cubemap support has a real dependency
blocker, record the precise blocker and deletion condition for any local path.

## Acceptance Criteria
- [x] Every source-shape anchor in Bevy `examples/3d/pccm.rs` is classified as
      complete, partial, facade, blocked, or intentionally excluded.
- [x] The outer room and cubemap assets match Bevy's PCCM example content or
      have a precise asset/dependency blocker.
- [x] The standard native capture visibly shows the PCCM room and reflective
      inner cube.
- [x] Parallax correction can be toggled through Bevy-shaped UI widget flow or
      a precise UI blocker is linked.
- [x] `examples/3d/pccm/reference.png` is refreshed only after the visible PCCM
      scene signal is present.
