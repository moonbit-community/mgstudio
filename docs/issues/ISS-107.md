## Description
`examples/3d/atmosphere` is not a source-shaped port of Bevy's
`bevy/examples/3d/atmosphere.rs`. The render resource path is already tracked
by ISS-065 and ISS-067, but the example itself also diverges from Bevy through
local global state, missing Earth/Mars atmosphere presets, missing
`ScatteringMedium` asset setup, missing `Water` extended material shader,
different camera/sun/fog values, local probe spheres, and a 2D help overlay.

These are not all external blockers. They must be repaired or explicitly
classified before the example can count as Bevy source parity.

## Design
After the atmosphere render-resource blocker is resolved, port the example
owner symbol-by-symbol from Bevy. Do not keep local water/material/fog/probe UI
approximations as the parity path. Any remaining missing MoonBit language or
dependency capability must be recorded as a precise blocker.

## Acceptance Criteria
- [ ] `GameState` and `AtmospherePresets` are represented as Bevy-shaped
      resources, including Earth and Mars `ScatteringMedium` handles.
- [ ] Keys 1, 2, 3, 4, Enter, Up, and Down match Bevy's control behavior.
- [ ] The camera, sun, terrain, fog volume, atmosphere entity, and water plane
      match Bevy's source values and component ownership.
- [ ] `Water` is ported as an `ExtendedMaterial<StandardMaterial, Water>` owner
      with its shader, image bindings, sampler settings, and `WaterSettings`
      uniform data, or a real blocker is documented.
- [ ] Local-only probe spheres and 2D help overlay are removed from the parity
      path.
- [ ] The reference image is refreshed only after ISS-065/ISS-067 are resolved
      and the source-shaped example renders without validation/fatal output.

## Notes
- 2026-06-16: Created from the symbol-level ISS-105 audit. The current example
  has useful local controls and a partial visual baseline, but it is not a
  Bevy-shaped owner: Earth/Mars switching, `AtmospherePresets`,
  `ScatteringMedium` asset handles, `Water` extended material, `Terrain`,
  exact camera/sun/fog values, stdout-only controls, and Bevy's dynamic sun
  transform mutation are all missing or adapted.
- 2026-07-01: Fresh visual comparison confirms this source-shape gap is
  visible, not just architectural. Mgstudio includes local-only probe spheres
  and a locally adapted water/material path, and omits Bevy's Earth/Mars preset
  controls. Bevy's source owner has `AtmospherePresets`,
  `ScatteringMedium` asset handles, `MaterialPlugin<ExtendedMaterial<StandardMaterial, Water>>`,
  exact camera/sun/fog setup, and stdout-only controls. Complete this only
  after ISS-065 is unblocked and the example can be ported without hiding the
  render-resource failure.
- 2026-07-01: Removed local-only probe spheres and the 2D help overlay, restored
  the Bevy water material shape using a `Water` `MaterialExtension` with
  bindings 100/101/102 and the copied Bevy `water_material.wgsl`, and changed
  the water plane/camera/control text closer to Bevy. Also copied
  `bevy/assets/textures/mars_mie_phase.ktx2` verbatim into
  `mgstudio-engine/assets/textures/mars_mie_phase.ktx2`.
- 2026-07-01: The example is still not complete source parity. Bevy's Digit4
  path requires `ScatteringMedium::mars(falloff_resolution, phase_resolution,
  dust_phase)` plus `Falloff::Curve` and chromatic phase texture support in the
  light/scattering-medium owner. Mgstudio currently has only `Linear`,
  `Exponential`, `Tent`, `Isotropic`, `Rayleigh`, and scalar `Mie`. Do not fake
  Mars by reusing the Earth medium or a scalar Mie approximation; port the light
  owner symbols or keep this acceptance item open.
- 2026-07-01: Validation after the partial source-shape repair:
  `moon -C mgstudio-engine check --target native examples/3d/atmosphere
  render/renderer pbr/atmosphere pbr light` passed, and the standard 90-frame
  capture completed at `/tmp/mgstudio_atmosphere_iss107_water.png`. This is not
  closeable yet: Digit4 remains blocked by ISS-158, `GameState` /
  `AtmospherePresets` are not yet represented as Bevy-shaped resources, and the
  visual output still does not match Bevy.
