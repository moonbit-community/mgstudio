- External ref: none

## Description
`examples/3d/atmosphere` must remain a source-shaped port of Bevy's
`bevy/examples/3d/atmosphere.rs`. The local example-level gaps have been
reduced to Bevy-shaped resources, `ScatteringMedium` asset handles, typed water
extended material setup, stdout controls, and the checked local reference
capture. Full source parity is still blocked by ISS-158 because Bevy's Mars
medium depends on typed curve and chromatic phase asset support that mgstudio
does not yet expose without an unsafe erased-payload workaround.

## Design
Keep the example owner mapped symbol-by-symbol from Bevy. Do not reintroduce
local water/material/fog/probe UI approximations as the parity path. Leave the
Digit4/Mars branch blocked on ISS-158 until `ScatteringMedium::mars` and the
chromatic phase texture resolver can be represented without JSON-erased payloads
or a numeric shortcut.

## Acceptance Criteria
- [x] `GameState` and `AtmospherePresets` are represented as Bevy-shaped
      resources, including Earth and Mars `ScatteringMedium` handles.
- [ ] Keys 1, 2, 3, 4, Enter, Up, and Down match Bevy's control behavior,
      except Digit4/Mars is blocked by ISS-158.
- [x] The camera, sun, terrain, fog volume, atmosphere entity, and water plane
      match Bevy's source values and component ownership.
- [x] `Water` is ported as an `ExtendedMaterial<StandardMaterial, Water>` owner
      with its shader, image bindings, sampler settings, and `WaterSettings`
      uniform data, or a real blocker is documented.
- [x] Local-only probe spheres and 2D help overlay are removed from the parity
      path.
- [x] The reference image is refreshed only after ISS-065/ISS-067 are resolved
      and the source-shaped example renders without validation/fatal output.
