## Description
`examples/3d/atmosphere` is not a source-shaped port of Bevy's
`bevy/examples/3d/atmosphere.rs`. The render resource path is already tracked
by ISS-065 and ISS-067, but the example itself also diverges from Bevy through
local global state, missing Earth/Mars atmosphere presets, missing
`ScatteringMedium` asset setup, missing `Water` extended material shader,
different camera/sun/fog values, local probe spheres, and a 2D help overlay.

These are not all external blockers. They must be repaired or explicitly
classified before the example can count as Bevy source parity.

## Design
After the atmosphere render-resource blocker is resolved, port the example
owner symbol-by-symbol from Bevy. Do not keep local water/material/fog/probe UI
approximations as the parity path. Any remaining missing MoonBit language or
dependency capability must be recorded as a precise blocker.

## Acceptance Criteria
- [ ] `GameState` and `AtmospherePresets` are represented as Bevy-shaped
      resources, including Earth and Mars `ScatteringMedium` handles.
- [ ] Keys 1, 2, 3, 4, Enter, Up, and Down match Bevy's control behavior.
- [ ] The camera, sun, terrain, fog volume, atmosphere entity, and water plane
      match Bevy's source values and component ownership.
- [ ] `Water` is ported as an `ExtendedMaterial<StandardMaterial, Water>` owner
      with its shader, image bindings, sampler settings, and `WaterSettings`
      uniform data, or a real blocker is documented.
- [ ] Local-only probe spheres and 2D help overlay are removed from the parity
      path.
- [ ] The reference image is refreshed only after ISS-065/ISS-067 are resolved
      and the source-shaped example renders without validation/fatal output.
