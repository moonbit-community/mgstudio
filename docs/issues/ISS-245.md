visual gate completes without relying on the screenshot script retry path. The

`MGSTUDIO_PARITY_CAPTURE_DELAY_FRAMES=90 MGSTUDIO_PARITY_RUN_TIMEOUT_SECONDS=240 MGSTUDIO_PARITY_CAPTURE_DISABLE_RETRY=1 mgstudio-engine/scripts/p0_visual_capture_native.sh examples/3d/scrolling_fog /tmp/mgstudio_iss245_scrolling_fog_delay90.png`

Record the output path, run log status, and visual evidence. This issue should
not introduce new renderer logic; if the gate reveals another source-level
bug, create a new child issue instead of closing this one with a workaround.
