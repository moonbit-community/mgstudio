# ISS-313: Port glTF primitive bounding-box payload parity

## Metadata
- Type: bug
- Status: closed
- Priority: 1
- Labels: examples, pbr, volumetric-fog, gltf, mesh, bounds, source-parity
- Assignee: unassigned
- Created: 2026-07-05
- Updated: 2026-07-05
- External ref: none

## Description
Bevy reads each glTF primitive's bounding box and converts it when mesh
coordinate conversion is active. Mgstudio must carry equivalent primitive
bounding-box data through its parsed glTF model and scene-node construction
instead of relying on absent bounds or render-time guesses.

## Design
Compare Bevy's `primitive.bounding_box()` use with mgstudio's parsed glTF
accessor and primitive data model. If mgstudio does not preserve the bounds
needed by Bevy, port a source-shaped payload path from parsed accessor data to
the primitive scene node. Avoid vertex-scanning or visibility heuristics unless
Bevy uses the same source owner for the same case.

## Acceptance Criteria
- [x] Mgstudio parsed glTF accessor and primitive structures are mapped.
- [x] The source of primitive min/max bounds is identified and compared with
      Bevy's `primitive.bounding_box()` behavior.
- [x] Bounds conversion under `rotate_meshes` is implemented or proven already
      complete.
- [x] Any missing upstream parser capability is recorded as a blocker instead
      of being hidden behind a local workaround.

    primitive bounds extraction from the position accessor. It converts the two

  - `mgstudio-engine/scene/scene.mbt:16-46` carries the primitive bounds payload
    as `SceneNode3d.aabb : @camera.Aabb?`.

    AABB into the primitive `SceneNode3d`.
  - `mgstudio-engine/scene/gltf_loader_wbtest.mbt:645-699` verifies both
    unconverted and `rotate_meshes`-converted AABB centers and half sizes from
    accessor `min`/`max`.
- 2026-07-05: Bevy comparison: ISS-311 established that Bevy uses
  `primitive.bounding_box()` during primitive child creation, then converts the
  min/max corners when `rotate_meshes` is active. Mgstudio previously had no
  parsed accessor min/max payload, so it could not represent this source path.
  This was a local parser/model gap, not an external blocker.
- 2026-07-05: Source-shape classification:
  - Parsed accessor bound payload: complete for glTF vec3 primitive position
    bounds.
  - Primitive AABB payload on scene node: complete at source-data level.
  - Runtime ECS component insertion from the scene node payload: intentionally
    deferred to ISS-314.
