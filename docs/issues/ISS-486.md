## Description

The first-ever pinned-Bevy spot capture of `examples/3d/deferred_rendering`
(frame 90, fixed frames, 2560x1440) shows mean_abs_rgb 28.03 with mixed
character: several regions match closely (e.g. (896,864) ours
(145,236,122) vs Bevy (141,235,118); (2048,288) whites equal; (1664,864)
within a few steps), while others differ structurally — at (512,288) ours
renders scene content (101,118,86) where Bevy shows the dark backdrop
(46,47,49); at (1280,216) ours is darker scene content vs Bevy's brighter
(182,164,151); the center sphere hue differs ((124,57,35) vs (98,80,82)).
Mid-tone regions also sit ~10-15% brighter in ours.

The same-engine old-vs-new delta is the clean expected tonemapping class
(18.25 mean, 39.9% strong), so this divergence PREDATES the ISS-483 work
and was invisible to old-vs-new screening — batch 1 was never
Bevy-compared. Candidate causes to investigate at the owning modules:
camera framing/fov, scene element scale or placement in the example port,
the deferred G-buffer lighting path, or environment/reflection
differences. No root-cause claim yet.

Human judgment (2026-08-04, VIS-481-batch1r): reference refresh PASSED
and installed — the reference tracks our engine's current state; this
issue tracks the Bevy gap separately.
