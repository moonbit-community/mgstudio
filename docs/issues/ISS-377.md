## Description
Prove that the real `examples/3d/volumetric_fog` directional and ambient light
values written into the mesh-view GPU light data match Bevy's source
expressions.

## Design
Use the owner map from ISS-376. Compare Bevy directional light preparation
against mgstudio's render-world data for:

- directional light count and ordering;
- directional light color, illuminance scaling, and direction;
- volumetric and shadow flags;
- depth bias, normal bias, soft shadow size, cascade count, cascade overlap,
  depth texture base index, decal index, and sun disk fields;
- ambient color and brightness.

Use focused tests or recorded runtime evidence from the real example. Do not
repair code here unless the repair owner is already proven and moved to
ISS-375.

## Close Notes
Closed on 2026-07-05 after adding focused real-example evidence in
`mgstudio-engine/examples/3d/volumetric_fog/main_wbtest.mbt`.

Bevy source expressions audited:

- `bevy/crates/bevy_pbr/src/render/light.rs::prepare_lights` writes
  `GpuLights.n_directional_lights` from the view-visible directional light
  count.
- `GpuDirectionalLight.color` is `light.color * light.illuminance`.
- `GpuDirectionalLight.dir_to_light` is `light.transform.back()`.
- Directional flags are derived from shadow, volumetric, lightmapped-diffuse,
  and contact-shadow state.
- `soft_shadow_size`, `shadow_depth_bias`, `shadow_normal_bias`,
  `num_cascades`, `cascades_overlap_proportion`, `depth_texture_base_index`,
  `decal_index`, `sun_disk_angular_size`, and `sun_disk_intensity` are copied
  from the extracted directional light and cascade state.
- `GpuLights.ambient_color` is `AmbientLight.color * AmbientLight.brightness`.
- `ambient_light_affects_lightmapped_meshes` is copied from ambient light
  state.

Mgstudio evidence:

- Added test
  `volumetric_fog: directional and ambient GPU lights match Bevy prepare_lights`.
- The test runs the real `examples/3d/volumetric_fog` app setup plus
  `tweak_scene`, `move_directional_light`, `move_point_light`, and
  `adjust_app_settings` for six updates, then reads the render-world
  `Render3dLightingState` and `GpuLights3d`.
- The test asserts one directional light, `color * illuminance`,
  `directional_transform.back()`, shadow/volumetric/lightmapped-diffuse flags,
  directional depth bias, normal bias, soft shadow size, cascade count,
  cascade overlap, depth texture base index `0`, decal index `-1`, default
  Earth `SunDisk` values, black ambient color from brightness `0`, and ambient
  lightmapped-diffuse flag `1`.

Validation:

- `moon -C mgstudio-engine test examples/3d/volumetric_fog --target native --release --filter 'volumetric_fog: directional and ambient GPU lights match Bevy prepare_lights'`
  passed `1/1`; duplicate `-lobjc` and `-lz` linker warnings were emitted.
- `moon -C mgstudio-engine fmt` passed.
- `moon -C mgstudio-engine info` passed with no work to do.
- `moon -C mgstudio-engine check --target native` passed with no work to do.

No directional or ambient GPU value divergence was found. ISS-377 does not
assign a repair owner to ISS-375. Continue with ISS-378 for directional shadow
cascade and depth-texture values and ISS-379 for clustered point/spot values.
