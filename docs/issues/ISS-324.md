## Description
`ISS-304` currently combines render extraction, visibility, phase inclusion,
and draw-state checks. This leaf issue owns only the render extraction boundary
for the `volumetric_fog` frame-dominating mesh contributor: source entity,
render entity, extracted transform, mesh handle, material handle, AABB, and
visibility-relevant copied data.

## Design
Compare Bevy PBR mesh extraction anchors with the mgstudio extraction path.
Use focused runtime evidence for the real `VolumetricFogExample.glb` `Cube`
primitive. Keep this separate from phase queue ordering and material pipeline
state, which are covered by `ISS-325`.
