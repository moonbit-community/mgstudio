## Description
`examples/3d/scrolling_fog` depends on Bevy's 3D noise density texture and the
animated `FogVolume.density_texture_offset`. Mgstudio must prove that the KTX2
asset, texture view dimension, sampler binding, optional-density bind-group
shape, and per-frame offset data reach the shader like Bevy.

## Design
Compare Bevy `FogVolume` extraction, density texture asset lookup, optional
texture/sampler binding, and `density_texture_offset` update path against
mgstudio. Preserve the Bevy asset file unchanged. Missing texture assets must be
handled like Bevy's render asset lookup, not with substitute textures.

## Acceptance Criteria
- [x] `volumes/fog_noise.ktx2` is loaded as the Bevy-equivalent 3D `R32Float`
      density texture without asset edits.
- [x] Textured fog volumes use the density-texture pipeline and bind a 3D
      texture view plus sampler at the Bevy-equivalent bindings.
- [x] Missing render assets follow Bevy's skip/absence behavior instead of a
      local fallback texture.
- [x] Capture or focused evidence shows `density_texture_offset` changes
      rendered pixels after ISS-202 is complete.

## Close Notes
Closed on 2026-07-04.

Audited Bevy `FogVolume.density_texture`, `ViewFogVolume.density_texture`,
`volumetric_fog` density-image lookup, density bind-group entries, and the
`examples/3d/scrolling_fog.rs::scroll_fog` offset update. Mgstudio preserves the
same source shape: `volumes/fog_noise.ktx2` is loaded with repeat addressing on
all axes and linear mag/min/mipmap filters, `FogVolume.density_texture` is
forwarded into `ViewFogVolume`, and `density_texture_offset` is packed into the
volumetric fog uniform consumed by `volumetric_fog.wgsl`.

`asset/host_io_wbtest.mbt` verifies the Bevy density asset decodes as a 64x64x64
3D texture with `R32Float` format and 1,048,576 payload bytes. Renderer
white-box coverage now verifies Bevy's `RenderAssets<Image>::get(id)` absence
semantics: negative or missing density ids produce `None` and therefore use the
textureless pipeline instead of a fallback texture, while a real 3D `R32Float`
texture id resolves successfully. The volumetric fog bind group layout and bind
group path bind density resources at group 1 bindings 2 and 3 as a 3D float
texture view plus filtering sampler.
