## Description
Bevy's `examples/gizmos/3d_gizmos.rs` demonstrates both immediate-mode `Gizmos`
and static gizmo assets through `Assets<GizmoAsset>`, including a 30,000-line
sphere spawned as a `Gizmo` component. The mgstudio example currently covers the
immediate 3D gizmo drawing path, but it does not expose or use a source-shaped
`GizmoAsset` asset/component path.

## Design
Port the Bevy `GizmoAsset` owner shape into mgstudio instead of approximating the
static sphere with per-frame immediate lines. The final example should retain the
Bevy source structure: create a gizmo asset during setup, add it to
`Assets<GizmoAsset>`, spawn a `Gizmo` component with the handle and line config,
and render it through the gizmo render path.

## Acceptance Criteria
- [ ] mgstudio has source-shaped `GizmoAsset` and `Gizmo` component APIs for
      static gizmo geometry.
- [ ] `examples/gizmos/3d_gizmos` creates and spawns the 30,000-line sphere in
      setup, matching Bevy's example structure.
- [ ] The example still renders immediate-mode 3D gizmos and the static gizmo
      asset in the standard native screenshot path.
- [ ] Relevant gizmo package tests cover asset-backed static gizmo storage and
      render extraction.
