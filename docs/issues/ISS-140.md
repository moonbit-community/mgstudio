## Description
Bevy's `examples/gizmos/3d_gizmos.rs` demonstrates both immediate-mode `Gizmos`
and static gizmo assets through `Assets<GizmoAsset>`, including a 30,000-line
sphere spawned as a `Gizmo` component. mgstudio already has the retained
`GizmoAsset` and `Gizmo` component API shape, but the retained component path is
not extracted into the 3D render pipeline, and the example still avoids the
source-shaped retained asset setup.

## Design
Wire the existing retained `GizmoAsset` owner shape into mgstudio's 3D gizmo
render path instead of approximating the static sphere with per-frame immediate
lines. The final example should retain the Bevy source structure: create a gizmo
asset during setup, add it to `Assets<GizmoAsset>`, spawn a `Gizmo` component
with the handle and line config, and render it through the gizmo render path.

## Acceptance Criteria
- [x] mgstudio extracts retained `Gizmo` components backed by `GizmoAsset` into
      the 3D gizmo render path.
- [x] `examples/gizmos/3d_gizmos` creates and spawns the 30,000-line sphere in
      setup, matching Bevy's example structure.
- [x] The example still renders immediate-mode 3D gizmos and the static gizmo
      asset in the standard native screenshot path.
- [x] Relevant gizmo package tests cover asset-backed static gizmo storage and
      render extraction.
