## Description
The volumetric fog shader samples view depth while the camera may be configured
with MSAA. Bevy's path must be mirrored precisely: mgstudio should sample the
same Bevy-equivalent depth texture representation, or record a blocker if the
current backend cannot express the required depth resolve/sampling behavior.

## Design
Audit Bevy's view-depth texture preparation and render target handling for MSAA
against mgstudio's depth target creation and sampled depth binding. Do not hide
an unsupported MSAA case behind a fallback. If local infrastructure is missing,
add the required source-shaped render target state; if the backend API is
missing, record an external blocker with the exact missing capability.

## Acceptance Criteria
- [x] Non-MSAA cameras bind the expected sampled view depth texture.
- [x] MSAA cameras either bind the Bevy-equivalent sampled depth representation
      or have a precise blocker documenting the missing backend capability.
- [x] Focused coverage or notes prove the chosen path matches Bevy's source
      semantics.

## Close Notes
2026-07-04: Bevy creates one volumetric fog bind group layout per
`VolumetricFogBindGroupLayoutKey` combination. Binding 1 uses
`texture_depth_2d_multisampled()` when the key contains `MULTISAMPLED`, and
`texture_depth_2d()` otherwise. The same key also drives the `MULTISAMPLED`
shader def.

Mgstudio matches this source shape:
`VolumetricFogPipelineKey::bind_group_layout_key` derives the multisampled bit
from `MeshPipelineViewLayoutKey::MULTISAMPLED`, renderer
`mesh3d_volumetric_fog_bind_group_layout_index` derives bit 0 from
`msaa_sample_count > 1`, and
`ensure_mesh3d_volumetric_fog_bind_group_layouts` creates binding 1 as
`TEXTURE_SAMPLE_TYPE_DEPTH` with `multisampled` set from that bit. The embedded
WGSL remains Bevy-shaped with `texture_depth_multisampled_2d` under
`#ifdef MULTISAMPLED` and `texture_depth_2d` otherwise.

No backend blocker was found for the native path: mgstudio depth textures are
created with `RENDER_ATTACHMENT | TEXTURE_BINDING | COPY_SRC` and the active
pass state now carries the selected view depth texture.

Validation:
- `moon -C mgstudio-engine test pbr/volumetric_fog --target native --release`
  passed: 13 tests.
- `moon -C mgstudio-engine test render/renderer --target native --release`
  passed: 87 tests.
