## Description
ISS-198 verified that the volumetric fog pass receives a directional shadow
texture binding and cascade metadata. The final capture still lacks the expected
diagonal light-shaft structure, so this issue groups the smaller source-owner
audits needed to prove that the shadow texture contains Bevy-equivalent pillar
occluder data for the active directional light.

## Design
Do not treat "a shadow texture is bound" as sufficient. Split the work by Bevy
owner boundary: directional cascade construction, shadow target/pass creation,
visible-entity extraction, shadow phase queue/draw execution, and frame identity
between the rendered target and the volumetric fog binding. Each child issue
must either prove source-level parity, fix a local divergence source-faithfully,
or record a precise blocker.
