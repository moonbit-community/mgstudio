## Description
Bevy `volumetric_fog` queries each view for `ViewVolumetricFogPipelines`,
`ViewVolumetricFog`, and `MeshViewBindGroup`, and returns/skips according to
specific resource gates such as missing pipelines, uniform buffer binding, and
missing render meshes.

## Design
Audit mgstudio's PBR and renderer execution gates against Bevy before
auditing concrete bind groups and draw commands.

## Acceptance Criteria
- [ ] View query inputs are classified against Bevy.
- [ ] Pipeline-cache and uniform-buffer early-return behavior is classified.
- [ ] Per-volume missing mesh/render-asset behavior is classified.
- [ ] Pass order relative to main pass and early postprocess is rechecked.
