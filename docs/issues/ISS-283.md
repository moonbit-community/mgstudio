## Description
Bevy `volumetric_fog` queries each view for `ViewVolumetricFogPipelines`,
`ViewVolumetricFog`, and `MeshViewBindGroup`, and returns/skips according to
specific resource gates such as missing pipelines, uniform buffer binding, and
missing render meshes.

## Design
Audit mgstudio's PBR and renderer execution gates against Bevy before
auditing concrete bind groups and draw commands.

## Acceptance Criteria
- [x] View query inputs are classified against Bevy.
- [x] Pipeline-cache and uniform-buffer early-return behavior is classified.
- [x] Per-volume missing mesh/render-asset behavior is classified.
- [x] Pass order relative to main pass and early postprocess is rechecked.

## Close Notes
Closed 2026-07-09. Bevy `volumetric_fog` consumes view target, view depth,
per-view pipelines, per-view fog volumes, mesh view bind group, MSAA, pipeline
cache, uniform buffer binding, GPU images, mesh allocator, fog assets, and
render meshes. Mgstudio splits that shape between the PBR prepared-output gate
and renderer host call, but the observed gates map to Bevy source behavior:
missing per-view fog or pipelines skips the PBR host call; missing native pass
state, color target, view depth, uniform buffer, pipelines, or view bind group
returns from renderer materialization; missing per-volume mesh skips that
volume. The `light_count > 0` prepared gate corresponds to Bevy
`extract_volumetric_fog` returning early when no `VolumetricLight` exists.

Pass ordering is covered by source-shaped tests: volumetric fog runs after the
main pass and before early postprocess, and the main pass explicitly ends its
active pass before the volumetric fog pass starts.

Existing evidence:
- `pbr/volumetric_fog/top_wbtest.mbt` covers Core3d MainPass ->
  volumetric_fog -> EarlyPostProcess order.
- `pbr/render_execute_camera_wbtest.mbt` covers the camera execution trace
  boundary between main pass, volumetric fog, and postprocess.
- `pbr/volumetric_fog_execute_wbtest.mbt` covers prepared-output gates for
  view count, volume count, light count, fog assets, per-view fog metadata, and
  pipeline variants.
- `render/renderer/gpu_wbtest.mbt` covers volume mesh choice, dynamic offset
  forwarding, density texture lookup, and pipeline cache key behavior.

Verification:

- `moon -C mgstudio-engine test --release render/renderer`
- `moon -C mgstudio-engine check --target native`
