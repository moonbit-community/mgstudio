## Description
Mesh3d GPU preprocessing owns per-camera upload states, reset/direct/indirect compute pipelines, layouts, bind-group layouts, and depth-pyramid resources.

## Design
Give preprocessing upload-state aggregates exact release operations, release every persistent preprocessing field from the backend owner, and replace any raw cache clearing with owner-aware clearing.

## Acceptance Criteria
- [ ] Per-camera preprocessing buffers and bind groups are released.
- [ ] Reset, direct, indirect, and indexed/non-indexed build pipeline families are released.
- [ ] Depth-pyramid textures, views, samplers, layouts, and pipelines are released.
- [ ] Native WGPU report coverage returns representative preprocessing handles to baseline.
