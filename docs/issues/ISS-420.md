## Description
Mesh3d GPU preprocessing owns per-camera upload states, reset/direct/indirect compute pipelines, layouts, bind-group layouts, and depth-pyramid resources.

## Design
Give preprocessing upload-state aggregates exact release operations, release every persistent preprocessing field from the backend owner, and replace any raw cache clearing with owner-aware clearing.

## Acceptance Criteria
- [x] Per-camera preprocessing buffers and bind groups are released.
- [x] Reset, direct, indirect, and indexed/non-indexed build pipeline families are released.
- [x] Depth-pyramid textures, views, samplers, layouts, and pipelines are released.
- [x] Native WGPU report coverage returns representative preprocessing handles to baseline.

## Notes

The camera upload-state array owns its entries. Filtering old camera keys must release rejected states before rebuilding the array; raw `Array::clear` alone only discards MoonBit references and does not release native WGPU handles.

## Close Notes

Added complete release semantics for `GpuMesh3dPreprocessCameraUploadState`, covering phase and compute bind groups, all upload/work-item/metadata/indirect buffers, and per-camera depth pyramids. Backend shutdown now releases every preprocessing pipeline, layout, bind-group layout, dummy depth resource, and sampler. Camera-state retention now releases removed states instead of silently dropping their native handles.
