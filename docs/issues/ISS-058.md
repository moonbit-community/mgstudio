## Description
`Milky2018/moon_cpal@0.11.6` fails to build on the current MoonBit toolchain because multiple structs still declare `fn new(..)` constructors inside struct bodies and call those constructors as value constructors. Many examples import `Milky2018/mgstudio`, which pulls in the default audio stack, so stale `reference.png` files cannot be regenerated until this dependency is fixed upstream and published.

## Design
Do not patch `.mooncakes` or add a local compatibility layer. Wait for an upstream `Milky2018/moon_cpal` release that uses current MoonBit top-level constructor methods, then update `mgstudio-engine/moon.mod` normally.

## Acceptance Criteria
- [ ] A fixed `Milky2018/moon_cpal` version is available in the MoonBit registry.
- [ ] `mgstudio-engine/moon.mod` uses the fixed version.
- [ ] A package importing the default audio stack builds with `moon -C mgstudio-engine build --target native --release`.
