# ISS-161: Unblock render pipeline depth bias descriptor fields

## Metadata
- Type: task
- Status: closed
- Priority: 1
- Labels: wgpu_mbt, render, pbr, source-parity, depth-bias
- Assignee: unassigned
- Created: 2026-06-29
- Updated: 2026-06-30
- External ref: https://github.com/moonbit-community/wgpu-mbt/issues/32

## Description
Bevy writes `DepthBiasState::constant`, `slope_scale`, and `clamp` into render
pipeline descriptors. Mgstudio already exposes material and wireframe depth
bias data, but the current `wgpu_mbt` render pipeline descriptor builder only
accepts depth format, depth write, and depth compare. This prevents source-level
PBR `StandardMaterial::specialize` parity for material `depth_bias` and also
prevents faithful emission of non-default depth bias values from render
descriptor data.

## Design
Do not add a project-local native stub or silently ignore non-default depth
bias. Keep mgstudio's render descriptor source-shaped and require `wgpu_mbt` to
expose safe builder support for the official WebGPU depth bias fields before
non-default values can reach the backend.

## Acceptance Criteria
- [x] `wgpu_mbt` exposes render pipeline depth bias constant, slope scale, and
      clamp setters or an equivalent complete `DepthBiasState` builder API.
- [x] Mgstudio passes non-default `DepthStencilState` depth bias fields into
      `wgpu_mbt` without project-local native stubs.
- [x] PBR `StandardMaterial::depth_bias` and wireframe depth bias affect real
      GPU render pipeline descriptors.

## Notes
- 2026-06-29: `wgpu_mbt@0.14.2` exposes
  `RenderPipelineDescBuilder::set_depth_stencil(format, depth_write_enabled?,
  depth_compare_u32?)`, but no depth bias fields. This is an upstream binding
  gap because the official WebGPU pipeline depth-stencil state includes the
  depth bias fields.
- 2026-06-29: Upstream request filed as moonbit-community/wgpu-mbt#32.
- 2026-06-30: `wgpu_mbt@0.14.6` extends
  `RenderPipelineDescBuilder::set_depth_stencil` with `depth_bias`,
  `depth_bias_slope_scale`, and `depth_bias_clamp`. Mgstudio now forwards
  `DepthStencilState` bias fields from render pipeline cache materialization
  and mesh2d descriptor pipeline creation, and updates the remaining low-level
  mesh pipeline C call to the new ABI.

## Close Notes
Closed after updating to `Milky2018/wgpu_mbt@0.14.6` and forwarding Bevy-shaped
depth bias fields into the render pipeline builder. Verified with `moon -C
mgstudio-engine check --target native --deny-warn` and `moon -C
mgstudio-engine test --release render/renderer --deny-warn`.
