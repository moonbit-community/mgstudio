# ISS-161: Unblock render pipeline depth bias descriptor fields

## Metadata

- Assignee: unassigned

## Description
Bevy writes `DepthBiasState::constant`, `slope_scale`, and `clamp` into render
pipeline descriptors. Mgstudio already exposes material and wireframe depth
bias data, but the current `wgpu_mbt` render pipeline descriptor builder only
accepts depth format, depth write, and depth compare. This prevents source-level
PBR `StandardMaterial::specialize` parity for material `depth_bias` and also
prevents faithful emission of non-default depth bias values from render
descriptor data.

## Design
Do not add a project-local native stub or silently ignore non-default depth
bias. Keep mgstudio's render descriptor source-shaped and require `wgpu_mbt` to
expose safe builder support for the official WebGPU depth bias fields before
non-default values can reach the backend.

## Acceptance Criteria
- [ ] `wgpu_mbt` exposes render pipeline depth bias constant, slope scale, and
      clamp setters or an equivalent complete `DepthBiasState` builder API.
- [ ] Mgstudio passes non-default `DepthStencilState` depth bias fields into
      `wgpu_mbt` without project-local native stubs.
- [ ] PBR `StandardMaterial::depth_bias` and wireframe depth bias affect real
      GPU render pipeline descriptors.
