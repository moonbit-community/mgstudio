## Description
`examples/3d/color_grading` currently implements the visible idea of Bevy's
`bevy/examples/3d/color_grading.rs`, but it is not a source-shaped port.

The main scene, color-grading enums, option values, camera settings, fog,
environment map, buttons, and keyboard adjustment behavior are represented.
However, the UI is manually expanded into many direct world writes, including
repeated `set_by_key` blocks that have no Bevy source equivalent. The example
does not preserve Bevy's bundle-returning helper functions, `Changed<Interaction>`
query, `TextUiWriter` update path, `WorldAssetRoot` scene ownership, or
`Single<&mut ColorGrading>` mutation model. A local `ColorGradingCamera` marker
and overlay camera are used as scaffolding.

## Design
Repair the example against the Bevy source owner. Keep the visible controls and
scene values, but reshape the code around Bevy's symbols: resource/component
owners, bundle helpers, UI writer behavior, change detection, and in-place
camera color-grading mutation.

## Acceptance Criteria
- [x] `setup` exposes Bevy-shaped `Commands`, selected-option resource, and
      `AssetServer` params where the ECS API can express them.
- [x] UI construction preserves Bevy's helper boundaries:
      `add_buttons`, `buttons_for_global_controls`, `buttons_for_section`,
      `button_for_value`, `add_help_text`, and `text`.
- [x] Mechanical duplicate component writes are removed.
- [x] Button press handling preserves the `Changed<Interaction>` filter and
      only updates the selected option on pressed button widgets.
- [x] UI state updates preserve Bevy's changed-state early exit and
      `TextUiWriter`-style text/color update semantics.
- [x] Camera color grading is adjusted through Bevy-shaped query/resource
      params and in-place `ColorGrading` mutation rather than local marker
      lookup plus component replacement.
- [x] Scene loading preserves `WorldAssetRoot` semantics or records a precise
      ECS/scene blocker.
- [x] Local-only `ColorGradingCamera` and overlay scaffolding are removed from
      the parity path unless a real blocker is documented.
- [ ] The reference screenshot is refreshed after the source-shaped port still
      renders correctly.
