## Description
`moon -C mgstudio-engine test pbr --release` currently fails in
`pbr/material_pipeline_specializer_wbtest.mbt` at
`"pbr material specialization keeps tangent defs for forward decal meshes"`.
The failure is:

`forward decal test mesh must generate tangents`

This was discovered while validating ISS-221. The failure is not part of the
camera computed-value owner, but it means the PBR package-wide release test
gate is not clean.

## Design
Audit the test mesh and the Bevy mesh tangent-generation owner before changing
code. The fix must preserve Bevy source shape: decal/material specialization
tests should construct the same tangent-bearing geometry Bevy expects, and
mesh tangent generation must not silently downgrade to an approximation.

## Acceptance Criteria
- [ ] `moon -C mgstudio-engine test pbr/material_pipeline_specializer_wbtest.mbt --release`

- [ ] `moon -C mgstudio-engine test pbr --release` no longer fails on the
      forward decal tangent-generation test.
- [ ] Any remaining package-wide PBR failures are recorded separately with
      exact failing test names.
