## Description
`moon -C mgstudio-engine test pbr --release` currently fails in
`pbr/material_pipeline_specializer_wbtest.mbt` at
`"pbr material specialization keeps tangent defs for forward decal meshes"`.
The failure is:

`forward decal test mesh must generate tangents`

This was discovered while validating ISS-221. The failure is not part of the
camera computed-value owner, but it means the PBR package-wide release test
gate is not clean.

## Design
Audit the test mesh and the Bevy mesh tangent-generation owner before changing
code. The fix must preserve Bevy source shape: decal/material specialization
tests should construct the same tangent-bearing geometry Bevy expects, and
mesh tangent generation must not silently downgrade to an approximation.

## Acceptance Criteria
- [x] `moon -C mgstudio-engine test pbr/material_pipeline_specializer_wbtest.mbt --release`
      passes.
- [x] `moon -C mgstudio-engine test pbr --release` no longer fails on the
      forward decal tangent-generation test.
- [x] Any remaining package-wide PBR failures are recorded separately with
      exact failing test names.

## Notes
- 2026-07-06: `moon -C mgstudio-engine test pbr --release` reported 435 total
  tests, 434 passed, 1 failed. Focused camera/sub-view tests still passed:
  `camera_bundle_test.mbt`, `projection_wbtest.mbt`, and
  `projection_test.mbt`.
- 2026-07-06: Root cause was the whitebox test fixture, not tangent
  generation. The test hand-authored a four-vertex plane without normals, while
  Bevy-shaped tangent generation requires normals and UVs. The fixture now
  mirrors mgstudio's forward decal mesh owner: rectangle builder, rotation from
  +Z to +Y, then tangent generation.
