## Description
Bevy's `tweak_scene` system runs over changed `DirectionalLight` components in
the `volumetric_fog` example, enables shadow maps, and inserts
`VolumetricLight` on the same entities.

## Design
Port the `Commands` plus `Query<(Entity, &mut DirectionalLight),
Changed<DirectionalLight>>` behavior as closely as MoonBit ECS allows. Do not
replace the `VolumetricLight` insertion with light-intensity, fog-density, or
renderer-flag approximations.

## Acceptance Criteria
- [x] Changed directional lights have `shadow_maps_enabled` set to `true`.
- [x] The same entities receive `VolumetricLight`.
- [x] The system uses the local equivalent of Bevy's changed-filter query
      instead of scanning unrelated entities.
- [x] A focused test or runtime capture proves the mutation reaches the
      render-visible light state.
