## Description
`examples/3d/reflection_probes` had a fully transparent checked-in
`reference.png`. After fixing the shader-composition startup stall, the capture
showed skybox/cubes content but the central metallic sphere remained matte
instead of reflective.

The current mgstudio example already has Bevy-shaped components for camera
exposure, skybox, environment map, light probe, and reflection modes, so the
failure appears to be in the local PBR/runtime lighting path or scene/probe
data flow rather than in the screenshot wrapper.

## Design
Audit the example and PBR render path against Bevy's
`reflection_probes.rs`, `EnvironmentMapLight`, `GeneratedEnvironmentMapLight`,
`LightProbe`, parallax correction, skybox, exposure, and relevant render
owners. Do not accept a dark capture as a reference, and do not hide missing
reflection-probe behavior behind an environment-map fallback.

## Acceptance Criteria
- [ ] `examples/3d/reflection_probes` is source-shape audited against Bevy's
      `reflection_probes.rs`.
- [x] The standard 90-frame native capture shows visible skybox/cubes scene
      content and a reflection/probe effect on the metallic sphere.
- [ ] Any missing PBR reflection-probe runtime owner is ported or recorded as
      a precise blocker if MoonBit or a dependency cannot express it.
- [ ] `mgstudio-engine/examples/3d/reflection_probes/reference.png` is
      refreshed only after the visual signal is present.

## Notes
- 2026-06-13: Standard capture command succeeded with `alpha_mean=1`,
  `gray_mean=0.282162`, `size=2560x1440`, and the generic sanity script passed.
  Manual review rejected the output because it lacked the visible skybox,
  cubes-scene, and reflection-probe features expected from the Bevy source. The
  generated image was discarded.
- 2026-06-14: Reproduced a stricter current failure where the standard capture
  produced no RGBA8 blob at all. Sampling the running native process showed the
  main thread inside `render3d_prepare_meshes_system ->
  render3d_prewarm_mesh_pipelines -> load_wgsl_preprocessed ->
  moon_wgsl_naga_oil::Composer`, repeatedly parsing/composing the mesh WGSL
  import graph before a capturable frame. Added a composed-WGSL cache in
  `shader/compile`, keyed by target plus sorted bool/value shader defs, matching
  the required shader-cache behavior rather than increasing capture timeouts.
  After this, the standard capture completed to
  `/tmp/mgstudio_iss080_reflection_probes_cached.png` and showed visible
  skybox/cubes content. Remaining visual gap: the central sphere is still
  non-reflective/matte, so the reflection-probe/PBR lighting path remains
  incomplete and the checked-in reference must not be refreshed yet.
  Validation: `moon -C mgstudio-engine check --target native --deny-warn
  --package-path shader/compile`; `moon -C mgstudio-engine test --release
  shader/compile`; `moon -C mgstudio-engine check --target native --deny-warn
  --package-path render/renderer`; `moon -C mgstudio-engine check --target
  native --deny-warn --package-path examples/3d/reflection_probes`; and
  `MGSTUDIO_PARITY_CAPTURE_DELAY_FRAMES=90
  MGSTUDIO_PARITY_RUN_TIMEOUT_SECONDS=240
  mgstudio-engine/scripts/p0_visual_capture_native.sh
  examples/3d/reflection_probes
  /tmp/mgstudio_iss080_reflection_probes_cached.png`.
- 2026-06-14: Fixed the matte-sphere visual failure. The example had diverged
  from Bevy's `spawn_sphere` source shape: Bevy uses
  `Sphere::new(1.0).mesh().ico(7).unwrap()`, while mgstudio had a local
  handwritten UV sphere mesh with no explicit normal attribute. Replaced that
  local mesh path with the existing Bevy-shaped `SphereMeshBuilder::ico(7)`
  primitive path and removed duplicate camera HDR/exposure component inserts.
  The standard 90-frame native capture now produces a reflective metallic
  sphere with visible skybox/cubes content and was saved as
  `mgstudio-engine/examples/3d/reflection_probes/reference.png`.
  Validation: `moon -C mgstudio-engine check --target native --deny-warn
  --package-path examples/3d/reflection_probes`; and
  `MGSTUDIO_PARITY_CAPTURE_DELAY_FRAMES=90
  MGSTUDIO_PARITY_RUN_TIMEOUT_SECONDS=240
  mgstudio-engine/scripts/p0_visual_capture_native.sh
  examples/3d/reflection_probes
  /tmp/mgstudio_iss080_reflection_probes_ico.png`.
