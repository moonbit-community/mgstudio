## Description
Bevy places volumetric fog systems in `ExtractSchedule`,
`RenderSystems::Prepare`, `prepare_core_3d_depth_textures.before(...)`, and
the Core3d graph after `MainPass` and before `EarlyPostProcess`.

## Design
Audit the mgstudio schedule/pass ordering against Bevy's plugin build. This is
an audit issue: if a schedule divergence is found, either fix it in this slice
or file a precise follow-up.

## Acceptance Criteria
- [x] Extract schedule registration is classified.
- [x] Prepare-system placement is classified.
- [x] Depth texture preparation ordering is classified.
- [x] Core3d graph insertion relative to main pass and early postprocess is
      classified.

  with asset/resource initialization.

  reason: the source-shaped logic exists and has tests, but it is not yet a
  standalone render prepare system before a Core3d depth-texture owner. This
  audit does not hide those partial anchors; the remaining executable work is
  already tracked by ISS-279 through ISS-284 under ISS-195, with broader
  render-app ordering pressure tracked by ISS-018 and ISS-019.
