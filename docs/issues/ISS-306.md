## Description
Before changing mgstudio's loader, identify the exact Bevy source anchors that
own `VolumetricFogExample.glb` scene import. The audit must cover scene root
creation, `load_node`, node transforms, node names/extras, primitive child
entities, and glTF extension handling that can affect this example.

## Design
Read Bevy `bevy/crates/bevy_gltf/src/loader/mod.rs` and any directly called
helpers needed for scene/node import. Record the source paths and symbol names
needed by later issues; do not infer parity from mgstudio files alone.

## Notes
- 2026-07-05: Split from ISS-301 so Bevy source-owner mapping is not mixed with
  local implementation or runtime evidence.
- 2026-07-05: Bevy source anchors for scene and node import:
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:929-1007` pre-creates
    `GltfAssetLabel::Node(index)` handles, checks cycles, and builds
    `GltfNode` subassets with children, mesh handle, `node_transform`, skin,
    extras, and named-node map entries.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1020-1126` creates one
    `WorldAsset` per glTF scene, spawns the scene root with
    `convert_coordinates.scene_conversion_transform()`, `Visibility::default`,
    and scene name, calls `load_node` for each root node with
    `Transform::default()` as the parent transform, inserts scene name/extras,
    resolves skin joint entities after all nodes are spawned, runs
    `extension.on_scene_completed`, then labels the asset as
    `GltfAssetLabel::Scene(index)`.
  - `bevy/crates/bevy_gltf/src/loader/gltf_ext/scene.rs:15-44` owns
    `node_name` and `node_transform`: unnamed nodes become `GltfNode{index}`;
    matrix nodes are converted through `Mat4::from_cols_array_2d`; decomposed
    nodes preserve translation, quaternion array, and scale.
  - `bevy/crates/bevy_gltf/src/convert_coordinates.rs:64-118` owns
    scene-versus-mesh coordinate conversion. Scene conversion affects only the
    top-level scene entity; mesh conversion affects mesh assets and entities
    that instance meshes through `Mesh3d`.
- 2026-07-05: Bevy `load_node` anchors:
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1512-1539` computes the local
    node transform, accumulated `world_transform`, and negative-scale winding
    inversion state.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1539-1567` spawns the glTF node
    entity as `(transform, Visibility::default())`, inserts `Name` and
    `GltfExtras`, and conditionally inserts animation targeting data.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1569-1616` inserts camera
    components on the same node entity when `settings.load_cameras` and a glTF
    camera are present, then maps `gltf_node.index()` to the node entity.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1833-1857` recursively calls
    `load_node` for child nodes under the current node's `with_children`
    spawner while passing the accumulated `world_transform`.
- 2026-07-05: Bevy primitive child anchors:
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1620-1667` enters node children,
    iterates mesh primitives, loads an inverted-scale material variant if
    needed, creates `GltfAssetLabel::Primitive { mesh, primitive }`, reads the
    primitive bounding box, and obtains
    `convert_coordinates.mesh_conversion_transform_inverse()`.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1669-1705` spawns a primitive
    child entity with `Mesh3d(label_handle)` and the mesh conversion transform,
    applies skinned-mesh bounds policy, inserts morph-weight reference when
    needed, converts bounds when meshes are rotated, and inserts
    `Aabb::from_min_max`.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1707-1751` inserts primitive,
    mesh, and material extras; `GltfMeshName`; `GltfMaterialName`; `Name` from
    `primitive_name`; optional skin mapping; and runs
    `extension.on_spawn_mesh_and_material`.
  - `bevy/crates/bevy_gltf/src/loader/gltf_ext/mesh.rs:10-18` owns
    `primitive_name`: mesh name plus material name when present, otherwise the
    mesh name or `"Mesh"`.
  - `bevy/crates/bevy_gltf/src/label.rs:33-82` defines the relevant labels:
    `Scene{index}`, `Node{index}`, and `Mesh{mesh}/Primitive{primitive}`.
- 2026-07-05: Bevy light and camera anchors for this asset:
  - `mgstudio-engine/assets/models/VolumetricFogExample/VolumetricFogExample.glb`
    contains scene `Scene` with root nodes `[0, 1]`; node 0 is `Sun` with a
    `KHR_lights_punctual` light extension; node 1 is `Cube` with mesh 0; no
    glTF camera is present.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1569-1612` is still the camera
    import owner for this path, but it is not exercised by this asset because
    no glTF camera exists.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1755-1830` owns glTF light child
    import. Directional lights spawn a child `DirectionalLight` with sRGB color
    and lux illuminance; point and spot lights convert candela to luminous power
    with `4 * pi`; each light child can receive light name, extras, and the
    matching extension hook.
