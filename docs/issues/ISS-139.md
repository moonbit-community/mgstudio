## Description
`examples/ui/text/text_debug` now runs and produces a reference screenshot, but
the Bevy source uses a root `Text::default()` with `TextSpan` children and
`TextUiWriter` updates. Mgstudio maps that source shape, yet the captured image
does not visibly show the final dynamic text block in the bottom-right region.

This must be audited against Bevy's current `bevy/examples/ui/text/text_debug.rs`
and the UI text source owners:

- `bevy/crates/bevy_ui/src/widget/text.rs`
- `bevy/crates/bevy_ui/src/measurement.rs`
- `bevy/crates/bevy_ui/src/layout/mod.rs`
- `bevy/crates/bevy_text/src/pipeline.rs`

## Design
Do not change the example layout heuristically. First compare a fresh Bevy
reference capture with the mgstudio reference, then classify the mismatch as one
of:

- correct Bevy-equivalent overflow/framing,
- a UI text measurement scheduling gap,
- a root `Text` plus child `TextSpan` extraction/layout bug,
- a required-components gap,
- or a screenshot framing issue.

If the mismatch is real, port the corresponding Bevy source-owner behavior
directly.

## Acceptance Criteria

- [ ] `examples/ui/text/text_debug/reference.png` is refreshed only after the source-level cause is resolved or explicitly classified.

## Close Notes
Closed 2026-06-19.

Bevy reference was captured with `cargo +1.95.0 run --example text_debug --release`
and `/tmp/bevy_text_debug_full.png`; Bevy showed the bottom-right dynamic text
block with the root `Text::default()` plus child `TextSpan` structure intact.

Root cause: `mgstudio-engine/ui/ghost_hierarchy.mbt` was not matching Bevy's
`UiChildren` source shape. It treated every non-ghost child as an effective UI
child, while Bevy's iterator only yields children that are `Node` or
`GhostNode`. As a result, plain `TextSpan` child entities entered taffy layout,
the root `Text` node became a parent instead of a measured text leaf, and the
dynamic bottom-right text block collapsed out of the reference image.

Fix:

- Updated main UI ghost hierarchy traversal to skip non-UI children and expose
  root ghost descendants, matching `bevy/crates/bevy_ui/src/experimental/ghost_hierarchy.rs`.
- Kept the example's root `Text` plus child `TextSpan` shape and
  `TextUiWriter` updates unchanged.
- Updated UI tests that had been manually constructing invalid UI children
  without `Node` required components.
- Added a main-path regression test proving ghost children are flattened while
  non-UI children and their subtrees are skipped.
- Refreshed `mgstudio-engine/examples/ui/text/text_debug/reference.png`; the
  bottom-right dynamic text block is now visible.

Source-shape classification:

- `bevy/examples/ui/text/text_debug.rs`: complete for the audited root
  `Text`/`TextSpan`/`TextUiWriter` anchors.
- `bevy/crates/bevy_text/src/text_access.rs`: complete for flattened
  root/span read-write indexing used by this example.
- `bevy/crates/bevy_ui/src/experimental/ghost_hierarchy.rs`: complete for the
  audited `UiChildren` traversal behavior in the main UI path.
- `bevy/crates/bevy_ui/src/widget/text.rs`: partial overall; complete for the
  audited required root text layout shape.
- `bevy/crates/bevy_ui/src/layout/mod.rs`: partial overall; this issue fixed
  the child traversal mismatch that prevented text measurement.
- `bevy/crates/bevy_text/src/pipeline.rs`: partial overall; no pipeline change
  was needed for this issue.
