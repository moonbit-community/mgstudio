## Description
After the pass-order boundary is source-shaped, the renderer draw path must
prove that it consumes the same prepared resources as Bevy's
`volumetric_fog`: view bind group, volumetric fog bind group, dynamic uniform
offsets, depth texture, optional density texture, and hull mesh.

## Design
Audit `bevy_pbr/src/volumetric_fog/render.rs::volumetric_fog` against the
mgstudio renderer path. Add focused tests or instrumentation around draw-entry
construction and backend resource checks. Missing renderer resources should
surface as real errors or precise follow-up issues, not silent skipped draws.

## Acceptance Criteria
- [x] The draw path consumes prepared `ViewVolumetricFog`,
      `ViewVolumetricFogPipelines`, uniform offsets, depth texture, density
      texture, and fog hull mesh ids.
- [x] A focused capture for `examples/3d/scrolling_fog` or
      `examples/3d/atmosphere` emits no volumetric fog missing-resource or
      fatal renderer log.
- [x] Any remaining backend primitive gap is recorded as a separate blocker
      issue with the exact missing API.

## Close Notes
Closed on 2026-07-04.

Bevy source owner:
`bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::volumetric_fog` consumes
`ViewVolumetricFog`, `ViewVolumetricFogPipelines`, `MeshViewBindGroup`,
`ViewDepthTexture`, the dynamic `VolumetricFogUniformBuffer` binding, optional
3D density images, and the Bevy `FogAssets` plane/cube hull meshes.

Mgstudio renderer consumption audit:

- `render3d_draw_volumetric_fog` reads `ViewVolumetricFog` and
  `ViewVolumetricFogPipelines` from the render view entity and converts each
  `ViewFogVolume` into `HostMesh3dVolumetricFogVolume` with
  `density_texture_id`, `uniform_buffer_offset`, and `exterior`.
- `GpuBackend::draw_mesh3d_volumetric_fog` uses the mesh-view bind group as
  group 0, creates the volumetric fog bind group as group 1 from the dynamic
  uniform buffer, depth texture, and optional 3D density texture/sampler, and
  passes `[uniform_buffer_offset]` as the dynamic offset.
- `mesh3d_volumetric_fog_hull_mesh_id` now owns the Bevy
  `exterior ? cube : plane` hull selection and is used by the real draw path.
- `mesh3d_volumetric_fog_bind_group_layout_index` mirrors Bevy bitflags:
  `MULTISAMPLED = 0x1`, `DENSITY_TEXTURE = 0x2`.
- No new backend primitive blocker was found in this slice.
