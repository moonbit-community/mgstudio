## Description
Bevy prepares sampled depth texture usage for volumetric fog and carries
density texture handles, density texture offset, and density texture scale
through `ViewFogVolume` into the pass.

## Design
Audit `prepare_view_depth_textures_for_volumetric_fog` plus density texture
metadata separately from uniform packing. Do not accept fallback textures as
source parity.

## Acceptance Criteria
- [ ] View depth texture usage and binding readiness are classified.
- [ ] Density texture handle lookup and missing-asset behavior are classified.
- [ ] Density texture offset/scale animation inputs are classified.
- [ ] Any fallback texture or late allocation divergence is fixed or filed as
      a narrower ISS.
