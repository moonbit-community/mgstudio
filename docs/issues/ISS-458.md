## Description

The `examples/2d/sprite_slice` validation example currently renders every text
label but no sprite textures. This includes the Original and Stretched cases,
which do not depend on `ComputedTextureSlices`, so the failure is outside the
changed-sprite slice query being evaluated by `ISS-456`.

Fresh native fixed-frame captures at both frame 90 and frame 600 are
byte-identical with SHA-256
`8981b5ccb1d2b478a5f88dcc815bae99b5f497f1df17c7c15f82343c43ddebd4`.
The checked-in reference contains the complete original, stretched, sliced,
tiled, and constrained-corner textures and has SHA-256
`2a4248a89193085e73668f255f11bf8206909e7ea921c455a04b10ceba375549`.
