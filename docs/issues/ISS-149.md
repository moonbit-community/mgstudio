## Description
`ISS-080` fixed the original visual/runtime failure in
`examples/3d/reflection_probes`: the checked-in reference now shows the
skybox/cubes scene and a reflective central sphere. The example is still not
source-complete against Bevy's `examples/3d/reflection_probes.rs`, as recorded
by the symbol audit in `ISS-105`.

This issue tracks the remaining example-source migration, not the concrete PBR
reflection-probe runtime path already completed by `ISS-101`, `ISS-102`, and
`ISS-103`.

## Design
Port the example owner by Bevy source anchors, preserving behavior while
removing local mgstudio-only control flow:

- replace the file-global `Ref[ReflectionProbesState]` with Bevy-shaped
  resources/components where MoonBit can express them;
- preserve `AppStatus`, `Cubemaps`, `SphereMaterial`, and `CubesScene` owner
  roles instead of tracking single entities and handles in local state;
- move camera environment-map insertion toward the
  `Added<Camera3d>`/post-spawn system shape;
- make reflection-mode switching query-driven: remove probes and cube scenes,
  respawn the probe/scene for `ReflectionProbe`, and update every camera as the
  Bevy source does;
- replace the world-space `Text2d` helper with Bevy-shaped UI `Text` plus
  `Node` ownership once the local UI/text API can express that shape;
- keep `GeneratedEnvironmentMapLight` mode honest: if the upstream generation
  owner remains partial, leave a precise dependency or owner relationship
  rather than pretending the example is complete.

Do not change the checked-in visual reference unless a new source-shaped
implementation produces an equivalent or intentionally reviewed output.

## Acceptance Criteria
- [x] Every source anchor from `bevy/examples/3d/reflection_probes.rs` is
      classified as complete, partial, facade, blocked, or intentionally
      excluded after the implementation pass.
- [x] The example no longer uses file-global mutable state to represent Bevy
      resources, components, or query-owned entities where a typed mgstudio ECS
      API can express the source shape.
- [x] Reflection-mode switching follows Bevy's query/despawn/respawn and
      camera component update semantics as closely as MoonBit allows.
- [x] UI/help text ownership is either Bevy-shaped or a precise blocker is

- [x] `GeneratedEnvironmentMapLight` behavior is either source-shaped through
      the PBR generation owner or explicitly related to the existing generation

- [x] The standard 90-frame native capture remains visually valid against
      `mgstudio-engine/examples/3d/reflection_probes/reference.png`.
- [x] Targeted `moon check --release`, `moon fmt`, and `moon info` pass for the
      touched packages.
