## Close Notes
Closed 2026-07-06. Bevy source anchors:
`bevy/examples/3d/fog_volumes.rs` `setup` directional-light spawn,
`setup` camera spawn, and `rotate_camera`; component defaults cross-checked
against `bevy/crates/bevy_light/src/volumetric.rs`.

Anchor mapping:
- Directional light transform: Bevy uses
  `Transform::from_xyz(1.0, 1.0, -0.3).looking_at(vec3(0.0, 0.5, 0.0),
  Vec3::Y)`. Mgstudio `spawn_directional_light` uses the same translation and
  `looking_at(fog_center(), Vec3::Y)`. Status: complete.
- Directional light component: Bevy sets `shadow_maps_enabled: true` and
  `illuminance: 32000.0` with other fields defaulted. Mgstudio starts from
  `DirectionalLight::DirectionalLight()` and applies
  `with_shadow_maps_enabled(true)` and `with_illuminance(32_000.0F)`. Status:
  complete.
- Volumetric light participation: Bevy adds the `VolumetricLight` marker to
  the same light entity. Mgstudio adds `@pbr.VolumetricLight::VolumetricLight()`
  to the same spawned tuple. Status: complete.
- Camera components: Bevy spawns `Camera3d::default`, the transform
  `from_xyz(-0.75, 1.0, 2.0).looking_at(vec3(0.0, 0.0, 0.0), Vec3::Y)`, `Hdr`,
  and `VolumetricFog { step_count: 64, ambient_intensity: 0.0, ..default() }`.
  Mgstudio `spawn_camera` spawns `Camera3d`, the same transform, `Hdr`, and
  `VolumetricFog().with_step_count(64).with_ambient_intensity(0.0F)`. The
  remaining `VolumetricFog` defaults match Bevy: white ambient color, ambient
  intensity overridden to `0.0`, jitter `0.0`, and step count overridden to
  `64`. Status: complete.
- Camera rotation system: Bevy updates every `Transform` with `Camera3d` by
  rotating translation with `Quat::from_rotation_y(0.01)` and then looking at
  `vec3(0.0, 0.5, 0.0)`. Mgstudio `rotate_camera` queries
  `Write[Transform]` with `With[Camera3d]`, applies the same quaternion
  translation step, and calls `looking_at(fog_center(), Vec3::Y)`. Status:
  complete.
