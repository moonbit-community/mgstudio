# ISS-456: Migrate trace-proven dense query hotspots to table batches

## Description

Apply the retained `ISS-449` dense table-batch API to the remaining
performance-sensitive query call sites. A call site is eligible only after a
native trace shows material cost and the batch traversal can preserve its exact
query data, filter, change-detection, deferred-command, and source-owner
semantics.

## Acceptance Criteria

- [x] Every matrix row has a retained, rejected, or externally blocked result.
- [x] Every retained migration preserves the pinned Bevy query/filter and
      change-detection semantics.
- [x] Every retained migration runs one focused test at a time with
      `MOONBIT_NEW_NATIVE=1`.
- [x] Every retained migration uses the row's distinct example for its runtime
      gate and performs a valid visual comparison when the example renders.
- [x] Every retained or rejected call-site experiment is committed separately.
- [x] Unsupported per-row filters are not weakened or evaluated as table-wide
      predicates.
