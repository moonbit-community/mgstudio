## Description
Bevy's `volumetric_fog` example owns a `MoveBackAndForthHorizontally`
component and `move_point_light` system that animate the red point light
between `min_x` and `max_x`, clamping and flipping speed at each boundary.

## Design
Port the component shape and point-light movement logic directly from
`bevy/examples/3d/volumetric_fog.rs`. Do not replace the movement with a local
global timer, entity-handle cache, renderer-side animation, or sinusoidal
approximation.

## Acceptance Criteria
- [x] `MoveBackAndForthHorizontally` carries Bevy's `min_x`, `max_x`, and
      `speed` fields.
- [x] The point light is spawned with Bevy's `min_x = -1.93`, `max_x = -0.4`,
      and `speed = -0.2`.
- [x] `move_point_light` updates `Transform.translation.x`, clamps at both
      bounds, and flips the stored speed exactly like Bevy.
- [x] A focused test covers the non-clamp and boundary-flip cases.
