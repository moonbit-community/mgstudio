## Description
`examples/animation/custom_skinned_mesh` still has a transparent checked-in
`reference.png`. Retrying the standard native capture produced a nonblank image,
but the scene is not source-equivalent to Bevy.

Current Bevy builds ten skinned strip meshes across the X axis, assigns
deterministic random material colors plus `textures/uv_checker_bw.png`, animates
different transforms per joint index, and draws transform gizmo axes for each
animated joint. Mgstudio currently builds a single simplified skinned strip
with two joints and one material. The screenshot therefore cannot be accepted
as a parity reference even though it is numerically nonblank.

## Design
Port the Bevy example source shape directly. Keep the deterministic PRNG,
ten-joint-instance loop, UV checker material, per-index animation cases,
generated skinned mesh bounds, and gizmo axes behavior. Do not accept the
single-strip scene as a reference and do not replace the missing Bevy behavior
with a local animation demo.

## Acceptance Criteria
- [ ] `mgstudio-engine/examples/animation/custom_skinned_mesh/main.mbt`
      matches the current Bevy example structure: ten skinned mesh instances,
      seeded deterministic material colors, texture use, per-index joint
      animation, and transform gizmo axes.
- [ ] Required mesh attributes and indices match Bevy's custom mesh topology,
      joint indices, and joint weights.
- [ ] The standard native capture renders the multi-instance skinned mesh scene
      and no longer produces the simplified single-strip output.
- [ ] The refreshed `reference.png` is accepted only after manual review
      confirms the multi-instance Bevy-shaped scene content.
- [ ] Focused animation/skinning checks and the standard capture run have no
      validation, fatal, missing-resource, unsupported, or error output.

  animation cases, and transform gizmo axes are not yet ported.
