## Description
Bevy updates `DynamicSkinnedMeshBounds` with
`mesh_entities.par_iter_mut()` in
`bevy/crates/bevy_camera/src/visibility/mod.rs::update_skinned_mesh_bounds`.
Mgstudio now has a source-shaped scalar implementation with table-row fast
access, cached joint transform reads, and no dirty-skip shortcut, but it still
runs the per-entity mutable query serially.

The current `many_foxes` release profile at
`/tmp/mgstudio_many_foxes_iss152_direct_finish_aabb3d/frametime_breakdown.md`
reports `mgstudio.visibility.update_skinned_mesh_bounds=5.213 ms/frame` at
`1000` foxes after the local AABB accumulator optimization. Counters show
`22000` joint bounds processed, `22000` joint transform cache hits, `0` misses,
and `1000` AABB writes. This is the Bevy-visible every-frame workload; the
missing capability is safe parallel mutable query execution over disjoint table
rows.

## Design
Do not add feature-local dirty skipping, JSON payload erasure, global fallback
state, or a one-off thread pool inside visibility. The correct owner is ECS:
provide a Bevy-shaped parallel query or table-batch API that can safely split
disjoint mutable rows, expose per-worker local state when needed, merge counters
deterministically, and preserve component change-tick semantics.

The same capability should also unblock `ISS-043` for animation target
evaluation, because Bevy uses `targets.par_iter_mut()` there as well.

## Acceptance Criteria
- [ ] ECS exposes a safe Bevy-shaped parallel mutable query or table-batch API
      for disjoint component rows.
- [ ] `update_skinned_mesh_bounds` uses that API without changing Bevy's
      every-frame recompute semantics.
- [ ] Per-worker diagnostics/counters merge deterministically without global
      mutable fallback state.
- [ ] Component mutation records the same write/change-tick semantics as the
      scalar path.
- [ ] `many_foxes` reports
      `mgstudio.visibility.update_skinned_mesh_bounds < 3 ms/frame` at `1000`
      foxes on the current development machine, or a more specific language or
      runtime blocker is recorded with exact evidence.
- [ ] Relevant ECS, mesh, camera/primitives, and camera/visibility release tests
      pass.
