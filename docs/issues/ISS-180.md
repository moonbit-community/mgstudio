## Description
Bevy runs volumetric fog after the main 3D pass and before early postprocess.
Mgstudio needs the same pass ordering once extracted state, pipeline state,
uniforms, and depth usage are source-shaped. This issue is now the group ticket
for the smaller pass-order execution slices.

## Design
Do not implement this as one broad change. Close the child issues in order:

- ISS-187 records and verifies the Bevy Core3d pass-order boundary.
- ISS-188 moves the mgstudio execution boundary to an explicit post-main
  volumetric fog step.
- ISS-189 verifies the renderer draw-entry/resource consumption path at that
  boundary.

## Acceptance Criteria
- [x] ISS-187, ISS-188, and ISS-189 are closed.
- [x] The pass executes after the main 3D pass and before bloom, tonemapping, and other early postprocess effects.
- [x] The pass consumes prepared `ViewVolumetricFog`, pipeline ids, uniform buffer offsets, depth texture, and density texture resources.
- [x] Renderer logs show no volumetric fog missing-resource or fatal output for a focused atmosphere/scrolling_fog capture.
