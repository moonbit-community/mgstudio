# ISS-020: Unblock exact Bevy meshlet visibility-buffer runtime under native WebGPU limits

## Description
Mgstudio has ported much of Bevy's meshlet asset, processor, storage-buffer,
descriptor, material-id, and material-shade planning surface. Runtime meshlet
visibility remains unavailable because exact Bevy visibility-buffer resources
need behavior beyond the portable WebGPU C ABI shape used by the current native
MoonBit rendering stack.

This is no longer tracked as an open `wgpu_mbt` repository issue. The historical
upstream requests were closed, and the remaining question is whether mgstudio
can obtain an exact Bevy-equivalent native path for `R64Uint` atomic storage
textures and the related pipeline-layout requirements, or whether the meshlet
runtime must stay blocked until the underlying native/WebGPU ABI surface can
express those resources.

## Design
Keep the blocker explicit and do not claim runtime parity until the exact
Bevy visibility-buffer resource shape is available. Do not rewrite the meshlet
algorithm to a different visibility-buffer representation as a local parity
claim. Once an exact native path exists, remove the runtime-unavailable path and
wire Bevy's visibility buffer, material shade pass, and mesh shader capability
checks into the renderer.

## Acceptance Criteria
- [ ] The native MoonBit rendering stack can create the exact Bevy visibility-buffer texture/access combination: `TextureFormat::R64Uint` plus atomic storage texture access for `texture_storage_2d<r64uint, atomic>`.
- [ ] The native MoonBit rendering stack can express bind-group layouts and `IMMEDIATES` or push-constant ranges in the same descriptor shape required by Bevy.
- [ ] Mesh shader capability reporting is available or explicitly mapped to Bevy's adapter requirement checks.
- [ ] Mgstudio removes the meshlet runtime-unavailable gate once dependency support exists.
- [ ] The meshlet example renders with Bevy-equivalent visibility buffer and material-shade output.
- [ ] The roadmap blocker is closed or updated with exact dependency, ABI, or local integration evidence.
