# ISS-020: Unblock exact Bevy meshlet visibility-buffer runtime

## Metadata

- External ref: moonbit-community/wgpu-mbt#22

## Description
Mgstudio has ported much of Bevy's meshlet asset, processor, storage-buffer,
descriptor, material-id, and material-shade planning surface. Runtime meshlet
visibility remains unavailable because exact Bevy visibility-buffer resources
need WebGPU native-extension behavior that is not exposed through the current
MoonBit dependency stack.

## Design
Keep the blocker explicit and do not claim runtime parity until the exact ABI is
available. Once upstream support exists, remove the runtime-unavailable path and
wire Bevy's visibility buffer, material shade pass, and mesh shader capability
checks into the renderer.

## Acceptance Criteria
- [ ] `wgpu_mbt` can create the exact Bevy visibility-buffer texture/access combination: `TextureFormat::R64Uint` plus atomic storage texture access for `texture_storage_2d<r64uint, atomic>`.
- [ ] `wgpu_mbt` exposes a pipeline layout API that can express bind-group layouts and `IMMEDIATES` or push-constant ranges in the same descriptor shape required by Bevy.
- [ ] Mesh shader capability reporting is available or explicitly mapped to Bevy's adapter requirement checks.
- [ ] Mgstudio removes the meshlet runtime-unavailable gate once dependency support exists.
- [ ] The meshlet example renders with Bevy-equivalent visibility buffer and material-shade output.
- [ ] The roadmap blocker is closed or updated with exact upstream issue references.
