## Description

`QueryData` currently combines access declaration, archetype matching, fetch
planning, table-row fetching, sparse fetching, and the returned row item in one
`Self` type. Prototype the minimum separation needed for persistent query state
and typed table fetch state.

## Acceptance Criteria

- [ ] The design explicitly maps query specification, state, table fetch, and
      item responsibilities to the pinned Bevy query owner.
- [ ] The prototype preserves tuple, optional, `Has`, sparse-set, and change
      filter semantics required by the selected test surface.
- [ ] One focused ECS query test runs at a time with
      `MOONBIT_NEW_NATIVE=1`.
- [ ] `examples/stress_tests/many_components` is the only runtime example gate.
- [ ] The retained/rejected decision follows the `ISS-444` experiment protocol.
