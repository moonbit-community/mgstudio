## Description
The raw mgstudio WGSL assets may match Bevy, but the runtime executes the
composed shader after import resolution. `scrolling_fog` directional shadow
sampling cannot be accepted until the composed `volumetric_fog.wgsl` import
closure is captured and checked against Bevy's source-owner graph.

## Design
Use the same shader loader/composer path that the native renderer uses for
`pbr/volumetric_fog/volumetric_fog.wgsl`. Record a focused artifact or test
asserting that the composed source contains the Bevy directional-light,
shadow-sampling, mesh-view, and volumetric-fog helper code paths and no local
shader rewrite. Do not patch WGSL source to satisfy the test; if composition
cannot preserve Bevy source shape, open or reference an external blocker.

## Acceptance Criteria
- [x] The composed runtime shader has no unresolved `#import` directives.
- [x] The composed source includes Bevy's directional light scattering loop and
      imported directional shadow visibility helpers.
- [x] The artifact or focused test identifies the exact shader path and loader
      entry used by the renderer.
- [x] Any WGSL composition limitation is recorded as a precise external blocker
      instead of being hidden behind a local rewrite.
