# ISS-314: Insert Bevy-shaped primitive AABB components during scene spawn

- Updated: 2026-07-05

## Description
After primitive bounds are available on the scene node, mgstudio must insert the
runtime AABB component used by visibility and render extraction in the same
source-shaped place where Bevy inserts `Aabb`.

## Design
Compare Bevy's primitive child spawn component set with mgstudio's scene
spawner and visibility component keys. Port the AABB write into the owning scene
spawn path, preserving the Bevy data flow from glTF primitive bounds to runtime
component. Do not add renderer-local fallback bounds or culling heuristics.

## Acceptance Criteria
- [x] Mgstudio runtime AABB component type and ECS key are identified.
- [x] Mgstudio scene-spawn component insertion site is mapped.
- [x] Primitive scene nodes with bounds insert the runtime AABB component.
- [x] Nodes without glTF primitive bounds keep the Bevy-equivalent absence
      behavior or record a blocker if this cannot be represented.
