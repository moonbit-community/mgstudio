## Description
`examples/3d/lines/reference.png` can now serve as a nontransparent visual
baseline, but the example is not source-level faithful to Bevy. Bevy's
`examples/3d/lines.rs` demonstrates a custom 3D line material:
`MaterialPlugin::<LineMaterial>`, a `LineMaterial` asset with a uniform color,
`shaders/line_material.wgsl`, `PrimitiveTopology::LineList`, and
`PrimitiveTopology::LineStrip` with explicit indices containing `u16::MAX` as a
primitive restart marker.

Mgstudio's current example uses unlit `StandardMaterial` as a substitute and
does not preserve Bevy's custom material owner or indexed primitive-restart line
strip shape. That is a local approximation and must not be counted as render or
example source parity.

## Design
Port Bevy `examples/3d/lines.rs` as a source-shaped custom material example:

- add a real `LineMaterial` asset owner with color uniform data;
- register the equivalent of `MaterialPlugin<LineMaterial>`;
- embed and bind `shaders/line_material.wgsl`;
- preserve `LineList` and `LineStrip` mesh construction, including primitive
  topology and the `u16::MAX` primitive restart index;
- remove the unlit `StandardMaterial` substitute from this example once the
  custom material path exists.

If mgstudio lacks a required generic material plugin or custom material
pipeline API, record the exact engine/API blocker instead of keeping the
standard-material approximation.

## Acceptance Criteria
- [ ] Every source-shape anchor in Bevy `examples/3d/lines.rs` is classified as
      complete, partial, facade, blocked, or intentionally excluded.
- [ ] `LineMaterial` is a real custom material with the same shader and uniform
      ownership shape as Bevy's example.
- [ ] The line-list and line-strip meshes preserve Bevy's primitive topology and
      primitive-restart indexed strip behavior.
- [ ] The standard-material substitute is removed from the example or replaced
      by a precise blocker note.
- [ ] `examples/3d/lines/reference.png` remains visually valid after the source
      parity fix.
