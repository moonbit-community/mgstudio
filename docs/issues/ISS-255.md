## Description
Bevy selects volumetric-fog shader behavior through pipeline specialization
definitions. If mgstudio's `scrolling_fog` pass composes the correct WGSL text
but uses the wrong shader definitions, directional shadows, density textures,
MSAA depth handling, or atmosphere branches can diverge silently.

## Design
Audit Bevy `bevy_pbr/src/volumetric_fog/render.rs` pipeline specialization
against the mgstudio pipeline key and shader-def construction used by
`scrolling_fog`. Verify the definitions that select density texture sampling,
directional shadow filtering, MSAA/depth variants, and atmosphere integration.
Keep this as pipeline-specialization evidence, separate from shader body math.

## Acceptance Criteria
- [x] `DENSITY_TEXTURE` is enabled only for the textured fog-volume variant used
      by `scrolling_fog`.
- [x] The directional shadow filter definition matches Bevy's hardware 2x2 path
      for the active renderer capabilities.
- [x] MSAA, depth, and atmosphere shader definitions match Bevy for the active
      `scrolling_fog` camera/pass.
- [x] A focused test or note records the actual mgstudio pipeline key values
      used to derive those definitions.

## Close Notes
Closed on 2026-07-05.

Audited Bevy
`bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::VolumetricFogPipeline::specialize`.
The Bevy specialization always starts with
`SHADOW_FILTER_METHOD_HARDWARE_2X2`, then adds `MULTISAMPLED` from
`MeshPipelineViewLayoutKey::MULTISAMPLED`, `ATMOSPHERE` from
`MeshPipelineViewLayoutKey::ATMOSPHERE`, and `DENSITY_TEXTURE` only when the
pipeline key has `has_density_texture`.

Added a focused `examples/3d/scrolling_fog` white-box gate:
`scrolling_fog: volumetric fog shader defs mirror Bevy active pipeline key`.
The test derives the active example conditions from the real app world:

- one camera with `Msaa::Off`;
- no `Atmosphere` component;
- one `FogVolume` with a density texture;
- textureless pipeline key shader defs:
  `["SHADOW_FILTER_METHOD_HARDWARE_2X2"]`;
- textured pipeline key shader defs:
  `["SHADOW_FILTER_METHOD_HARDWARE_2X2", "DENSITY_TEXTURE"]`;
- both bind-group layout keys are non-MSAA, and only the textured key has the
  density-texture bit.

Validation:

```sh
moon -C mgstudio-engine test examples/3d/scrolling_fog --target native --release --filter '*volumetric fog shader defs mirror Bevy active pipeline key*'
```

Result: `Total tests: 1, passed: 1, failed: 0.`
