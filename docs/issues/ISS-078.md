## Description
`examples/ui/render_ui_to_texture` still has a fully transparent checked-in `reference.png`. A standard native capture run succeeds, but the generated image is effectively black instead of a usable render-to-texture reference.

## Design
Audit the example and the render-to-texture/UI camera path against the current Bevy source owner before accepting a refreshed reference. This is not an external dependency blocker: the capture script can build and run the example, so any local approximation or missing data-flow must be fixed in mgstudio code.

## Notes
- 2026-06-12: Standard capture command succeeded but produced a nearly black image. Sanity report failed all default checks: `non_black_ratio=0.0`, `mean_luma=1.740816117713533`, `center_mean_luma=1.7943516295573618`. The generated image was discarded.
- 2026-06-14: Claimed for source-shape diagnosis against
  `bevy/examples/ui/render_ui_to_texture.rs` and the mgstudio
  `examples/ui/render_ui_to_texture` package.
- 2026-06-14: Root cause was in the renderer path, not the example reference
  file itself. `Assets<Image>::add(Image::new_target_texture(...))` allocated
  a GPU render target in the asset layer, but the 2D render runtime only knew
  target sizes from its private `render2d_create_render_target` registry. The
  UI camera therefore lacked computed render target information for the
  Bevy-shaped asset image target, and the texture sampled by the cube stayed
  effectively black.

## Close Notes
Closed on 2026-06-14. The 2D render runtime now resolves image render target
size and format through the render texture facade when the camera target is an
asset image, so Bevy-shaped target texture assets can drive offscreen UI
passes. The example target texture, offscreen camera marker, UI layout, panel
layout, drag sizing, and directional light setup were also tightened against
`bevy/examples/ui/render_ui_to_texture.rs`.

Validation:
- `moon -C mgstudio-engine check --target native --deny-warn --package-path render`
- `moon -C mgstudio-engine check --target native --deny-warn --package-path render/texture`
- `moon -C mgstudio-engine check --target native --deny-warn --package-path sprite_render/render`
- `moon -C mgstudio-engine check --target native --deny-warn --package-path examples/ui/render_ui_to_texture`

`extrema=((60,189),(115,189),(158,212),(255,255))`,
`mean_luma=145.652`. A full reference scan after this refresh reports
120 fully transparent references and 4 near-black references.
