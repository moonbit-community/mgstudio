## Description
`examples/window/monitor_info` failed screenshot capture while most other window
examples produced reference screenshots. This package likely reports monitor
metadata rather than visual content, but the behavior needs explicit
classification.

Failed package:

- `examples/window/monitor_info`

## Design
Inspect the package source and run log. If the package is metadata-only,
exclude it from screenshot capture and document the correct validation method.
If it opens a visual window, make the capture path produce `reference.png`.

## Close Notes

Closed 2026-06-19. `monitor_info` is screenshot-required: Bevy's
`examples/window/monitor_info.rs` opens one fullscreen window per monitor and
renders monitor metadata as UI text. The mgstudio example now follows that
shape by spawning a per-monitor window, camera-targeted UI text, and monitor
removal cleanup without mutating ECS structurally inside query iteration.

The capture failure exposed a runner-level gap: with `primary_window: None`,
the first `Update` can enqueue logical windows before native host windows exist.
The winit runner must keep the event loop alive while such logical windows are
awaiting host creation instead of exiting on zero native windows immediately.

Validation:

- `moon -C mgstudio-engine check --target native examples/window/monitor_info`
- `moon -C mgstudio-engine test --release winit`
