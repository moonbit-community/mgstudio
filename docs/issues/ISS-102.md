## Description
`ISS-101` completed the concrete runtime path for reflection probes and
irradiance volumes, but `bevy/crates/bevy_pbr/src/light_probe/mod.rs` still owns
several render-resource and scheduling anchors that mgstudio only approximates
through the current camera execute path.

The remaining source-owner gap is not the light-probe data layout itself. It is
where that data lives and when it is written: Bevy stores all view probe data in
`LightProbesBuffer`, inserts `ViewLightProbesUniformOffset` on each render-world
view, and runs `gather_light_probes` / `upload_light_probes` in the render app
using Bevy render systems.

## Design
Move the light-probe upload ownership toward Bevy's render-resource model
without changing the already verified runtime semantics:

- map `LightProbesBuffer(DynamicUniformBuffer<LightProbesUniform>)` to an
  mgstudio render resource with equivalent per-view uniform ownership;
- attach a `ViewLightProbesUniformOffset`-equivalent component to each
  render-world camera/view instead of treating the uniform bytes as pass-local
  backend state only;
- represent `gather_light_probes::<EnvironmentMapLight>`,
  `gather_light_probes::<IrradianceVolume>`, and `upload_light_probes` as
  named systems or source-owner functions that match Bevy's data flow and
  schedule placement as closely as MoonBit allows;
- keep the concrete behavior from `ISS-101`: visible-cluster filtering,
  distance sorting, texture-index mapping, reflection/irradiance counts, and
  real cluster indices must not regress.

## Acceptance Criteria
- [x] `LightProbesBuffer` and `ViewLightProbesUniformOffset` are no longer
      facade-only anchors; they own data used by the render path.
- [x] Light-probe upload is represented as Bevy-shaped render-resource work,
      not only as ad hoc bytes passed during camera main-pass execution.
- [x] Reflection probe and irradiance volume white-box tests still pass.
- [x] `examples/3d/pccm` capture remains pixel-equivalent to its checked-in
      reference.
- [x] `moon check --release`, targeted tests, `moon fmt`, and `moon info` pass
      for the touched packages.
