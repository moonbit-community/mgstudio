## Description
TAA history textures and pipelines, Bloom mip resources and pipelines, Tonemapping caches, and AutoExposure compute/view resources retain persistent native handles.

## Design
Add complete aggregate/cache-entry release operations, fix runtime eviction/replacement paths, and connect this temporal/exposure owner group to backend shutdown.

## Acceptance Criteria
- [x] TAA histories, samplers, layouts, and pipeline cache entries are released.
- [x] Bloom mip views/texture, samplers, buffers, layouts, and pipelines are released.
- [x] Tonemapping and AutoExposure caches and per-view resources are released.
- [x] Native WGPU report coverage returns representative handles to baseline.
