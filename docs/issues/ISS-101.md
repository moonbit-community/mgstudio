## Description
`examples/3d/pccm` now uses Bevy's `LightProbe + EnvironmentMapLight +
ParallaxCorrection` source shape, but the reflective inner cube remains flat
gray. The root cause is in mgstudio's PBR light-probe owner, not the example:
`pbr/light_probe/top.mbt` currently exposes data types and plugin resources,
while the render path only forwards environment maps attached directly to the
camera into pass state.

Bevy's `bevy_pbr/src/light_probe/mod.rs` gathers visible probes per view,
builds `RenderViewLightProbes<EnvironmentMapLight>`, uploads a
`LightProbesUniform` containing reflection-probe arrays, and writes real
reflection-probe indices into cluster bindings. Mgstudio currently writes
`0xFFFF_FFFF` for reflection-probe cluster entries and never uploads real
per-view reflection-probe data, so PCCM cannot render Bevy-style reflection
probes.

## Design
Port the Bevy light-probe source owner before accepting PCCM visual parity:

- map Bevy `RenderLightProbe`, `LightProbesUniform`,
  `ViewLightProbesUniformOffset`, `LightProbeInfo`, and
  `RenderViewLightProbes<EnvironmentMapLight>` into mgstudio's package split;
- gather in-scope `LightProbe + EnvironmentMapLight + ParallaxCorrection`
  entities for each 3D camera/view using Bevy's transform, distance sorting,
  parallax bounds, falloff, intensity, and flags semantics;
- bind both diffuse and specular cubemap arrays for view environment maps and
  reflection probes without falling back to camera-attached environment maps;
- replace the placeholder `0xFFFF_FFFF` reflection-probe cluster indices with
  the per-view render probe indices;
- keep PCCM as the representative visual gate.

Do not workaround this by attaching the PCCM environment map directly to the
camera. That would only exercise Bevy's view environment-map path and would not
port reflection probes.

## Acceptance Criteria
- [ ] Every in-scope source-shape anchor in
      `bevy/crates/bevy_pbr/src/light_probe/mod.rs` and
      `bevy/crates/bevy_pbr/src/light_probe/environment_map.rs` is classified
      as complete, partial, facade, blocked, or intentionally excluded.
- [x] `LightProbe + EnvironmentMapLight + ParallaxCorrection` entities affect
      PBR materials without also attaching `EnvironmentMapLight` to the camera.
- [x] Cluster reflection-probe entries carry real per-view probe indices rather
      than `0xFFFF_FFFF` placeholders.
- [x] `examples/3d/pccm` capture shows the reflective inner cube and remains
      source-shaped after the fix.
- [ ] Relevant `moon check --release`, targeted tests, `moon fmt`, and
      `moon info` pass.
