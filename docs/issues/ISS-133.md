## Description
Bevy examples such as `bevy/examples/3d/contact_shadows.rs` rely on
`MeshPickingPlugin` plus entity-scoped `Pointer<Drag>`, `Pointer<Over>`,
`Pointer<Out>`, and `Pointer<DragEnd>` observers. The drag observer exposes
`event.delta`, which the example uses to rotate the FlightHelmet model while
also switching the primary window cursor between `Grab`, `Grabbing`, and
`Default`.

Mgstudio currently exposes pointer enter/leave/down/up/click/move observer
kinds and `PointerEvent` carries pointer id, kind, position, and target, but it
does not expose Bevy-shaped drag or drag-end observer kinds, drag delta payloads,
or a public `MeshPickingPlugin` registration surface that can be mirrored by
examples.

## Design
Extend the picking/input observer layer with Bevy-shaped mesh picking and drag
observer semantics. This should be implemented in the engine/picking API, not as
example-local mouse polling, keyboard fallback, or cursor-only approximation.
Once available, update `examples/3d/contact_shadows` to use the exact
FlightHelmet drag/over/out/dragend observer chain from the Bevy owner.

## Acceptance Criteria
- [x] A public mesh picking plugin surface exists for examples that maps to
      Bevy's `MeshPickingPlugin` role.
- [x] Pointer observer kinds include Bevy-shaped `Drag` and `DragEnd`
      equivalents.
- [x] Drag events expose a delta equivalent to Bevy `event.delta`.
- [x] Entity-scoped observers can register for drag and drag-end through
      `EntityCommands`.
- [x] `examples/3d/contact_shadows` uses these observers for FlightHelmet
      rotation and drag cursor updates without keyboard, polling, or local
      fallback behavior.

## Close Notes
Closed on 2026-06-19. `PointerEventKind` now includes `DragStart`, `Drag`, and
`DragEnd`, pointer events carry Bevy-shaped `delta` and `distance` vectors, and
`PickingState` tracks press and drag positions so primary-button pointer motion
emits drag start, drag, and drag-end events. `OnPointer` exposes `delta()` and
`distance()`, and `EntityCommands::observe_pointer*` can register drag and
drag-end observers through the existing pointer observer registry.

`picking/mesh_picking` now exposes a public `MeshPickingPlugin` compatibility
surface and `MeshPickingCamera` marker. The plugin does not duplicate runtime
systems because mgstudio currently installs mesh hit testing through the shared
`PickingPlugin` path in `DefaultPlugins`.

`examples/3d/contact_shadows` now adds `MeshPickingPlugin` and uses
FlightHelmet entity-scoped `Pointer<Drag>`, `Pointer<Over>`, `Pointer<Out>`,
and `Pointer<DragEnd>` observers to rotate the scene root and update the
primary-window cursor without keyboard, polling, or local fallback behavior.
