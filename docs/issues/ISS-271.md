## Description
Bevy `setup_camera_fog` attaches camera render components including
`AtmosphereSettings`, `Exposure`, `Tonemapping`, `Bloom`,
`AtmosphereEnvironmentMapLight`, `VolumetricFog`, `Msaa::Off`, TAA, and SSR.

## Design
Audit the mgstudio atmosphere camera against Bevy's exact component set and
values. Do not count a visually plausible sky or water image as complete if
camera render components diverge.

## Acceptance Criteria
- [ ] Camera transform and render component set are classified.
- [ ] Exposure, tonemapping, bloom, atmosphere environment map light, and SSR
      settings are classified.
- [ ] Camera `VolumetricFog`, MSAA, and TAA settings are classified.
- [ ] Any remaining divergence is fixed or filed as a narrower ISS.
