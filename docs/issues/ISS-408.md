# ISS-408: Eliminate native render resource leaks

## Description
The native renderer owns manually released `wgpu_mbt` handles, but several replacement and shutdown paths currently discard those handles without releasing them. Repeated SSAO configuration changes, atmosphere or scattering LUT recreation, cube-texture replacement, and render-backend replacement can therefore retain native GPU resources for the remainder of the process.

## Design
Use `defer` for resources whose lifetime is bounded by one lexical scope. Give every cross-frame aggregate an explicit idempotent release operation, release the previous aggregate before replacement, and add a complete renderer-backend shutdown boundary. Preserve Bevy-shaped resource ownership and do not introduce heuristic cleanup based on frame age.

## Acceptance Criteria
- [x] Lexically scoped native descriptors are released with `defer` on success and error paths.
- [x] Every affected cross-frame resource aggregate releases all handles before replacement.
- [x] Cube-texture replacement releases the complete previous texture record.
- [x] Renderer backend replacement and shutdown release all backend-owned native handles.
- [x] Native leak regression tests cover repeated replacement paths.
- [x] All MoonBit validation commands run with `MOONBIT_NEW_NATIVE=1`.
