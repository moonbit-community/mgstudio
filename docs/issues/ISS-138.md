## Description
`bevy/examples/showcase/breakout.rs` always adds the local
`stepping::SteppingPlugin`, positioned at `percent(35), percent(50)`. In Bevy
without `bevy_debug_stepping`, that plugin still renders an explanatory overlay.
The current mgstudio `examples/games/breakout` migration restores the gameplay,
collision, scoreboard, sprite, and audio source shape, but does not yet wire the
showcase stepping overlay into the example.

## Design
Port the showcase stepping helper as a reusable example-local or shared helper
that matches Bevy's `examples/showcase/stepping.rs` behavior. Do not fake the
overlay with static text in breakout, and do not treat the absence of the overlay
as an external blocker: mgstudio already has core schedule stepping state in
`app/stepping.mbt`, so this is a local source-parity task.

## Acceptance Criteria
- [ ] `examples/games/breakout` wires a Bevy-shaped stepping plugin/helper at
      the same Update schedule and UI position as the Bevy source.
- [ ] The no-debug-stepping overlay behavior is represented faithfully for
      mgstudio's available stepping feature set.
- [ ] The implementation reuses or cleanly factors existing
      `examples/showcase/stepping` and `app/stepping` code instead of adding a
      breakout-specific approximation.
- [ ] `examples/games/breakout/reference.png` is refreshed after the overlay is
      intentionally included or the issue explicitly documents why the checked
      reference should remain overlay-free.
