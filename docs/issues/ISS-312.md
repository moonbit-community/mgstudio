## Description
Mgstudio must apply the same glTF mesh conversion semantics as Bevy for the
`VolumetricFogExample.glb` Cube primitive: mesh vertex data conversion,
primitive child local transform, and any inverse conversion transform.

## Design
Compare the Bevy anchors from ISS-311 with mgstudio's glTF loader,
coordinate-conversion helpers, and `SceneNode3d` construction. If the transform
path diverges, fix it in the owning fragment using Bevy as the source of truth.
Do not compensate through camera movement, asset edits, render-time overrides,
or screenshot-only changes.

## Acceptance Criteria
- [x] Mgstudio file paths and line anchors for mesh vertex conversion are
      listed.
- [x] Mgstudio file paths and line anchors for primitive child transform
      creation are listed.
- [x] The Cube primitive's conversion transform is proven Bevy-aligned or the
      exact divergence is fixed here.
- [x] Any remaining unfixable divergence is assigned to ISS-305 with exact
      source-owner evidence.

## Notes
- 2026-07-05: Split from ISS-309 so transform conversion can be verified
  before primitive bounds are blamed for render-space differences.
- 2026-07-05: Mgstudio source anchors after repair:
  - `mgstudio-engine/gltf/loader/top.mbt:93-156` defines
    `GltfConvertCoordinates`, `gltf_convert_coordinates_vec3`,
    `gltf_convert_coordinates_quat`, `gltf_convert_coordinates_vec4`,
    `scene_conversion_transform`, `mesh_conversion_transform`, and
    `mesh_conversion_transform_inverse`.
  - `mgstudio-engine/gltf/convert_coordinates.mbt:16-35` exposes the same
    vector/quaternion conversion helpers from the public `@gltf` package used by
    the scene loader.
  - `mgstudio-engine/scene/gltf_loader.mbt:117-130` carries glTF primitive
    position, normal, tangent, UV, joint, custom-attribute, morph-target,
    index, material, and extras accessors in `GltfPrimitiveDef`.
  - `mgstudio-engine/scene/gltf_loader.mbt:1456-1530` parses primitive
    `POSITION`, `NORMAL`, `TANGENT`, `TEXCOORD_0`, `TEXCOORD_1`, `JOINTS_0`,
    and `WEIGHTS_0` attributes. `TANGENT` is excluded from custom attributes,
    matching Bevy's standard-attribute handling.
  - `mgstudio-engine/scene/gltf_loader.mbt:3319-3335` converts morph target
    vec3 position, normal, and tangent displacements when `rotate_meshes` is
    enabled.
  - `mgstudio-engine/scene/gltf_loader.mbt:3468-3635` builds primitive mesh
    assets. Positions, normals, and tangents are converted when
    `rotate_meshes` is enabled; UVs, joints, weights, and custom vec3
    attributes are not coordinate-converted, matching ISS-311's Bevy anchor.
  - `mgstudio-engine/scene/gltf_loader.mbt:3649-3658` resolves loader
    coordinate settings and computes `mesh_entity_transform` from
    `mesh_conversion_transform_inverse()`.
  - `mgstudio-engine/scene/gltf_loader.mbt:3960-4006` creates each primitive
    `SceneNode3d` with `Mesh3d`, material, and the shared
    `mesh_entity_transform`, so the Cube primitive identified in ISS-308 uses
    the same Bevy-shaped primitive child transform path.
- 2026-07-05: Fixed local divergence: mgstudio previously parsed morph target
  tangents but not the primitive `TANGENT` vertex attribute itself. Bevy
  converts primitive tangents through `convert_attribute` when
  `rotate_meshes` is enabled. Mgstudio now parses `TANGENT`, converts it via
  `gltf_convert_coordinates_vec4`, and stores it on `Mesh3dGeometry`.
- 2026-07-05: Source-shape classification:
  - `GltfConvertCoordinates` helper mapping: complete for the ISS-311 anchors.
  - Primitive mesh asset coordinate conversion: complete for positions,
    normals, tangents, and morph target vec3 displacements.
  - Primitive child inverse mesh transform: complete at source level; runtime
    Cube value proof remains assigned to ISS-315.
  - Primitive bounds/AABB conversion: intentionally not classified here; owned
    by ISS-313 and ISS-314.
