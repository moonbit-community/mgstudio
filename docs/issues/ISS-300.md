## Description
`examples/3d/volumetric_fog` is dominated by a near gray/white surface, but the
current tracker does not name the concrete mesh, entity, depth contributor, or
render phase item responsible. Without that evidence, fixes risk becoming
camera or screenshot workarounds.

## Design
Add temporary or test-only diagnostics as needed to identify the actual
mgstudio contributor rendered over the frame. The evidence should connect a
visible pixel/depth contribution back to the ECS scene entity, mesh/material
asset, and render phase item. Keep diagnostics out of production behavior.

Do not change camera placement, assets, fog settings, or render ordering while
collecting this evidence.

- [x] The render phase or depth path that draws the contributor is recorded.
- [x] Any diagnostic code is removed, test-only, or otherwise clearly scoped.
