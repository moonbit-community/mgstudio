## Description
Effect stack, custom postprocess, skybox, CAS, blit, screenshot, FXAA, TAA, bloom, tonemapping, auto exposure, SSAO, atmosphere, scattering medium, deferred lighting, SSR, and light-probe generation all own persistent native resources.

## Design
Complete three independently verified child tasks for general post-processing, temporal/exposure processing, and advanced PBR features. Add or reuse release operations for each feature aggregate and cache entry, preserve the feature modules as source owners, and invoke the area teardown from backend shutdown.

## Acceptance Criteria
- [x] Every listed post-processing feature releases layouts, pipelines, buffers, bind groups, samplers, textures, and views it owns.
- [x] Existing SSAO, atmosphere, and scattering-medium release operations are integrated into shutdown.
- [x] Optional and cached feature resources are drained without double release.
- [x] Native WGPU report coverage exercises representative feature owners.
