## Description
Even with correct scene import and material data, mgstudio can diverge from
Bevy if mesh extraction, camera-relative transforms, visibility filtering,
phase binning, or depth pass routing differs for the identified contributor.

## Design
Compare Bevy PBR mesh extraction, visibility, and render phase queueing against
mgstudio PBR/render fragments for the contributor found in ISS-300. Focus on
`GlobalTransform` to render-world conversion, view visibility, render layers,
main pass/depth pass inclusion, and phase item ordering.

Do not introduce heuristic draw suppression. If the contributor is genuinely
visible under Bevy semantics, close with evidence and leave the root cause to a
different child issue.
