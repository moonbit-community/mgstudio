## Description
Map the mgstudio fragments that implement the Bevy glTF scene/node import
anchors identified by ISS-306. This must include the loader-time `SceneNode3d`
shape, scene root placement, node hierarchy, primitive child creation, and
component payloads stored before runtime spawning.

## Design
Compare `mgstudio-engine/scene/gltf_loader.mbt`, `SceneNode3d`, and directly
used helper functions against the Bevy anchors from ISS-306. Keep this issue to
static source mapping; runtime ECS proof belongs to ISS-308 and bounds proof
belongs to ISS-309.

## Acceptance Criteria
- [x] Mgstudio source paths and symbols for scene root import are listed.
- [x] Mgstudio source paths and symbols for node hierarchy and transform import
      are listed.
- [x] Mgstudio source paths and symbols for primitive mesh/material child
      creation are listed.
- [x] Any source-shape divergence from ISS-306 is recorded with an owner issue:

      repair issue, or marked as a true blocker only if MoonBit or an external

## Notes
- 2026-07-05: Split from ISS-301 so local loader mapping can be reviewed after
  the Bevy owner map is explicit.
- 2026-07-05: Mgstudio static source map for loader-time scene/node import:
  - `mgstudio-engine/scene/scene.mbt:16-46` defines `SceneNode3d`, the
    loader-time payload used before ECS spawning. It can carry name, parent
    scene-node index, mesh/material, camera, lights, glTF scene/node/mesh/
    primitive/skin metadata, glTF extras, transform, visibility range,
    animation target/root data, skin data, and morph weights.
  - `mgstudio-engine/scene/scene.mbt:49-164` defines `SceneNode3d::new` for
    mesh primitive nodes and `SceneNode3d::new_empty` for scene roots, glTF
    nodes, light children, and camera-bearing nodes.
  - `mgstudio-engine/scene/scene.mbt:167-203` defines `Scene`, including the
    `nodes3d` array and optional scene extras.
- 2026-07-05: Mgstudio helper mapping for Bevy scene/node import anchors:
  - `mgstudio-engine/scene/gltf_loader.mbt:2475-2481` maps unnamed node names
    to `GltfNode{index}`, matching Bevy's `node_name` fallback.
  - `mgstudio-engine/scene/gltf_loader.mbt:2702-2717` selects
    `GltfConvertCoordinates` from loader settings and defaults.
  - `mgstudio-engine/gltf/loader/top.mbt:93-152` defines coordinate
    conversion, scene conversion transform, mesh conversion transform, and mesh
    conversion inverse. This mirrors Bevy's split between scene-root conversion
    and mesh-instance conversion.
  - `mgstudio-engine/scene/gltf_loader.mbt:2736-2797` maps glTF camera
    projection and active-camera selection into `Camera`, `Camera3d`, and
    `Projection` payloads.
  - `mgstudio-engine/scene/gltf_loader.mbt:2800-2872` maps
    `KHR_lights_punctual` light data into light child payloads, including lux
    directional intensity and `4 * pi` point/spot intensity conversion.
- 2026-07-05: Mgstudio loader map for `scene_build_from_gltf`:
  - `mgstudio-engine/scene/gltf_loader.mbt:3639-3710` selects the glTF scene,
    scene extras, coordinate conversion, skinned bounds policy, mesh conversion
    transform, node paths, animation roots, image/material/skin caches, and
    camera load state.
  - `mgstudio-engine/scene/gltf_loader.mbt:3775-3835` is the local equivalent
    of Bevy `load_node` node entity creation: it guards cycles through
    `visited_nodes`, computes negative-scale material inversion state, creates
    a `SceneNode3d::new_empty` with local node transform, parent index, name,
    `GltfSceneIndex`, `GltfNodeIndex`, optional skin index, extras, camera
    payload, and animation data.
  - `mgstudio-engine/scene/gltf_loader.mbt:3836-3851` creates an explicit
    identity-transform light child `SceneNode3d` under the glTF node when
    lights are enabled and the node has a parsed light.
  - `mgstudio-engine/scene/gltf_loader.mbt:3853-4008` creates one
    `SceneNode3d::new` primitive child per mesh primitive, after building the
    mesh asset, material component, primitive name, extras, mesh/material
    names, skin payload, and morph weights. The primitive child uses
    `mesh_entity_transform` from coordinate conversion and is parented to the
    glTF node scene-node index.
  - `mgstudio-engine/scene/gltf_loader.mbt:4025-4032` recursively walks child
    glTF nodes under the current node; `mgstudio-engine/scene/gltf_loader.mbt:
    4035-4063` appends the scene root node with scene conversion transform,
    scene name, `GltfSceneIndex`, and scene extras, then walks the selected
    scene root nodes under it.
  - `mgstudio-engine/scene/gltf_loader.mbt:947-956` owns primitive display
    naming: mesh name plus material name when present, otherwise mesh name or
    `"Mesh"`, matching Bevy's `primitive_name` shape.
  - `mgstudio-engine/scene/gltf_loader.mbt:3237-3263` owns scale-inversion
    and cull-mode selection used while building material variants.
  - `mgstudio-engine/scene/gltf_loader.mbt:3468-3635` owns mesh primitive asset
    construction and applies coordinate conversion to positions, normals, and
    morph-target vectors when `rotate_meshes` is enabled.
- 2026-07-05: Mgstudio runtime materialization map:
  - `mgstudio-engine/scene/scene_spawner.mbt:447-535` materializes a ready
    `Scene` by pre-spawning one ECS entity per `SceneNode3d`, resolving each
    node parent from `parent_node_index` or the external scene root entity.
  - `mgstudio-engine/scene/scene_spawner.mbt:536-646` inserts `Parent`,
    `Transform`, inherited `Visibility`, `Name`, glTF metadata/extras, camera,
    projection, and light components from each `SceneNode3d`.
  - `mgstudio-engine/scene/scene_spawner.mbt:647-735` inserts mesh,
    material, morph target, skin-pending, visibility-range, animation player,
    animation target, and `AnimatedBy` components.
  - `mgstudio-engine/scene/scene_spawner.mbt:736-753` notifies glTF loader
    extensions after node and mesh primitive spawn using the spawned entity.
- 2026-07-05: Source-shape differences routed to child issues:
  - Bevy inserts `Aabb::from_min_max` on primitive child entities during
    `load_node`; the current `SceneNode3d` and `scene_spawner` mapping above
    has no explicit primitive AABB payload. This remains assigned to ISS-309,
    which owns primitive bounds and mesh conversion parity.
  - Mgstudio primitive child nodes currently carry extra runtime metadata
    (`GltfNodeIndex`, `GltfMeshIndex`, and `GltfPrimitiveIndex`) and extension
    notification hooks, while the Bevy primitive child anchor in ISS-306 mainly
    inserts primitive/mesh/material extras, mesh/material names, `Name`, AABB,
    mesh, material, and skin/morph data. This must be classified in ISS-308's
    runtime hierarchy and metadata proof before claiming source-level
    alignment.
