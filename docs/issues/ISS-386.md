## Description
Prove that the real `examples/3d/volumetric_fog` directional light exposes the
same cascade count, cascade ordering, and directional shadow depth texture base
index that Bevy would expose to volumetric fog.

## Design
Use the owner map from ISS-385 and the directional light evidence from
ISS-377. Compare the real example's `num_cascades`, cascade ordering, and
`depth_texture_base_index` against the Bevy source expressions that pack
directional light GPU data for shadowed volumetric lighting. Do not inspect
matrix contents here; that belongs to ISS-387.

## Close Notes
Closed on 2026-07-05 after adding focused real-example scalar/base-index
evidence in `mgstudio-engine/examples/3d/volumetric_fog/main_wbtest.mbt`.

Bevy source expressions audited:

- `bevy/crates/bevy_pbr/src/render/light.rs::prepare_lights` counts directional
  cascades from `light.cascade_shadow_config.bounds.len().min(MAX_CASCADES_PER_LIGHT)`.
- The same loop enables the shadow flag only when
  `num_directional_cascades_enabled_for_this_view + cascades <=
  max_texture_array_layers`.
- `GpuDirectionalLight.num_cascades` is the enabled cascade count.
- `GpuDirectionalLight.depth_texture_base_index` is
  `num_directional_cascades_enabled_for_this_view` before the current light's
  cascade count is added.
- The later directional-shadow loop zips `cascades`, `frusta`, and
  `cascade_shadow_config.bounds`, so cascade ordering follows the source
  cascade array and the ordered bound array.
- `bevy/crates/bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl` consumes the
  scalar base through `array_index =
  (*light).depth_texture_base_index + cascade_index`.

Mgstudio evidence:

- Added test
  `volumetric_fog: directional shadow cascade scalar inputs match Bevy order`.
- The test runs the real `examples/3d/volumetric_fog` app setup plus
  `tweak_scene`, `move_directional_light`, `move_point_light`, and
  `adjust_app_settings` for six updates.
- It records the real fog pass counter
  `render_3d_volumetric_fog_view_shadow_binding_resources`, which is emitted
  only when the pass receives a valid directional shadow texture id and
  `cascade_count > 0`.
- It reads the render-world `Render3dLightingState` and `GpuLights3d`, then
  asserts one directional light, one real cascade entry list, source cascade
  count equal to `directional_cascade_bounds.length()`,
  `GpuDirectionalLight.num_cascades` equal to that source cascade count,
  `depth_texture_base_index == 0`, and strictly increasing cascade bounds.
- The existing test
  `volumetric_fog: directional and ambient GPU lights match Bevy prepare_lights`
  continues to assert that the real example's GPU directional light copies the
  Bevy-shaped cascade count, overlap, and base index.
- Strengthened the existing runtime pass-local test to assert
  `render_3d_volumetric_fog_view_shadow_binding_resources` explicitly, so the
  directional shadow binding path is covered separately from the broader
  directional/spot texture resource counter.
