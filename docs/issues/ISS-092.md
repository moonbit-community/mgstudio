## Description
`examples/3d/skybox` still has a transparent checked-in `reference.png`.
Retrying the standard native capture produced a numerically nonblank but
visually unusable dark frame instead of Bevy's visible Ryfjallet cubemap
skybox.

Current Bevy owns this path through `bevy_core_pipeline/src/skybox/mod.rs`
and `bevy_light/src/probe.rs::Skybox`: the plugin extracts `Skybox`, prepares
`SkyboxUniforms`, specializes a dedicated skybox render pipeline, validates a
cube texture view, prepares a bind group, and draws the skybox with the
core-3d depth format. Mgstudio currently stores the component in `pbr` and
draws a skybox proxy mesh through the generic mesh3d host path.

## Design
Port the Bevy skybox source owner directly instead of accepting a dark
reference image or patching the example. The implementation should map the
current Bevy `SkyboxPlugin`, extraction, uniforms, pipeline specialization,
bind-group preparation, cube texture validation, and draw ordering into
mgstudio owners. If MoonBit or wgpu_mbt cannot express an exact fragment,
record that as a precise blocker before leaving any local fallback in place.

## Acceptance Criteria
- [x] Every Bevy source-shape anchor in `bevy_core_pipeline/src/skybox/mod.rs`
      is classified as complete, partial, facade, blocked, or intentionally
      excluded.
- [x] `bevy_light/src/probe.rs::Skybox` maps to the mgstudio component owner
      without a PBR-only facade claiming complete source parity.
- [x] `examples/3d/skybox` renders a visible cubemap skybox through the
      standard native capture command and no longer produces a uniform dark
      frame.
- [x] The refreshed `examples/3d/skybox/reference.png` is accepted only after
      manual review confirms visible skybox/environment texture signal.
- [x] Focused render/PBR checks and the standard capture run have no
      validation, fatal, missing-resource, unsupported, or error output.
- [ ] The remaining skybox draw ownership is moved from renderer-local host
      draw logic into Bevy-shaped `SkyboxPlugin` render-app phase/node
      ownership.
