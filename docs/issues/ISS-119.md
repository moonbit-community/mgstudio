## Description
`examples/3d/parallax_mapping` exercises the parallax render feature, but it is
not a symbol-level port of Bevy's `bevy/examples/3d/parallax_mapping.rs`.

The current implementation keeps many important runtime values: parallax depth,
layer and method controls, texture paths, ground material, cube positions,
spin speeds, and camera view positions. The strict gaps are source-shape issues:
Bevy's `Spin` and `FreeCameraController` components, local system state,
material asset queries, camera marker query, child light marker, `TextSpan`
hierarchy, `TextUiWriter` span updates, tangent-generation anchors, and static
camera transform table are replaced by a global `ParallaxState`, tracked
handles, direct world mutation, full-string text replacement, and helper
functions.

There is also a concrete behavior mismatch: Bevy uses quaternion `slerp` for
camera rotation interpolation, while the local implementation uses normalized
linear interpolation.

## Design
Port the example directly from the Bevy source owner. Keep only local changes
that are required by concrete MoonBit language/API limitations, and record each
such limitation as a precise blocker. Do not keep global state, tracked handles,
direct world mutation, local text replacement, or local primitive generation as
the parity path when the Bevy source has a specific owner.

## Acceptance Criteria
- [x] `Spin` is represented as an ECS component and `spin` uses a
      Bevy-shaped query over transforms and spin components.
- [x] `FreeCameraController` is represented as an ECS marker component and
      `move_camera` uses a Bevy-shaped single camera query.
- [x] `TargetDepth`, `TargetLayers`, and `CurrentMethod` are represented with
      Bevy-shaped local system state semantics or precise local-state blockers.
- [x] `CurrentMethod` display text and `next_method` transition order preserve
      the Bevy source owner.
- [x] `main` preserves Bevy's startup/update system set shape instead of
      folding all parallax controls into one local system.
- [x] `update_parallax_depth_scale`, `switch_method`, and
      `update_parallax_layers` use Bevy-shaped keyboard, material asset query,
      local state, text writer, and text entity parameters where possible.
- [x] Camera movement uses source-equivalent quaternion `slerp`, not nlerp.
- [x] `CAMERA_POSITIONS` is represented as a source-shaped transform table.
- [x] The light marker uses `Sphere::new(0.05).mesh().ico(3).unwrap()` as a
      child of the point light, or records precise primitive/children blockers.
- [x] The point light preserves Bevy's struct/default semantics, not local
      explicit intensity/range defaults, unless those constructor defaults are
      proven equivalent.
- [x] Main and background cubes preserve the Bevy cuboid mesh plus
      `with_generated_tangents().unwrap()` anchors or record a precise
      mesh/tangent blocker.
- [x] The four background cubes reuse the source-shaped generated mesh handle
      and bundle/closure structure where possible.
- [x] Help text uses UI `Text`, `Node`, `TextSpan` children, and `TextUiWriter`
      span updates rather than world-space text and full-string replacement.
- [x] `ParallaxState`, tracked camera/material/text/spin handles, local nlerp,
      and local text formatting scaffolding are removed from the source-parity
      path unless precise blockers are documented.
- [x] The reference screenshot is refreshed after the source-shaped port still
      renders correctly.
