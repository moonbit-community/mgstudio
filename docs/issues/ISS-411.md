# ISS-411: Release superseded atmosphere GPU resources

## Metadata
- Type: bug
- Status: closed
- Priority: 0
- Labels: render, pbr, atmosphere, native, memory-leak
- Assignee: unassigned
- Created: 2026-07-12
- Updated: 2026-07-12
- External ref: none

## Description
Atmosphere LUT shape changes replace a large aggregate of textures, views, buffers, samplers, bind-group layouts, pipeline layouts, and pipelines without releasing the previous aggregate.

## Design
Give `GpuAtmosphereResources` a complete release operation and release the prior aggregate only after the replacement has been constructed successfully.

## Acceptance Criteria
- [x] Every handle owned by superseded atmosphere resources is released exactly once.
- [x] Failed replacement construction leaves the previous atmosphere resources usable.
- [x] Native WGPU report coverage proves repeated shape replacement has bounded live handles.
