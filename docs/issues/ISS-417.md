## Description
GPU preprocessing, meshlet visibility/culling/raster/resolve/downsample resources, and motion-vector caches form a large independent family of buffers, bind groups, layouts, textures, samplers, and pipelines.

## Design
Follow the existing preprocessing, meshlet, and motion-vector owner boundaries as three independently verified child tasks; add exact aggregate release operations and attach each area teardown to backend shutdown.

## Acceptance Criteria
- [ ] Preprocessing pipelines, layouts, bind groups, depth-pyramid resources, and upload states are released.
- [ ] Meshlet persistent buffers, per-view maps, culling/raster/resolve/downsample resources, and pipelines are released.
- [ ] Motion-vector layouts, pipelines, view caches, slots, and instance resources are released.
- [ ] Native WGPU report coverage exercises representative resources from all three groups.
