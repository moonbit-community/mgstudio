## Description
`examples/3d/custom_system_setup3/reference.png` is fully transparent. A standard 90-frame native capture produced an opaque image, but the visual result was only the default dark background with no visible scene content.

The generated image passed the current luma-based sanity script because the background is not near black, so this example exposes a false positive class for empty captures.

## Design
Audit the example against its intended source owner before refreshing the checked-in reference. The fix should identify whether the missing content is caused by example setup, schedule/system registration, camera framing, asset loading, or render extraction.

Do not accept a non-transparent background-only capture as a valid visual reference.

## Acceptance Criteria
- [ ] `examples/3d/custom_system_setup3` captures visible scene content, not only the clear color.
- [ ] The example setup and schedule path are audited against the source owner.
- [ ] The refreshed `reference.png` is produced by `mgstudio-engine/scripts/p0_visual_capture_native.sh`.
- [ ] ISS-060 is updated after the reference is refreshed or the example is reclassified.
