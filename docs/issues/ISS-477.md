## Description

The Bevy source owners `bevy_gizmos/src/gizmos.rs`, `config.rs`,
`simplex_stroke_font.rs` and `stroke_text.rs` were implemented inside
`mgstudio-engine/sprite`, a package whose Bevy counterpart `bevy_sprite`
contains none of those files. `Gizmos` itself was `@sprite.Gizmos`.

The correspondingly named files under `mgstudio-engine/gizmos` were facades:

| File | mgstudio before | Bevy owner |
| --- | ---: | ---: |
| `gizmos.mbt` | 34 lines (3 forwarding fns) | `gizmos.rs`, 952 |
| `simplex_stroke_font.mbt` | 43 lines (4 consts) | `simplex_stroke_font.rs`, 1414 |
| `stroke_text.mbt` | 48 lines (forwards to `@sprite`) | `stroke_text.rs`, 347 |
| `lib.mbt` | 25 re-export aliases to `@sprite` | `lib.rs`, 363 |

This was a **Runtime Owner Semantics** violation rather than a runtime gap:
`examples/gizmos/3d_text_gizmos` already matched the pinned Bevy output.

`mgstudio-engine/sprite/text2d.mbt` was misfiled in the same way. All 175 lines
of it were stroke-text code; `bevy_sprite/src/text2d.rs` contains zero
stroke-text or gizmo references.

## Design

Move the owners into `mgstudio-engine/gizmos` under Bevy-aligned names, then
delete the re-export bridge. Analysis before the move confirmed the code was
fully self-contained: zero symbols referenced in either direction between the
moving files and the remaining `bevy_sprite`-owned files.

Moved: `sprite/gizmo.mbt` to `gizmos/gizmos.mbt`; `sprite/simplex_stroke_font.mbt`
to `gizmos/simplex_stroke_font.mbt`; `sprite/gizmo_config.mbt` into
`gizmos/config.mbt`; `sprite/stroke_text.mbt` and `sprite/text2d.mbt` into
`gizmos/stroke_text.mbt`; `sprite/gizmo_3d_wbtest.mbt` and
`sprite/stroke_text_wbtest.mbt` into `gizmos/`.

Deleted: the 25 `pub type X = @sprite.X` aliases plus the `init_gizmo_group`
and `gizmo()` forwarders in `gizmos/lib.mbt` and `gizmos/global.mbt`, which
became self-referential once the real definitions lived in the same package.
The three mgstudio-invented `sprite_stroke_text_*` bridge wrappers were dropped;
they existed only to cross the package boundary that no longer exists.

### Package cycle

Moving the owners created
`light -> gizmos -> camera -> pbr -> ui_render -> ui -> text -> sprite_render ->
sprite_render/render -> core_pipeline -> light`.

Resolved per the split-packages rule rather than by changing runtime semantics:
`gizmos` only used `@camera.Aabb` and `@camera.Frustum`, and both are really
owned by the leaf package `camera/primitives` (`camera` merely re-exports them
via `pub using @primitives`). `gizmos` now imports `camera/primitives` directly.

## Notes

Still open in this area, deliberately out of scope for this move:

- `gizmos/retained.mbt` holds 1986 lines against an 85-line Bevy owner
  (`retained.rs`); drawing logic that belongs to `arcs.rs`, `circles.rs`,
  `grid.rs`, `rounded_box.rs`, `arrows.rs`, `cross.rs` and `curves.rs` is
  pooled there.
- `gizmos/transform_gizmo.mbt` is still a 15-line comment against a 768-line
  Bevy owner.
- `GizmoBuffer::text_sections` and `text_sections_2d` are not implemented.
- `Isometry2d` is defined in `gizmos/gizmos.mbt`; Bevy owns it in `bevy_math`.
- `mgstudio-engine/sprite` has no port of the real `bevy_sprite/src/text2d.rs`
  (`Text2d` rendering) now that the misfiled stroke-text file has moved out.
