## Close Notes
Closed 2026-07-06. Bevy source owner:
`bevy/examples/3d/fog_volumes.rs`.

Scene and hierarchy anchors:
- `main`: builds `App`, installs `DefaultPlugins` with window title, inserts
  `GlobalAmbientLight::NONE`, registers `setup` in `Startup`, and registers
  `rotate_camera` in `Update`.
  Mgstudio fragment: `mgstudio-engine/examples/3d/fog_volumes/main.mbt`
  `fog_volumes_app`, `setup_global_ambient_light`, `setup`, and
  `rotate_camera`. Status: complete for scene/hierarchy ownership. Window
  branding intentionally uses mgstudio naming.
- `setup`: calls `commands.spawn` three times. The spawned entities are all
  root-level entities: fog volume, directional light, and camera. There is no
  parent/child hierarchy in the Bevy example.
  Mgstudio fragment: `spawn_fog_volume`, `spawn_directional_light`, and
  `spawn_camera`, each calling `commands.spawn` once. Status: complete.
- Fog-volume transform anchor:
  `Transform::from_xyz(0.0, 0.5, 0.0)`.
  Mgstudio fragment: `spawn_fog_volume` uses
  `Transform::from_xyz(0.0F, 0.5F, 0.0F)`. Status: complete for hierarchy and
  transform placement. FogVolume fields and density texture are owned by
  ISS-333.
- Directional-light transform anchor:
  `Transform::from_xyz(1.0, 1.0, -0.3).looking_at(vec3(0.0, 0.5, 0.0), Vec3::Y)`.
  Mgstudio fragment: `spawn_directional_light` uses the same translation and
  target via `fog_center()`. Status: complete for hierarchy and transform
  placement. Light component fields are owned by ISS-334.
- Camera transform anchor:
  `Transform::from_xyz(-0.75, 1.0, 2.0).looking_at(vec3(0.0, 0.0, 0.0), Vec3::Y)`.
  Mgstudio fragment: `spawn_camera` uses the same translation, target, and up
  vector. Status: complete for initial hierarchy and transform placement.
  Camera component fields and rotation behavior are owned by ISS-334.

No local scene/hierarchy approximation was found in this issue's scope; no new
