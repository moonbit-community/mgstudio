## Description
`examples/3d/auto_exposure/reference.png` is fully transparent. A standard 90-frame native capture now produces an opaque image, but the result is not a useful reference: only a small wall panel is visible at the left edge and the center of the image is black.

The captured image fails `visual_image_sanity.py` with `mean_luma=2.0091820854261915`, `center_mean_luma=1.103512881727655`, and `center_non_black_ratio=0.0`.

## Design
Audit `mgstudio-engine/examples/3d/auto_exposure/main.mbt` against `bevy/examples/3d/auto_exposure.rs` before refreshing the checked-in reference. The fix should account for the Bevy source owner shape:

- camera with `AutoExposure` and `Skybox`,
- dim wall-box geometry with the front slot,
- point light and zero ambient light,
- compensation curve and metering mask resources,
- UI image/text overlay behavior,
- update controls for camera rotation and auto-exposure toggles.

Do not accept a merely non-transparent screenshot as a valid reference until the visible output is useful and source-shaped.

## Acceptance Criteria
- [x] `examples/3d/auto_exposure` captures visible scene content at normal reference scale.
- [x] The example source shape is audited against Bevy's `examples/3d/auto_exposure.rs`.
- [x] The refreshed `reference.png` passes `mgstudio-engine/scripts/visual_image_sanity.py` or has a documented intentional-dark-scene review note.
- [x] ISS-060 is updated after the reference is refreshed or the example is reclassified.
