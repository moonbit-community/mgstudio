## Description
Even if the directional shadow pass renders the pillar, volumetric fog will not
show the expected light shaft unless the pass samples the same shadow target and
cascade metadata from the same camera/light frame. This issue proves the frame
identity between the rendered shadow target and the volumetric fog binding.

## Design
Track this through smaller leaf issues instead of mixing source audit, unit
proof, and runtime evidence in one task:

- ISS-246 audits the Bevy and mgstudio source-owner frame-data path.
- ISS-247 adds a focused frame-identity test for target id, layer, and cascade
  metadata.
- ISS-248 proves the scrolling_fog volumetric pass consumes the same current
  frame shadow binding at runtime.

This group does not audit shader sampling math; ISS-214 handles that after this
input identity is proven.

## Acceptance Criteria
- [ ] The source-owner frame-data path is audited and recorded in ISS-246.
- [ ] Focused test coverage is added and passing in ISS-247.
- [ ] Runtime scrolling_fog evidence is captured in ISS-248.
- [ ] The rendered directional shadow target id/layer/cascade index is the one
      bound to the volumetric fog pass for the same camera/light frame.
- [ ] Any remaining mismatch is fixed source-faithfully or recorded as a
