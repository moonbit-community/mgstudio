## Description
After the volumetric fog owner, extraction, pipeline, and prepared data are
source-shaped, mgstudio still must run the pass in Bevy's order: after the main
3D pass and before bloom, tonemapping, and other early postprocess stages. The
final acceptance surface is visual: `scrolling_fog`, `volumetric_fog`,
`fog_volumes`, and `atmosphere` must no longer rely on approximations or emit
volumetric fog renderer fatals.
