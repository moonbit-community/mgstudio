## Description
Prove the actual shader and pipeline variants exercised by
`examples/3d/volumetric_fog`, instead of relying only on static source
inspection. The evidence should identify the MSAA, atmosphere,
shadow-filtering, and density-texture state that the real example reaches.

## Design
Use existing white-box counters or add narrowly scoped evidence at the
Bevy-shaped owner boundary that prepares volumetric-fog pipelines. Do not use
renderer draw-loop counters in app-level tests unless the evidence path is
actually visible there. The test should prove the runtime variant that matters
for this example and should not mutate camera, fog, light, or asset content.

## Acceptance Criteria
- [x] The real example proves textureless and/or density-textured pipeline
      variant preparation as Bevy requires.
- [x] The real example proves MSAA and atmosphere shader-def values.
- [x] The real example proves the shadow-filtering shader-def value.
- [x] Any runtime variant divergence is linked to ISS-370 for final assignment.
