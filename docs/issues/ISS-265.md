## Description
Bevy's `volumetric_fog` runtime includes `tweak_scene`,
`move_directional_light`, and `move_point_light`. These systems make glTF
directional lights volumetric, rotate directional lights from keyboard input,
and animate the red point light between two x positions.

## Design
Use the child issues for executable work:

- ISS-286 ports `MoveBackAndForthHorizontally` and `move_point_light`.
- ISS-287 ports `move_directional_light`.
- ISS-288 ports `tweak_scene`.
- ISS-289 validates the integrated movement/tweak behavior with focused tests
  and a native capture.

Preserve Bevy's key handling, speed, clamping, speed sign flip behavior, and
component insertion semantics.
