## Description
Prove that mgstudio renders the real `examples/3d/volumetric_fog` fog pass
into the same target format, sample count, resolve path, and load/store state
that Bevy uses.

## Design
Use the owner map from ISS-381. Compare the Bevy render target and pass
descriptor against mgstudio for:

- color target identity and format;
- sample count and MSAA resolve behavior;
- load and store operations;
- depth attachment absence or presence as required by Bevy;
- whether the pass reads the same depth texture it expects while writing to the
  same color target.

## Acceptance Criteria
- [ ] Bevy target and load/store source expressions are cited in close notes.
- [ ] The corresponding mgstudio runtime values are asserted or recorded for
      the real example.
- [ ] Any divergence is assigned to ISS-375 with exact owner and field name.
- [ ] If no divergence is found, close with evidence that rules out target
      format and load/store state.
