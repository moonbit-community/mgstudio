## Description
Bevy's volumetric fog module extracts `VolumetricFog`, `FogVolume`, and
`VolumetricLight`, syncs `FogVolume` entities into the render world, and clears
render-side state when no volumetric lights are present. Mgstudio needs a
source-level audit for that data flow before final visual acceptance.

## Design
Use this issue as the parent for extraction/sync audits:

- ISS-276 audits extracted `VolumetricFog` view copy and stale-component
  cleanup.
- ISS-277 audits `FogVolume` sync/render-world entity ownership.
- ISS-278 audits `VolumetricLight` extraction and no-light cleanup behavior.

## Acceptance Criteria
- [x] ISS-276, ISS-277, and ISS-278 are closed.
- [x] Any remaining non-Bevy-shaped extraction/sync path has a follow-up ISS or
      is fixed in this slice.
