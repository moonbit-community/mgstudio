## Close Notes

Closed on 2026-07-15 with the primary-source report
[MoonBit `#valtype` and `MutArrayView` enforcement capabilities](../research/ecs-b-valtype-mutarrayview.md).
The current toolchain cannot express a generic `#valtype` constraint or infer
deep immutability, and a raw `MutArrayView` cannot intercept tracked writes or
prevent escaped aliases. An mgstudio-owned indexed view can preserve assignment
syntax while recording row-level changes and enforcing a runtime lease. Exact
API-enforced component eligibility requires a restricted generated schema or a
new compiler-known constraint. Validation used `MOONBIT_NEW_NATIVE=1` for one
native check and one native test command; all four focused runtime tests passed.
