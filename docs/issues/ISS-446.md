# ISS-446: Separate value-only and change-aware component reads

## Description

Current `Read[T]` construction eagerly loads added tick, changed tick, changed
caller, and derived flags even when the system only reads the component value.
Test a Bevy-shaped value-only read boundary distinct from change-aware `Ref<T>`
semantics.

## Acceptance Criteria

- [ ] The API distinction is mapped to pinned-Bevy `&T` and `Ref<T>` semantics.
- [ ] Value-only table reads do not load change metadata in the measured kernel.
- [ ] Change-aware reads preserve existing tick and caller behavior.
- [ ] One focused ECS test runs at a time with `MOONBIT_NEW_NATIVE=1`.
- [ ] `examples/stress_tests/many_cubes` is the only runtime example gate.
- [ ] The retained/rejected decision follows the `ISS-444` experiment protocol.
