## Description
`examples/3d/mirror/reference.png` can now serve as a nontransparent visual
baseline, but the example is not source-level faithful to Bevy. The current
MoonBit source explicitly notes that Bevy-only features like `ExtendedMaterial`
and `Camera::invert_culling` are represented by closest available runtime
behavior. That is a local approximation and must not be counted as PBR/render
source parity.

Bevy's `examples/3d/mirror.rs` uses a second camera rendering into an image,
`ExtendedMaterial<StandardMaterial, ScreenSpaceTextureExtension>`,
`shaders/screen_space_texture_material.wgsl`, an emissive texture sampled in
screen space, mirror-camera projection updates, and inverted culling for the
reflected camera. Mgstudio needs the same source shape or precise blockers for
any truly unavailable engine/API pieces.

## Design
Audit and port Bevy `examples/3d/mirror.rs` as a source-shaped mirror example:

- implement the `ScreenSpaceTextureExtension` material extension and its WGSL
  shader binding path;
- register the equivalent custom material plugin rather than using a standard
  material approximation;
- preserve mirror render-target image creation and resize semantics;
- implement or precisely block `Camera::invert_culling` for mirror cameras;
- preserve mirror camera transform/projection updates and UI drag-action flow.

Do not keep the current "closest runtime behavior" approximation as completed
parity. If `ExtendedMaterial`, custom material extension specialization, or
camera culling inversion cannot yet be expressed, record the exact blocker and
the deletion condition for any temporary local path.

## Acceptance Criteria
- [ ] Every source-shape anchor in Bevy `examples/3d/mirror.rs` is classified as
      complete, partial, facade, blocked, or intentionally excluded.
- [x] The mirror surface uses a real custom material extension with
      `screen_space_texture_material.wgsl`.
- [x] The mirror camera supports Bevy-equivalent inverted culling or a precise
      blocker records the missing engine/API capability.
- [ ] The approximation note in `examples/3d/mirror/main.mbt` is removed or
      replaced with precise blocker references.
- [ ] `examples/3d/mirror/reference.png` remains visually valid after the source
      parity fix.
