## Description
Bevy `examples/3d/volumetric_fog.rs` starts by spawning a
`WorldAssetRoot` for
`models/VolumetricFogExample/VolumetricFogExample.glb`. Mgstudio must use the
same authored scene root instead of local corridor/proxy geometry.

## Design
Compare Bevy `setup` against `mgstudio-engine/examples/3d/volumetric_fog`.
Port the scene asset root and remove proxy geometry from the parity path. Do
not replace missing assets with generated meshes.

## Acceptance Criteria
- [x] The example loads `models/VolumetricFogExample/VolumetricFogExample.glb`
      through the source-shaped asset root.
- [x] Local corridor/proxy geometry is removed from the parity path.
- [x] A focused run or capture proves the scene root resolves without
      missing-resource output.
