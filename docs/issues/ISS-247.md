## Description
Add focused test coverage that proves mgstudio's directional shadow pass target
identity is preserved from pass preparation into the data later consumed by the
volumetric fog path. The test should catch stale, previous-frame, or
mismatched-layer shadow binding bugs without relying on a screenshot.

## Design
Use the source-owner path audited in ISS-246. Prefer a PBR white-box test that
constructs a known camera/light/cascade setup and asserts that the directional
shadow binding texture id, phase shadow target id, target layer, cascade index,
and retained view identity all describe the same current frame.

## Acceptance Criteria
- [ ] A focused PBR test asserts directional shadow binding texture id matches
      each rendered shadow phase view target id.
- [ ] The test asserts target layer and cascade index agree for every cascade.
- [ ] The test asserts retained-view or queued-phase identity cannot mix a
      stale camera/light frame.
- [ ] The relevant `moon -C mgstudio-engine test ... --target native --release`
      command passes.
