## Description
The identified contributor's glTF material may import correctly while still
specializing to a different PBR pipeline state in mgstudio. This issue owns the
PBR material specialization slice only.

## Design
Compare Bevy's PBR material specialization and mesh pipeline key construction
against mgstudio. Focus on cull mode, alpha mode, depth write, depth compare,
blend state, unlit handling, normal-map flags, and any mesh/material key bit
that can affect whether the gray/white contributor dominates the frame. Do not
re-audit glTF material parsing here; that is ISS-316.

## Acceptance Criteria
- [x] Bevy source anchors for PBR material specialization and relevant mesh
      pipeline key construction are listed.
- [x] Mgstudio fragments implementing those anchors are listed.
- [x] The identified contributor's culling, alpha, depth, and blend state are
      compared against Bevy semantics.
- [x] Any local divergence is fixed here or assigned to ISS-305 with exact
      source-owner evidence.
