# ISS-455: Unblock generic value-type query row wrappers

## Description

Pinned Bevy represents query row items such as `&T`, `Ref<T>`, and `Mut<T>` as
borrowed, monomorphized values that do not require one heap allocation per
component per entity. Mgstudio's corresponding `Read[T]`, `ReadValue[T]`, and
`Write[T]` are generic MoonBit structs. On the current MoonBit toolchain,
generic structs cannot be annotated with `#valtype` when they contain their
type parameter, so the existing source-shaped query API cannot obtain the same
stack/value representation.

This blocks complete removal of per-row query-wrapper allocation without an
API change. Reusing one mutable wrapper across rows is not an acceptable local
substitute because MoonBit callers can retain a wrapper after the callback;
reuse would silently retarget that value to another entity and weaken current
query semantics.

## Design

Resolve this in the MoonBit language/runtime by allowing a monomorphized generic
value type whose fields obey the ordinary value-type restrictions. Do not add
unsafe wrapper reuse, hidden global row state, component-specific generated
wrappers, or a C-side erased payload as an mgstudio workaround.

### EXT-455: MoonBit rejects generic value types with a type-parameter field

- Dependency: the MoonBit compiler/toolchain active on 2026-07-15.
- Missing capability: a generic `#valtype` struct containing `T`, after
  monomorphization.
- Bevy requirement: borrowed query row items remain value-like and allocation
  free while retaining static component types.
- Blocked mgstudio owners: `ecs/query_data.mbt` `Read[T]` and `ReadValue[T]`,
  plus `ecs/entity_access.mbt` `Write[T]`.
- Minimum reproduction: add `#valtype` immediately before
  `pub struct ReadValue[T]`, then run
  `MOONBIT_NEW_NATIVE=1 moon -C mgstudio-engine check ecs --target native`.
- Current result: compiler error 4173 at `priv value : T`:
  `Value type is not allowed for type with type parameter as field (including
  type parameter behind a newtype).`
- Verification expectation: the reproduction checks successfully and generated
  native C contains no `moonbit_malloc` for a `ReadValue[ConcreteComponent]`
  row item.
- Local substitute implementation: not allowed for the existing query API.
- Upstream/community link: not filed.

## Acceptance Criteria
