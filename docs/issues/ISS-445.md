## Description

Hot world-parameter systems construct `@ecs.Query` values during every run even
though the app system-parameter path already owns persistent `QueryCache`
state. Test whether moving the pinned-Bevy visibility queries to registered
query system parameters removes measurable per-frame planning and cache setup.

## Design

- Use the existing typed `SystemParam for Query[D, F]` path; do not add global
  caches or world-id keyed static state.
- Preserve the exact visibility query shape, ordering, and two-bit
  `ViewVisibility` lifecycle.
- Measure only `examples/stress_tests/many_foxes` for the runtime gate.
- Revert production code if the epic retention gate is not met.

## Acceptance Criteria

- [x] A pre-change `many_foxes` trace records the affected visibility system

- [x] A focused app query-system-parameter test passes with

- [x] The same `many_foxes` trace shape records the post-change result.

- [x] Query and visibility semantics remain aligned with the pinned Bevy source.

## Close Notes

Rejected and reverted on 2026-07-15 because the measured improvement did not
meet the retention gate.

- Before: `/tmp/mgstudio_iss445_query_cache_before_20260715/frametime_breakdown.md`
  reported `61.738 ms/frame`, `16.197 FPS`, reset at `4.276 ms`, mark-hidden at
  `1.918 ms`, and the unchanged CPU visibility system at `16.288 ms`.
- After: `/tmp/mgstudio_iss445_query_cache_after_20260715/frametime_breakdown.md`
  reported `60.903 ms/frame`, `16.420 FPS`, reset at `4.151 ms`, mark-hidden at
  `1.866 ms`, and the unchanged CPU visibility system at `15.931 ms`.
- The total-frame improvement was 1.35%; reset improved 2.92%; mark-hidden
  improved 2.71%. The unchanged CPU visibility system moved 2.19% in the same
  direction, so the result is consistent with run-to-run variation rather than
  an important cache-lifetime cost.
- One focused visibility change-detection test and one focused filtered-query
  system-parameter test passed separately with `MOONBIT_NEW_NATIVE=1`.
- No production code or test change from the experiment remains.
