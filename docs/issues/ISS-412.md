# ISS-412: Release superseded scattering-medium GPU resources

## Description
Scattering-medium density or scattering LUT shape changes replace two textures, their views, and a sampler without releasing the previous aggregate.

## Design
Add a complete `GpuScatteringMediumResources` release operation and commit replacement transactionally so a construction failure does not destroy the previous resources.

## Acceptance Criteria
- [ ] Superseded density and scattering textures, views, and sampler are released exactly once.
- [ ] Failed replacement construction leaves the previous resources usable.
- [ ] Native WGPU report coverage proves repeated shape replacement has bounded live handles.
