## Description
Scattering-medium density or scattering LUT shape changes replace two textures, their views, and a sampler without releasing the previous aggregate.

## Design
Add a complete `GpuScatteringMediumResources` release operation and commit replacement transactionally so a construction failure does not destroy the previous resources.

## Acceptance Criteria
- [x] Superseded density and scattering textures, views, and sampler are released exactly once.
- [x] Failed replacement construction leaves the previous resources usable.
- [x] Native WGPU report coverage proves repeated shape replacement has bounded live handles.

## Close Notes

Added complete release semantics for `GpuScatteringMediumResources`, then changed shape replacement to construct the complete aggregate before swapping it into the backend and releasing the previous aggregate. Upload-only C descriptors now use lexical `defer` cleanup. A native WGPU report regression test verifies that replacing both LUT shapes keeps live texture, view, and sampler counts bounded.
