## Description
The `VolumetricFogExample.glb` scene may import correctly but still render from
the wrong space if scene spawning, parent attachment, `Transform` propagation,
or `GlobalTransform` extraction diverges from Bevy.

## Design
Compare Bevy scene spawning and transform propagation source owners against the
mgstudio scene/ECS fragments used by the volumetric fog example. Focus on the
scene root entity, first-level children, and the identified contributor from
ISS-300.

This issue should not modify the glTF asset or camera. If the transform path is
aligned, close with evidence and leave material/render extraction to sibling
issues.
