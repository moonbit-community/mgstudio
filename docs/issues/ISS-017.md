# ISS-017: Port PBR embedded LUT assets and resource initialization

## Metadata

- Updated: 2026-06-20

## Description
Bevy initializes `Bluenoise`, `AreaLightLuts`, and `DfgLut` resources from
embedded assets or exact placeholders. Mgstudio currently contains
`bluenoise/stbn.ktx2`, but the Bevy-relative `ltc/ltc.ktx2` and
`environment_map/dfg.ktx2` assets are not present under `mgstudio-engine/pbr`.

## Design
Copy Bevy's asset files exactly and port the resource initialization logic from
`bevy/crates/bevy_pbr/src/lib.rs`. Use MoonBit package prebuild/embed support if
needed. Do not approximate LUT data by renderer fallback textures when Bevy
expects a concrete PBR resource.

## Acceptance Criteria
- [x] `mgstudio-engine/pbr/ltc/ltc.ktx2` matches Bevy's source asset byte-for-byte.
- [x] `mgstudio-engine/pbr/environment_map/dfg.ktx2` matches Bevy's source asset byte-for-byte.
- [x] `Bluenoise`, `AreaLightLuts`, and `DfgLut` resources are initialized with Bevy-equivalent labels, sampler choices, usage flags, and placeholder behavior.
- [x] Area light, environment map, and PBR IBL examples use the real PBR resources instead of renderer-local fallback textures where Bevy would not.
- [x] Asset-copy verification is recorded with checksums or byte-for-byte comparison commands.
