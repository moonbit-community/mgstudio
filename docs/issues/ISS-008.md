## Description
Previous transform sync currently costs about `0.998 ms/frame`. It is smaller
than the top systems, but it is an always-on per-frame write path and may
amplify change tracking pressure after animation and transform propagation.

## Design
Compare the current previous-transform ownership model with Bevy's mesh/PBR
source and port the update conditions directly. The path should not update every
existing `PreviousGlobalTransform` unless the source semantics require it.

## Acceptance Criteria
- [ ] The system reports how many `PreviousGlobalTransform` components are scanned and written each frame.
- [ ] The update condition matches Bevy's prepass or motion-vector ownership model.
- [ ] Unchanged previous-transform data does not create unnecessary ECS changed-state pressure.
- [ ] At `1000` foxes, previous transform sync is reduced below `0.3 ms/frame` or the remaining cost is justified by source-equivalent semantics.
- [ ] Relevant PBR and transform tests pass with `--release`.
