# ISS-186: Consume prepared volumetric fog state in camera execution

## Description
After Bevy's prepare systems populate volumetric-fog render-world resources and
components, the draw pass consumes that prepared state. Camera execution should
not compute or mutate `ViewVolumetricFog`, `ViewVolumetricFogPipelines`, or the
uniform buffer as a side effect of drawing a single camera.

Mgstudio still has camera-local prepare calls in the 3D render flow. That must
be replaced with a source-shaped flow where camera execution reads the prepared
render-world state and emits draw commands only.

## Design
Rewire the camera/main-pass path so volumetric fog data preparation is invoked
before draw consumption and camera execution reads only prepared
`ViewVolumetricFog`, `ViewVolumetricFogPipelines`, and uploaded uniform-buffer
state. Preserve current visual behavior while removing draw-time mutation of
volumetric fog prepared data.

## Acceptance Criteria
- [x] Camera/main-pass execution no longer prepares or mutates volumetric-fog view data while drawing.
- [x] Draw code consumes prepared render-world `ViewVolumetricFog` and `ViewVolumetricFogPipelines`.
- [x] Focused tests prove camera execution uses prepared state rather than source-world fog data.
- [x] A standard `examples/3d/atmosphere` capture runs without volumetric-fog renderer fatals after the rewire.

## Close Notes
2026-07-04: Moved volumetric-fog prepare out of
`render3d_execute_camera_main_pass`. `render3d_execute_camera` now computes the
light-probe state after prepass target resolution, prepares the volumetric-fog
uniform/view/pipeline state before entering the main pass, and passes the
prepared result into the main pass. The main pass now consumes prepared
render-world `ViewVolumetricFog`, `ViewVolumetricFogPipelines`, and uploaded
uniform-buffer state when it calls `render3d_draw_volumetric_fog`; it no longer
mutates volumetric-fog prepared data while drawing.

Focused coverage in `pbr/volumetric_fog_execute_wbtest.mbt` now calls the
pre-main-pass prepare state path and verifies that uniforms use the render-world
`VolumetricFog` and `FogVolume` values rather than the camera payload's stale
fog data.
