## Description
`examples/3d/contact_shadows` is currently a local keyboard-driven rewrite of
Bevy's `bevy/examples/3d/contact_shadows.rs`, not a source-shaped port.

Bevy's owner is centered on radio-button widgets, `WidgetClickEvent` message
flow, an `AppStatus` resource, marker-query updates, a parent `LightContainer`,
pointer observers on the FlightHelmet scene, cursor icon updates, and
`TextUiWriter` radio state updates. Mgstudio instead stores all state in a
global `Ref`, tracks entity IDs manually, changes settings via keyboard
shortcuts, simulates light-type visibility with intensity rewrites, and uses a
`Text2dBundle` help overlay.

## Design
Port the example directly against the Bevy owner and the shared widgets helper.
Do not keep the keyboard/global-state implementation as the parity path. If a
specific ECS/UI/picking feature cannot express Bevy's observer or widget
message shape, record that missing feature as a precise blocker.

## Acceptance Criteria
- [ ] `main` preserves the window title, `MeshPickingPlugin`, `AppStatus`
      resource, `GlobalAmbientLight::NONE`, widget click message, and Bevy
      system ordering.
- [ ] `ExampleSetting`, `AppStatus`, `LightContainer`, and `GroundPlane` are
      represented as source-shaped enum/resource/component owners.
- [ ] `setup` builds the camera component tuple, three child lights under the
      light container, FlightHelmet scene, ground circle mesh, radio buttons,
      and top-center drag help text from the Bevy owner.
- [ ] FlightHelmet pointer drag/over/out/dragend observers and cursor icon
      updates are represented or a precise picking/window blocker is recorded.
- [ ] Radio button UI uses the shared widgets helper and emits/reads
      `WidgetClickEvent<ExampleSetting>`.
- [ ] `update_radio_buttons` updates `BackgroundColor` and text colors through
      Bevy-shaped widget queries and `TextUiWriter` semantics.
- [ ] `handle_setting_change` mutates light contact-shadow flags, shadow maps,
      light visibility, and ground `NotShadowReceiver` through Bevy-shaped
      queries and commands.
- [ ] `rotate_light` rotates the parent `LightContainer` transform with Bevy's
      fixed per-update speed semantics.
- [ ] Local-only global tracked state, keyboard shortcut controls, intensity
      based light-type switching, and `Text2dBundle` help overlay are removed
      from the parity path.
- [ ] The reference screenshot is refreshed after the source-shaped port still
      renders correctly.
