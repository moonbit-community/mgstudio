## Description
Bevy prepares `ViewVolumetricFog`, `ViewVolumetricFogPipelines`,
`VolumetricFogUniformBuffer`, dynamic uniform offsets, fog-volume transforms,
density texture metadata, and sampled depth texture usage before the volumetric
fog pass. Mgstudio must classify this prepared-data owner separately from the
draw pass.

## Design
Use this issue as the parent for prepared-data audits:

- ISS-281 audits `ViewVolumetricFog`, `ViewFogVolume`, uniform packing, and
  dynamic offsets.
- ISS-282 audits view-depth texture usage, density texture metadata, and
  animated density offsets.

## Acceptance Criteria
