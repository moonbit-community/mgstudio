# ISS-028: Move shape conversion and bundle authoring out of render2d runtime

## Metadata
- Type: task
- Status: open
- Priority: 1
- Labels: parity, sprite, mesh, primitives, render2d
- Assignee: unassigned
- Created: 2026-06-03
- Updated: 2026-06-05
- External ref: none

## Description
`sprite/render2d.mbt` contains 2D shape-to-mesh conversion helpers, sprite and
mesh bundle constructors, and authoring/runtime convenience logic. Examples
include the `shape_*` helpers, circle/ellipse/annulus/capsule/triangle/segment
geometry conversion, `SpriteBundle`, `Camera2dBundle`, and `Mesh2dBundle`.

These are authoring, mesh primitive, sprite, or camera concerns. They do not
belong in the sprite render runtime owner.

## Design
Move shape conversion to mesh/primitives or sprite authoring owners as
appropriate, and move bundle constructors to the owner package whose Bevy
component they represent. Keep render runtime files focused on extraction,
queueing, phase item construction, and draw commands.

## Acceptance Criteria
- [ ] Shape mesh conversion helpers no longer live in `sprite/render2d.mbt`.
- [ ] Stale bundle authoring APIs are either removed when current Bevy removed them, or moved under their Bevy-equivalent authoring/component owners when still in scope.
- [ ] Render runtime APIs do not allocate or author assets except where Bevy render extraction/preparation does so.
- [ ] Existing 2D shape and mesh2d examples pass after the move.
