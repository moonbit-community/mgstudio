## Description
Bevy's `examples/3d/occlusion_culling.rs` reads the opaque 3D indirect draw
parameters back from the GPU by combining:

- `RenderDebugFlags::ALLOW_COPIES_FROM_INDIRECT_PARAMETERS`;
- `IndirectParametersBuffers` for the `Opaque3d` phase;
- staging buffers created with `MAP_READ | COPY_DST`;
- command-encoder `copy_buffer_to_buffer`;
- asynchronous buffer mapping and typed CPU decoding of
  `IndirectParametersIndexed` plus the indirect batch-set count.

Mgstudio has GPU preprocessing and occlusion-culling internals, and wgpu_mbt
has enough low-level concepts for buffers, `MAP_READ`, and buffer copies in
renderer-owned code paths. The missing migration surface is a Bevy-shaped,
public render-app owner API that lets an example or plugin access the active
phase indirect buffers and perform the staging-buffer readback without reaching
through private renderer backend state.

## Design
Port the Bevy source owner instead of adding an example-local shortcut:

- expose render debug flags equivalent to Bevy's copy-from-indirect-parameters
  permission and wire them through `RenderPlugin`/`PbrPlugin` shape;
- expose or port an `IndirectParametersBuffers` resource keyed by phase owner,
  with indexed/non-indexed data and batch-set buffers available after GPU
  preprocessing prepares them;
- expose staging-buffer creation and readback through the render-app schedule
  surface, including map/unmap and typed byte decoding;
- preserve Bevy ordering: prepare staging buffers in render prepare/flush,
  copy after the main 3D pass and before postprocess, and extract/read results
  back to the main world without requiring an example-local renderer backend
  escape hatch.

## Acceptance Criteria
- [ ] `examples/3d/occlusion_culling` can install a source-shaped
      `ReadbackIndirectParametersPlugin`.
- [ ] The plugin can access opaque 3D indirect parameter buffers through a
      public Bevy-shaped resource instead of private backend state.
- [ ] Staging buffers can be created, copied to, mapped, decoded, and unmapped
      from render-app systems.
- [ ] The example displays GPU-derived rendered mesh counts and no longer shows
      the blocker text.
- [ ] ISS-086 can remove its blocked status and close without heuristic
      scene-space counters.
