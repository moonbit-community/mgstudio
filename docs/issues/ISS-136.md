## Description
`bevy/examples/3d/tonemapping.rs` configures `DefaultPlugins.set(AssetPlugin {
unapproved_path_mode: UnapprovedPathMode::Allow, ..default() })` so the example
can load drag-and-dropped local HDR/EXR files.

Mgstudio's current `AssetPlugin` exposes sampler, asset mode, asset root, and
processed asset root settings, but does not expose a Bevy-shaped
`UnapprovedPathMode` policy. `AssetServer::load(path)` currently accepts the
path used by the tonemapping example without this explicit safety knob, so the
runtime can work while the source shape is still not faithful to Bevy.

## Design
Audit Bevy's current asset path approval owner and add the equivalent mgstudio
policy surface in the asset package. The tonemapping example should then express
the same plugin graph as Bevy instead of relying on the current implicit path
acceptance behavior.

## Acceptance Criteria
- [x] Bevy's `UnapprovedPathMode` owner is audited and mapped to mgstudio asset
      code.
- [x] `AssetPlugin` exposes a source-shaped unapproved-path policy.
- [x] `AssetServer::load` applies or records that policy at the same ownership
      boundary as Bevy.
- [x] `examples/3d/tonemapping` uses the Bevy-shaped asset-plugin
      configuration for drag-and-drop image loading.
- [x] A targeted asset package test covers the default policy and explicit
      `Allow` behavior.

## Close Notes
- 2026-06-19: Added the Bevy-shaped `UnapprovedPathMode` policy to mgstudio
  asset paths and `AssetPlugin`, defaulting to `Forbid`. `AssetPath` now
  classifies absolute paths and paths that escape with parent components as
  unapproved. `AssetServer` applies the policy at file-backed load entry points
  including typed assets, registered assets, image loads, folders, blobs, and
  host registered loaders.
- 2026-06-19: Updated `examples/3d/tonemapping` to express Bevy's
  drag-and-drop image loading intent by setting
  `AssetPlugin::with_unapproved_path_mode(UnapprovedPathMode::Allow)` through
  `DefaultPlugins::set`.
- 2026-06-19: Added targeted asset tests for `AssetPath::is_unapproved`, default
  `Forbid`, and explicit `Allow`. Existing tests that intentionally use `/tmp`
  asset paths now opt into `Allow`.
- 2026-06-19: Verified with `moon -C mgstudio-engine check --target native`,
  `moon -C mgstudio-engine test asset --release`, `moon -C mgstudio-engine test
  examples/3d/tonemapping --release`, `moon -C mgstudio-engine fmt`,
  `moon -C mgstudio-engine info`, and
