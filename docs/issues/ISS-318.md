## Description
After glTF material import and PBR specialization are source-audited, mgstudio
needs executable evidence for the contributor identified by ISS-300 so future
changes cannot silently reintroduce the same material/depth divergence.

## Design
Add or extend focused tests/wbtests that load the real
`VolumetricFogExample.glb`, locate the identified contributor, and assert the
runtime material handle and relevant prepared render state that correspond to
the Bevy anchors from ISS-316 and ISS-317. Keep this test tied to real scene
loading and render extraction state, not screenshot color alone.

## Acceptance Criteria
- [x] A focused test locates the identified contributor in the loaded runtime
      scene.
- [x] The test asserts the imported material fields required by ISS-316.
- [x] The test asserts the prepared PBR material/depth/culling state required
      by ISS-317, or records the exact owner that cannot be observed yet.
- [x] The relevant targeted `moon -C mgstudio-engine test ... --target native
      --release` command passes.
