## Description
Bevy installs `SyncComponentPlugin::<FogVolume, Self>` and consumes
render-world fog-volume entities during uniform preparation.

## Design
Audit mgstudio's `FogVolume` render-world identity, transform availability,
and cleanup semantics against Bevy. Source-world collection inside camera
execution is not sufficient for this issue.

## Acceptance Criteria
- [x] `FogVolume` component sync ownership is classified.
- [x] Render-world transform availability for fog volumes is classified.
- [x] Fog-volume cleanup/despawn behavior is classified or filed as follow-up.

## Notes
- 2026-07-05: Split from ISS-238 so fog-volume sync can be fixed without
  mixing in view or light extraction behavior.
- 2026-07-09: Audited against
  `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::extract_volumetric_fog`.
  Bevy extracts `Query<(RenderEntity, &FogVolume, &GlobalTransform)>`; when
  volumetric lights exist, it inserts a cloned `FogVolume` and copied
  `GlobalTransform` into the synced render-world entity. Mgstudio
  `extract_volumetric_fog_from_worlds` mirrors this source shape by collecting
  only source entities that have `FogVolume`, `GlobalTransform`, and
  `RenderEntity`, then setting `FogVolume` and `GlobalTransform` on the render
  entity. The existing white-box test
  `pbr volumetric fog: extract copies Bevy render-world components` verifies
  both copied component values on the render entity.
- 2026-07-09: No-light cleanup is also source-equivalent for this owner. Bevy
  only removes `FogVolume` from extracted fog-volume render entities in the
  no-light branch; it does not remove `GlobalTransform` there. Mgstudio removes
  the render-world `FogVolume` and leaves source-world state untouched, covered
  by `pbr volumetric fog: no-light extract cleans render-world fog state only`.

## Close Notes
Closed as source-complete for `FogVolume` extraction and render-world ownership
within the current Bevy baseline. No code change and no external blocker were
required; the current MoonBit implementation already matches Bevy's
`FogVolume + GlobalTransform` extract query and no-light cleanup behavior.
