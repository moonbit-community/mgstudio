## Description
Bevy prepares `ViewVolumetricFog`, `ViewVolumetricFogPipelines`, and a
`VolumetricFogUniformBuffer` in render prepare systems, and separately marks
view depth textures for volumetric fog usage. Mgstudio has much of the math and
packing, but the lifecycle is still collapsed into local render execution and
manual upload steps.

## Design
Use this issue as the parent for prepare-system parity. The executable work is
split into smaller slices:

- ISS-178 restores standalone `prepare_volumetric_fog_uniforms` ownership.
- ISS-179 restores standalone depth-texture usage preparation.

## Acceptance Criteria
- [x] ISS-178 and ISS-179 are closed.
- [x] `ViewVolumetricFog` and `ViewVolumetricFogPipelines` are populated through Bevy-shaped prepare ownership.
- [x] Depth texture usage preparation happens before the pass needs to sample depth.
