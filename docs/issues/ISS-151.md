# ISS-151: Skip dead entities during PBR material extraction

## Metadata
- Type: bug
- Status: closed
- Priority: 1
- Labels: pbr, scene, ecs, release-test, source-parity
- Assignee: unassigned
- Created: 2026-06-24
- Updated: 2026-06-24
- External ref: none

## Description
`moon -C mgstudio-engine test scene --release` aborted in the test
`scene: removing SceneRoot despawns spawned children`. The crash report showed
the abort happened in `pbr::extract_mesh_materials`, not in the scene test
assertions.

The scene removal path despawns entities that had recently changed render
components. The PBR extraction code collected changed component entities and
then called `World::get_by_key` on them without first checking that they were
still alive. Bevy's equivalent query iteration does not yield dead entities, so
mgstudio's extract path must preserve that live-entity boundary before reading
components.

## Design
Align the affected boundaries with Bevy-shaped semantics:

- PBR material extraction skips dead changed entities and lets the removed
  component sweeps clean stale render material instances.
- Scene root removal uses ECS deferred hook commands for spawned child despawn
  and deferred component removal for the root's `SceneInstance`, avoiding
  synchronous structural mutation inside component remove hooks.
- ECS exposes a general deferred component removal command for hook callbacks,
  matching the existing deferred despawn command shape.

## Notes
- 2026-06-24: Initial diagnosis from macOS crash report:
  `pbr::extract_mesh_materials` panicked after scene root removal because it
  read a dead entity collected from changed component messages.

## Close Notes
Fixed by adding `DeferredEntityCommands::remove_by_key`, moving scene root
remove cleanup onto deferred hook commands, and making
`extract_mesh_materials` skip dead changed entities before component reads.

Validation:
- `moon -C mgstudio-engine test ecs --release --filter 'ecs component hooks: deferred remove commands flush after callback'`
- `moon -C mgstudio-engine test scene --release --filter 'scene: removing SceneRoot despawns spawned children'`
- `moon -C mgstudio-engine test pbr --release --deny-warn`
