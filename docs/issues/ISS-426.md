# ISS-426: Fix Moon test generated-driver ambiguous-braces warnings

## Metadata
- Type: bug
- Status: closed
- Priority: 1
- Labels: moonbit, tooling, tests, warnings, external-blocker
- Assignee: unassigned
- Created: 2026-07-12
- Updated: 2026-07-21
- External ref: none

## Description
With the 2026-07-12 toolchain,
`MOONBIT_NEW_NATIVE=1 moon test --target native --release --deny-warn`
failed after project sources passed strict checking because Moon generated
`__generated_driver_for_blackbox_test.mbt` files containing ambiguous `{}`
expressions. The same generated warning appeared across unrelated packages
such as `app`, `color`, `image`, `math`, and `utils`.

## Design
Do not edit `_build` outputs or weaken project warning policy. Reproduce against
the pinned Moon toolchain and upgrade or patch Moon's black-box test driver
generator when an upstream fix is available. Verification after the toolchain
upgrade uses the current default native backend; it does not restore the old
experimental-backend environment override.

## Acceptance Criteria
- [x] A Moon-generated black-box test driver for an originally affected package
      compiles without `ambiguous_braces` warnings under `--deny-warn`.
- [x] `moon test utils/utils_test.mbt --target native --release --deny-warn`
      reaches and runs the selected project test suite on the current default
      native backend.
- [x] No generated files are checked into the repository as a workaround.

## Close Notes
Closed after the current Moon toolchain's shared black-box driver generator
passed the original warning class under `--deny-warn`. The representative
`utils` package was named in the original report and its generated driver is
produced by the same toolchain template used by the other affected packages.
The generated file remains ignored build output; no workaround or
warning-policy relaxation was added to the source tree.
