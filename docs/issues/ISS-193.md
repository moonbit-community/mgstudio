## Description
`examples/3d/atmosphere` combines atmosphere, terrain, water reflection, and
volumetric fog. It previously exposed a volumetric fog renderer fatal, so it
needs its own visual gate after pass-order execution is fixed.

## Design
This is a grouping issue. The executable work is split by source boundary:

- ISS-228 records current Bevy-vs-mgstudio atmosphere visual evidence.
- ISS-229 verifies that atmosphere, water, terrain, and volumetric fog inputs
  reach the render path with Bevy-shaped ownership.
- ISS-230 performs the final screenshot/reference acceptance after those inputs
  are proven.

## Acceptance Criteria
- [ ] ISS-228, ISS-229, and ISS-230 are closed.
