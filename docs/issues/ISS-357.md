## Description
Even with correct pass inputs, `volumetric_fog` can render incorrectly if
mgstudio chooses the wrong Bevy hull mesh, draw order, culling mode, or dynamic
uniform offset for each `ViewFogVolume`. Audit the draw-entry path for the real
example.

## Design
Compare Bevy's fog-volume preparation and draw-command logic in
`bevy_pbr/src/volumetric_fog/render.rs` against mgstudio's prepared
`ViewFogVolume` records and renderer host draw entries. Cover exterior/interior
hull selection, plane/cube mesh identity, dynamic uniform byte offsets,
density-texture metadata, culling, and pass draw ordering.

Do not paper over a wrong draw by changing camera placement, fog density, or
asset content.

## Acceptance Criteria
- [x] Bevy fog-volume hull selection and draw-entry anchors are mapped to

- [x] Focused evidence proves the real example uses the expected hull mesh,

## Close Notes
Closed on 2026-07-05 after auditing volumetric-fog hull selection, draw-entry
shape, culling, and dynamic-offset use. The only code change for this issue was
additional white-box evidence in the real `volumetric_fog` example test for
prepared fog hull mesh ids.

Bevy owner anchors:

- `bevy/crates/bevy_pbr/src/volumetric_fog/mod.rs::FogAssets` creates
  `Plane3d::new(Vec3::Z, Vec2::ONE).mesh()` and
  `Cuboid::new(1.0, 1.0, 1.0).mesh()`.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::prepare_volumetric_fog_pipelines`
  specializes both volumetric-fog pipelines from the plane mesh vertex layout.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::VolumetricFogPipeline::specialize`
  sets back-face culling and additive alpha blending for the volumetric pass.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::prepare_volumetric_fog_uniforms`
  stores `ViewFogVolume.exterior = !camera_is_inside_fog_volume(...)` and the
  dynamic uniform byte offset returned by the uniform writer.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::volumetric_fog` selects
  the cube hull when `ViewFogVolume.exterior` is true, otherwise selects the
  plane hull, binds group 1 with `[view_fog_volume.uniform_buffer_offset]`, and
  dispatches indexed or non-indexed draw according to the selected render mesh.

Mgstudio implementation fragments:

- `mgstudio-engine/pbr/volumetric_fog/top.mbt` creates the same plane and
  cuboid `FogAssets`.
- `mgstudio-engine/pbr/volumetric_fog/render.mbt::prepare_volumetric_fog_view_uniforms`
  stores `ViewFogVolume.exterior` and `uniform_buffer_offset` from the same
  inside/outside and dynamic-uniform packing logic.
- `mgstudio-engine/pbr/volumetric_fog_execute.mbt::render3d_prepare_volumetric_fog_hull_meshes`
  resolves the render runtime ids for the Bevy plane and cube fog hull assets.
- `mgstudio-engine/pbr/volumetric_fog_execute.mbt::render3d_draw_volumetric_fog`
  forwards each prepared `ViewFogVolume` to the renderer in render-world volume
  order with density texture id, uniform offset, and exterior flag.
- `mgstudio-engine/render/renderer/mesh3d_pipeline_build.mbt` builds the
  volumetric-fog pipeline with back-face culling, Bevy-shaped blend factors,
  and the supplied fog hull vertex layout.
- `mgstudio-engine/render/renderer/mesh3d_volumetric_fog_pass.mbt` selects
  plane versus cube from `HostMesh3dVolumetricFogVolume.exterior`, binds group
  1 with the single dynamic uniform offset, and draws indexed or non-indexed
  meshes according to runtime mesh info.

Evidence:

- `mgstudio-engine/examples/3d/volumetric_fog/main_wbtest.mbt` proves the real
  example camera and 35-unit fog volume prepare an interior `ViewFogVolume`,
  which means Bevy's plane/fullscreen hull path is expected.
- The same real-example pass-local gate proves prepared plane and cube hull
  runtime ids are present, the render view has one textureless volume, and the
  first volume uses dynamic offset 0.
- `mgstudio-engine/pbr/volumetric_fog_execute_wbtest.mbt` proves
  render-world uniform preparation preserves per-view and per-volume metadata
  and offset ordering for multiple views and volumes.
- `mgstudio-engine/render/renderer/gpu_wbtest.mbt` proves interior volumes map
  to the plane mesh id, exterior volumes map to the cube mesh id, and dynamic
  offset arrays contain the volume's byte offset.
- `mgstudio-engine/pbr/volumetric_fog/top_test.mbt` proves the plugin creates
  the Bevy fog hull mesh assets.
