## Description
Map the Bevy source anchors that decide where volumetric fog executes relative
to Core3d main-pass work and postprocess systems.

## Design
Read Bevy's Core3d schedule and volumetric fog render plugin owners. Record the
paths and symbols for the Core3d system sets, main-pass boundary, volumetric
fog insertion point, and any skybox or atmosphere ordering constraints that are
explicitly visible in the source. Do not collect runtime evidence here.

## Acceptance Criteria
- [ ] Bevy Core3d schedule and post-main system-set anchors are listed with
      paths and symbols.
- [ ] Bevy volumetric fog insertion anchors are listed with paths and symbols.
- [ ] Any explicit Bevy ordering relationship with skybox, atmosphere,
      transparent, or early postprocess work is classified.
- [ ] No production behavior is changed.
