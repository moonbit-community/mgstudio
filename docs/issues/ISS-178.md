## Description
Bevy prepares `ViewVolumetricFog`, `ViewVolumetricFogPipelines`, and
`VolumetricFogUniformBuffer` as render prepare data. Mgstudio has most of the
math, but the lifecycle is still tied to local camera render execution.

## Design
Use this issue as the parent for uniform-prepare source ownership. The
executable work is split into smaller slices:

- ISS-183 restores `VolumetricFogUniformBuffer` lifecycle, allocation count,
  packing, upload, and dynamic offsets.
- ISS-184 restores per-view `ViewVolumetricFog` preparation from extracted
  render-world fog volumes.
- ISS-185 restores `ViewVolumetricFogPipelines` preparation and
  textureless/textured pipeline variant ownership.
- ISS-186 rewires camera/render execution to consume prepared render-world
  state instead of preparing fog data inside local camera execution.

## Acceptance Criteria
- [x] ISS-183, ISS-184, ISS-185, and ISS-186 are closed.
- [x] `ViewVolumetricFog` and `ViewVolumetricFogPipelines` are prepared before draw from render-world state.
- [x] `VolumetricFogUniformBuffer` packing and dynamic byte offsets match the WGSL host layout.
