## Description
The clean pinned Bevy `examples/3d/contact_shadows` executable builds and runs
on the current macOS development machine, but neither available official
capture path produces a usable visual baseline. Bevy's own
`bevy_ci_testing::ScreenshotAndExit` path writes an all-black `2560x1440` PNG,
while the real application window is created outside the current Space and
cannot be captured with the system window screenshot API.

This blocks the official side of the `contact_shadows` human visual-parity
packet. It does not block source-level render/PBR migration or mgstudio's
native capture. The checked-in mgstudio reference cannot substitute for the
official artifact: it was generated before later high-DPI/window corrections
and now shows approximately 1x text rasterization, while both the live pinned
Bevy window bounds and current mgstudio capture imply Retina 2x rasterization.

## Design
Obtain a nonblack screenshot of the unmodified pinned Bevy
`contact_shadows` window on the current machine. Preserve the Bevy commit,
Rust toolchain, enabled official example features, CI configuration, window
metadata, and capture logs. Do not substitute an mgstudio screenshot, the
all-black Bevy CI artifact, a screenshot from another Bevy revision, or a
refreshed local reference without the official comparison.

An acceptable solution may repair Bevy's native screenshot readback, move the
live window to a capturable Space, use a working ScreenCaptureKit host with
Screen Recording permission, or use another deterministic native-window
capture path. It must capture the actual unmodified pinned Bevy example.

## Acceptance Criteria
- [ ] Pinned Bevy `examples/3d/contact_shadows` produces a nonblack native screenshot.
- [ ] The run uses Rust 1.95.0 and Bevy commit `1413bc4e3632233b8fa610a6cf14b90258556c51` with the official required `bluenoise_texture` feature plus `bevy_ci_testing`.
- [ ] The artifact records the CI config or window id and bounds, capture command, dimensions, SHA-256, and run log.
- [ ] The official artifact and current mgstudio artifact are retained in a human-reviewable visual-parity packet.
- [ ] ISS-114 is re-audited against the official artifact and either closed with accepted evidence or left open with an exact local source-owner gap.
