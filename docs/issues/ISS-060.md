## Description
After refreshing the first batch of broken references and upgrading dependency blockers, 188 `reference.png` files still fail the blank/near-black triage scan: 179 are fully transparent and 9 are near-black. These references cannot be used as visual regression baselines.

## Design
After dependency blockers are resolved, regenerate each remaining stale reference with the standard native capture command shape and keep only captures that pass image sanity checks. Do not treat a generated non-blank image as Bevy visual parity; this issue only covers replacing unusable local reference artifacts.

## Acceptance Criteria
- [ ] No `mgstudio-engine/examples/**/reference.png` file is fully transparent.
- [ ] No `reference.png` file is an unintended opaque black screen.
- [ ] Every refreshed reference was produced by `mgstudio-engine/scripts/p0_visual_capture_native.sh` or an equivalent checked-in capture gate.
- [ ] Failed or screenshot-ineligible examples are recorded in dedicated issue notes instead of using blank placeholder images.
