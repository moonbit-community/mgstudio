# ISS-027: Move tilemap chunk ownership out of sprite/render2d and old sprite facades

## Description
`sprite/render2d.mbt` contains tilemap-specific types and systems including
`TileOrientation`, `TileData`, `TilemapChunk`, `TilemapChunkTileData`,
`TilemapChunkMaterial`, `TilemapChunkMaterialPlugin`, mesh cache helpers, tile
data image packing, and material preparation. Bevy owns these in
`bevy_sprite_render/src/tilemap_chunk/*`.

Although `mgstudio-engine/sprite_render/tilemap_chunk/*` exists, current code
still exposes the implementation through the older sprite/render2d path.

## Design
Move tilemap chunk implementation into `sprite_render/tilemap_chunk`, keep WGSL
assets copied from Bevy, and delete the old render2d-owned tilemap section.

## Acceptance Criteria
- [x] Tilemap chunk types, plugin, material, tile orientation, and preparation systems live under `sprite_render/tilemap_chunk`.
- [x] The old sprite/render2d tilemap section is removed.
- [x] Tilemap examples import the Bevy-shaped owner and pass relevant tests/examples.
- [x] Embedded tilemap WGSL remains copied from the Bevy asset source and generated via prebuild.
