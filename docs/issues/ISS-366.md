## Description
Compare the static `volumetric_fog.wgsl` import closure used by mgstudio
against Bevy's `bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl`. This issue
only classifies source-shape and import-closure parity; it must not repair
pipeline state or visual output.

## Design
Read Bevy's WGSL source and mgstudio's embedded WGSL registry/composition path.
List every Bevy import anchor, every mgstudio mapped module, and any missing,
renamed, facade, blocked, or locally divergent symbol. If the composed shader
cannot match Bevy because of a dependency parser/composer limitation, record the
limitation precisely instead of editing shader text around it.

## Acceptance Criteria
- [x] Bevy `volumetric_fog.wgsl` imports are mapped to mgstudio WGSL modules.
- [x] The active mgstudio composed shader closure is compared against the Bevy
      closure for the volumetric-fog shader.
- [x] Every difference is classified as complete, facade, partial, blocked, or
      local divergence.
- [x] Any local divergence is linked to ISS-370 for final assignment.
