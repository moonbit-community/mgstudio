## Description
Bevy's `volumetric_fog` example owns `AppSettings` defaults plus a
`create_text` helper that builds the help text UI used by
`adjust_app_settings`.

## Design
Port the resource defaults, text strings, text layout, and entity/component
shape directly from `bevy/examples/3d/volumetric_fog.rs`, using mgstudio
branding only where literal branding is required.

## Acceptance Criteria
- [x] `AppSettings` defaults enable both point-light and spotlight volumetric
      behavior like Bevy.
- [x] The help text content and layout match Bevy's example shape.
- [x] The text entity/component shape supports later incremental updates from
      `adjust_app_settings`.
- [x] A focused test or source audit records the final text/resource shape.
