## Description
The `VolumetricFogExample.glb` visual divergence may come from material state
loaded from glTF before PBR specialization. This issue owns only the Bevy glTF
material import slice for the contributor identified by ISS-300.

## Design
Compare Bevy's glTF material loading source anchors against mgstudio's glTF
loader. Focus on base color, alpha mode, double-sidedness, unlit flags,
emissive fields, normal/occlusion/metallic-roughness textures, and any material
extension field actually present in the source asset. Do not inspect renderer
pipeline state here; that is ISS-317.

## Acceptance Criteria
- [x] Bevy source anchors for glTF material import are listed.
- [x] Mgstudio fragments implementing those anchors are listed.
- [x] The identified contributor's imported material fields are compared
      against Bevy semantics.
- [x] Any local divergence is fixed here or assigned to ISS-305 with exact
      source-owner evidence.
