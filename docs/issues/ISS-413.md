## Description
`GpuBackend` owns the native instance, adapter, device, queue, surfaces, resource registries, and many cached render resources, but currently has no complete teardown operation. Replacing the global backend in tests or recreating the renderer in one process discards all of those manual handles.

## Design
Add an explicit idempotent backend shutdown boundary that drains pending and retired frame resources, releases all resource registries and feature caches, then releases surfaces, queue, device, adapter, and instance in dependency order. Route global backend replacement through that boundary. Use `defer` to roll back partially initialized instance/adapter/device stacks.

## Acceptance Criteria
- [ ] `GpuBackend` exposes one idempotent internal shutdown operation covering every owned native handle.
- [ ] Global backend replacement releases the previous backend before storing the next backend.
- [ ] Partial backend initialization releases already-created handles on error.
- [ ] WGPU GlobalReport tests demonstrate backend create/use/shutdown returns live handle counts to baseline.
- [ ] Repository-native checks and targeted tests pass with `MOONBIT_NEW_NATIVE=1`.
