# ISS-409: Release replaced texture resources and scoped descriptors

## Description
Cube-texture replacement removes the previous `GpuTextureInfo` record without releasing its owned texture, views, sampler, and bind group. Texture upload helpers also manually free call-scoped C descriptors after the operation, so an error raised before those statements leaks the descriptors.

## Design
Add one ownership-aware release helper for `GpuTextureInfo`, call it for the record removed during replacement, and use `defer` immediately after creating lexically scoped C descriptors. Account for aliased views and borrowed fallback sampler or bind-group handles so each owned WGPU reference is released exactly once.

## Acceptance Criteria
- [x] Replacing a cube texture releases every handle owned by the old texture record exactly once.
- [x] Borrowed fallback sampler and bind-group handles are not released by records that do not own them.
- [x] Texture upload descriptors use `defer` and are released when a later operation raises.
- [x] Targeted native tests and `moon check` pass with `MOONBIT_NEW_NATIVE=1`.
