## Description
Bevy rotates the `fog_volumes` camera every frame using
`Quat::from_rotation_y(0.01) * camera_transform.translation` and then looks at
the bunny center. This motion changes the density-light response over time.

## Design
Port `rotate_camera` directly and capture evidence from two frames to prove the
rendered fog volume changes because of the source-shaped camera update.

## Acceptance Criteria
- [ ] The camera rotation system matches Bevy's transform update semantics.
- [ ] Frame-to-frame evidence shows the fog volume response changes over time.
- [ ] The evidence capture completes with no volumetric fog renderer fatal or
      missing-resource output.
