## Description
Prove the decoded `fog_volumes` density asset reaches the render path as the
3D texture view required by Bevy's volumetric fog bind group.

## Design
Inspect mgstudio render-asset preparation, texture view dimension, sampler
selection, and volumetric-fog bind group readiness for the density texture.
Do not substitute a generated texture or proxy geometry.

## Acceptance Criteria
- [ ] The decoded density asset is prepared as a GPU texture with the required
      3D view dimension.
- [ ] The volumetric fog pass can resolve the texture through the same
      render-asset lookup used by production.
- [ ] Focused evidence proves the textured fog-volume branch is reachable for
      this asset.
- [ ] Any backend limitation is recorded as a precise blocker.
