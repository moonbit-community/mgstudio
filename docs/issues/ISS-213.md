## Description
Even with a valid directional shadow texture, `scrolling_fog` can still miss
Bevy's light-shaft structure if any host-to-WGSL input diverges: directional
light uniform layout, cascade uniform values, shadow texture base indices,
shadow flags, mesh-view bind group slots, or dynamic offsets.

## Design
Track the input-packing work as smaller Bevy source-owner audits. Each child
issue must map one owner boundary exactly, fix local divergence
source-faithfully, or record a precise blocker. Do not close this epic from a
visually plausible capture alone.

## Acceptance Criteria
- [x] ISS-249 maps every `volumetric_fog.wgsl` directional light and shadow
      field read to its Bevy owner and mgstudio producer.
- [x] ISS-250 verifies or fixes the `GpuLights` / `GpuDirectionalLight` host
      layout and byte packing.
- [x] ISS-251 verifies or fixes directional cascade override and shadow index
      propagation from the shadow pass into the lights uniform.
- [x] ISS-252 verifies or fixes mesh-view bind group slots and dynamic offsets
      used by volumetric fog.
- [x] ISS-253 adds focused `scrolling_fog`-shaped white-box coverage across the
      completed input-packing chain.
- [x] No JSON payload, workaround, fallback, or local reinterpretation is used
      to hide layout divergence.

## Close Notes
Closed after the host-to-WGSL input-packing chain was audited and covered at
the Bevy source-owner boundaries:

- ISS-249: WGSL directional-light and shadow reads mapped to Bevy and mgstudio
  producers.
- ISS-250: `GpuLights` / `GpuDirectionalLight` byte layout covered by focused
  PBR and renderer tests.
- ISS-251: directional shadow cascade override into the packed lights uniform
  covered by a PBR white-box test.
- ISS-252: volumetric fog group-0 mesh-view bind group slots, dynamic offsets,
  PBR lights bytes, and active directional shadow texture identity covered by
  renderer white-box tests.
- ISS-253: `scrolling_fog`-shaped pass-level white-box coverage added across
  PBR packing and renderer consumption.

This closes input packing only. It does not claim final `scrolling_fog` visual
parity; ISS-214 and ISS-215 remain the next work for shader sampling math and
visual acceptance.
