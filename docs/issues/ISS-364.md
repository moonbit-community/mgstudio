## Description
Bevy binds `VolumetricFogUniformBuffer` at binding 0 of the volumetric-fog
bind group and uses each `ViewFogVolume.uniform_buffer_offset` as the dynamic
offset. Audit that mgstudio packs, uploads, binds, and offsets the same uniform
data for the real `examples/3d/volumetric_fog` volume.

## Design
Compare Bevy `prepare_volumetric_fog_uniforms` and
`volumetric_fog` dynamic bind-group usage against mgstudio's prepared
`ViewFogVolume`, packed uniform buffer, renderer upload, bind group creation,
and dynamic-offset call. Do not audit hull mesh selection or draw ordering here;
ISS-357 owns that draw-entry evidence.

## Close Notes
Closed on 2026-07-05 after auditing the volumetric-fog uniform buffer and
dynamic-offset pass input. No renderer semantics, shader code, assets, or
example scene authoring changed for this issue.

Bevy owner anchors:

- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::VolumetricFogUniform`
  is the host-side uniform payload consumed by `volumetric_fog.wgsl`.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::VolumetricFogUniformBuffer`
  wraps `DynamicUniformBuffer<VolumetricFogUniform>`.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::prepare_volumetric_fog_uniforms`
  calls `VolumetricFogUniformBuffer::get_writer`, writes one
  `VolumetricFogUniform` for each `(view, fog_volume)` pair, and stores the
  returned `writer.write(...)` byte offset in each `ViewFogVolume`.
- `bevy/crates/bevy_pbr/src/render_resource/uniform_buffer.rs::DynamicUniformBuffer::get_writer`
  rounds `T::min_size()` up to the device `min_uniform_buffer_offset_alignment`
  and returns aligned offsets from `DynamicUniformBufferWriter::write`.
- `bevy/crates/bevy_pbr/src/volumetric_fog/render.rs::volumetric_fog` binds the
  `VolumetricFogUniformBuffer` at binding 0 of group 1 and passes
  `[view_fog_volume.uniform_buffer_offset]` as the dynamic offset.

Mgstudio implementation fragments:

- `mgstudio-engine/pbr/volumetric_fog/render.mbt` defines the equivalent
  `VolumetricFogUniform`, packs it to the WGSL host layout, stores packed
  uniforms in `VolumetricFogUniformBuffer`, uses a 288-byte min binding size,
  and advances offsets by the 512-byte dynamic stride.
- `mgstudio-engine/pbr/volumetric_fog/render.mbt::prepare_volumetric_fog_view_uniforms`
  writes one uniform per fog volume for each view and stores the returned byte
  offset on `ViewFogVolume`.
- `mgstudio-engine/pbr/volumetric_fog_execute.mbt::render3d_prepare_volumetric_fog_uniform_buffer`
  clears the shared buffer, prepares all render-world views, writes
  `ViewVolumetricFog` back to each render view, and uploads the packed bytes
  through `host_gpu_prepare_mesh3d_volumetric_fog_uniforms`.
- `mgstudio-engine/render/renderer/mesh3d_bind_groups.mbt` creates the group 1
  layout with binding 0 as a uniform buffer with `has_dynamic_offset=true` and
  `min_binding_size=MESH3D_VOLUMETRIC_FOG_UNIFORM_SIZE`.
- `mgstudio-engine/render/renderer/mesh3d_bind_groups.mbt::prepare_mesh3d_volumetric_fog_uniforms`
  grows the GPU buffer as needed and writes the packed bytes at offset 0.
- `mgstudio-engine/render/renderer/mesh3d_volumetric_fog_pass.mbt` binds group
  1 with `mesh3d_volumetric_fog_dynamic_offsets(volume)`, which returns the
  single `ViewFogVolume.uniform_buffer_offset`.

Evidence:

- `mgstudio-engine/pbr/volumetric_fog/render_wbtest.mbt` proves uniform buffer
  prepare/clear behavior, 0 and 512 byte offsets, and WGSL host-layout bytes.
- `mgstudio-engine/pbr/volumetric_fog_execute_wbtest.mbt` proves the standalone
  render-world uniform prepare inserts per-view fog metadata and preserves
  per-view/per-volume offsets.
- `mgstudio-engine/render/renderer/gpu_wbtest.mbt` proves the renderer passes
  the `ViewFogVolume.uniform_buffer_offset` as the group 1 dynamic offset.
- `mgstudio-engine/examples/3d/volumetric_fog/main_wbtest.mbt` proves the real
  example reaches the volumetric-fog pass with positive uniform count and the
  expected first volume offset.

Validation:

- `moon -C mgstudio-engine test pbr/volumetric_fog --target native --release --filter 'pbr volumetric fog: uniform buffer prepare and clear'`
  passed `1/1`; duplicate `-lobjc` linker warnings were emitted.
- `moon -C mgstudio-engine test pbr/volumetric_fog --target native --release --filter 'pbr volumetric fog: uniform bytes match WGSL host layout'`
  passed `1/1`.
- `moon -C mgstudio-engine test pbr --target native --release --filter 'pbr volumetric fog execute: standalone uniform prepare inserts per-view fog metadata'`
  passed `1/1`; duplicate `-lobjc` and `-lz` linker warnings were emitted.
- `moon -C mgstudio-engine test render/renderer --target native --release --filter 'renderer: volumetric fog volume selects Bevy hull mesh and dynamic uniform offset'`
  passed `1/1`; duplicate `-lobjc` linker warnings were emitted.
- `moon -C mgstudio-engine test examples/3d/volumetric_fog --target native --release --filter 'volumetric_fog: runtime pass-local evidence reaches Bevy fog pass'`
  passed `1/1`; duplicate `-lobjc` and `-lz` linker warnings were emitted.

Conclusion:

- The uniform buffer binding and dynamic-offset pass input are Bevy-shaped for
  this boundary.
- Hull mesh selection and draw-entry behavior remain owned by ISS-357 and are
  intentionally not closed by this audit.
- No local divergence from ISS-364 needs assignment to ISS-359. Continue with
  ISS-365 for textureless versus density-textured bind variants.
