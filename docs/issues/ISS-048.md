capture harness did not receive an RGBA8 blob. This issue now tracks manual

examples rather than strict Bevy parity work.

- `examples/3d/rapier_context_component`

## Design
Inspect each package source and its run log under
`.private/example_screenshots/20260605_193912/`. Keep examples that are useful
as mgstudio reference material, document diagnostic-only examples explicitly,
and split real runtime/capture failures into follow-up issues. Do not treat a
plausible file name or partial render as parity evidence.
