## Description
Several visual 2D and 3D examples failed the screenshot batch because the
native capture harness did not receive an RGBA8 blob. These are likely to be
real visual-gate gaps unless source inspection proves that a package is
intentionally non-visual.

Failed packages:

- `examples/2d/debugdump2`
- `examples/2d/rotate_to_cursor`
- `examples/2d/rotation`
- `examples/2d/wireframe_2d`
- `examples/3d/debugdump3`
- `examples/3d/fog`
- `examples/3d/fog_volumes`
- `examples/3d/rapier_context_component`
- `examples/3d/volumetric_fog`

## Design
Inspect each package source and its run log under
`.private/example_screenshots/20260605_193912/`. For each visual example,
compare the intended Bevy example behavior and make the mgstudio capture path
produce a real `reference.png`. If a package is diagnostic-only, document why it
is excluded instead of silently treating the missing image as success.

## Acceptance Criteria
- [ ] Each listed package is classified as screenshot-required or screenshot-excluded.
- [ ] Screenshot-required packages produce `mgstudio-engine/<package>/reference.png`.
- [ ] Diagnostic-only packages have an explicit exclusion reason.
- [ ] Any render/PBR/fog runtime bug discovered during triage is split into a follow-up issue or fixed before closure.

## Notes
- 2026-06-07: All listed packages failed with capture exit code 5 in the batch failure manifest.
- 2026-06-07: Started with the highest-risk subclass: visual examples that fail before producing any image because ECS system parameter validation or runtime setup aborts the app. The first local root cause is stale 2D example system-param shapes that diverged from current Bevy source and conflict under Bevy-style access validation.
- 2026-06-07: Fixed the ECS validation subclass for `examples/2d/rotation` and `examples/2d/rotate_to_cursor` by aligning their system params with current Bevy source: `Single` for unique player/camera/window lookups, Bevy-style disjoint filters, and `GlobalTransform` for camera-space conversion input. Both now produce checked-in `reference.png` screenshots.
- 2026-06-07: `examples/2d/wireframe_2d` was source-shape aligned for the text update system (`Single<Write<Text>, With<WireframeHelpText>>`), but it still does not produce an RGBA8 blob within the capture timeout. Its latest log only reports `Command exited without a return code`, so this is a separate capture/runtime issue rather than the ECS validation subclass fixed here.
