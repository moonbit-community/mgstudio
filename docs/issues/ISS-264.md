## Description
Bevy's static `volumetric_fog` setup spawns a red point light with
`VolumetricLight` and movement state, a shadowed white spot light with
`VolumetricLight`, and a large default `FogVolume`.

## Design
Port the static component values and transforms directly from Bevy. Runtime
movement and toggle behavior are handled by ISS-265 and ISS-266.

## Acceptance Criteria
- [x] Point light transform, color, intensity, range, shadows, and
      `VolumetricLight` match Bevy.
- [x] Spot light transform, color, intensity, angles, shadows, and
      `VolumetricLight` match Bevy.
- [x] The default `FogVolume` and scale match Bevy.
- [x] A focused render-input check proves these entities are visible to PBR
      extraction/prepare.
- [x] The native capture completes after ISS-285 fixes the volumetric fog MSAA
      render-pass sample-count mismatch exposed by these Bevy-shaped inputs.

## Close Notes
Closed on 2026-07-05.

Bevy source owner audited:

- `bevy/examples/3d/volumetric_fog.rs::setup` static light and fog-volume
  spawns: red moving point light with `VolumetricLight`, white shadowed spot
  light with `VolumetricLight`, and default `FogVolume` scaled by `35.0`.

Mgstudio change:

- `setup_lights` now uses Bevy's point-light transform, red color, intensity,
  range, shadow flag, and `VolumetricLight`.
- `setup_lights` now uses Bevy's spot-light transform looking at `Vec3::ZERO`,
  intensity, inner/outer angles, shadow flag, and `VolumetricLight`.
- Added the Bevy default `FogVolume` entity with scale `Vec3::splat(35.0)`.
- Removed the local manual directional-light spawn from this static setup; the
  authored glTF scene and later ISS-265 movement/tweak work own that path.
