## Description
`fog_volumes` should not be ported from memory or from the current mgstudio
shape. Before changing the scene, map the Bevy example source anchors and the
corresponding mgstudio fragments. This issue now groups smaller source-anchor
mapping slices instead of mixing the bunny density volume, camera, light, and
rotation system in one task.

## Design

- ISS-332 maps scene root, spawned entities, and hierarchy anchors.
- ISS-333 maps the bunny `FogVolume` component and density texture authoring.
- ISS-334 maps camera, directional light, and rotation system anchors.
