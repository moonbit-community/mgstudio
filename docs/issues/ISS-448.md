# ISS-448: Bind typed component columns once per table

## Metadata

- Status: closed

## Description

Required table-row fetch currently re-enters a `ComponentKey[T]` access closure,
looks up world-owned typed storage by world id, and then looks up the dense
column by table id for every row. Bind the typed column once when the iterator
enters a table, matching Bevy's `WorldQuery::set_table` boundary.

## Acceptance Criteria

- [x] Required table-row value access performs no per-row world-id or table-id
      map lookup after table binding.
- [x] Required table-row value access performs no per-row component-access
      closure dispatch after table binding.
- [x] Sparse-set and structural-migration semantics remain unchanged.
- [x] One focused ECS query test runs at a time with
      `MOONBIT_NEW_NATIVE=1`.
- [x] `examples/stress_tests/many_animated_sprite_meshes` is the only runtime
      example gate.
- [x] The retained/rejected decision follows the `ISS-444` experiment protocol.

## Notes

- 2026-07-15: Started after `ISS-447` showed that fetch-plan lifetime is not
  material. This experiment changes only the table-entry binding boundary: a
  typed component value array may be captured once per table, while sparse
  fetches, structural moves, matching, filters, and row-item semantics remain
  unchanged.
- 2026-07-15: The pre-change 20,000-row mutable query benchmark measured
  `6.20 ms`. The retained implementation must remove the typed storage
  world/table map lookups rather than merely add another cache lookup.
- 2026-07-15: Added a Bevy-style table-binding boundary to `QueryData`. Required
  `Read`, `ReadValue`, and `Write` fetches now capture their typed value arrays
  once when dense iteration enters a table. Tuple fetches compose the bound
  fetch functions, while the default implementation and sparse-anchor path
  retain the previous semantics.
- 2026-07-15: Focused tests passed individually for three-component iteration,
  `Read` change metadata, sparse non-dense cache behavior, `Write::modify`, and
  bound `Write::set` replacement/change marking. The native deny-warn ECS check
  also passed.
- 2026-07-15: The 20,000-row mutable query benchmark improved from `6.20 ms` to
  `3.94 ms` (`36.45%`). With identical trace filtering, the only runtime gate,
  `many_animated_sprite_meshes`, improved its animation system from
  `104.560 ms` to `97.327 ms` (`6.92%`). Stable whole-frame time moved from
  `311.103 ms` to `312.622 ms` (`0.49%` regression), within the protocol's
  `3%` noise allowance.

## Close Notes

Retained. Binding typed columns at table entry removes the measured per-row
world/table map and component-access closure path, exceeds the target-system
retention gate, and preserves the focused dense, sparse, write, and
change-detection semantics.
