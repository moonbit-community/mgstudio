# ISS-448: Bind typed component columns once per table

## Description

Required table-row fetch currently re-enters a `ComponentKey[T]` access closure,
looks up world-owned typed storage by world id, and then looks up the dense
column by table id for every row. Bind the typed column once when the iterator
enters a table, matching Bevy's `WorldQuery::set_table` boundary.

## Acceptance Criteria

- [ ] Required table-row value access performs no per-row world-id or table-id
      map lookup after table binding.
- [ ] Required table-row value access performs no per-row component-access
      closure dispatch after table binding.
- [ ] Sparse-set and structural-migration semantics remain unchanged.
- [ ] One focused ECS query test runs at a time with
      `MOONBIT_NEW_NATIVE=1`.
- [ ] `examples/stress_tests/many_animated_sprite_meshes` is the only runtime
      example gate.
- [ ] The retained/rejected decision follows the `ISS-444` experiment protocol.
