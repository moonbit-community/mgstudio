## Description
After light-node import is source-audited, mgstudio needs executable evidence
that the loaded runtime `Sun` node has the Bevy-equivalent hierarchy,
transform, and light component data.

## Design
Add or extend focused tests/wbtests that load the real
`VolumetricFogExample.glb`, locate the `Sun` node, and assert its parent-child
placement, local/global transform data, and light component fields that are
relevant to volumetric fog. Do not infer correctness from screenshot
brightness alone.

## Acceptance Criteria
- [x] A focused test locates the imported `Sun` node in the spawned runtime
      scene.
- [x] The test asserts hierarchy and transform behavior expected from Bevy's
      glTF import path.
- [x] The test asserts the light component fields required by ISS-319.
- [x] The relevant targeted `moon -C mgstudio-engine test ... --target native
      --release` command passes.

  the real `VolumetricFogExample.glb`, spawns the scene, propagates transforms,

  `moon -C mgstudio-engine test examples/3d/volumetric_fog --target native

  directional light child'`, `moon -C mgstudio-engine fmt`,
