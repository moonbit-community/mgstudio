## Description

Mutable row items carry `World`, entity identity, key, table id, row index, and
local component id to emulate borrow safety without MoonBit ownership. Test a
query/table-scoped lease and validity boundary so row iteration does not repeat
the full lifecycle context.

## Acceptance Criteria

- [ ] Use-after-scope, world close, structural invalidation, and nested-query
      behavior have focused regression coverage.
- [ ] The optimized row representation does not retain `World` solely for a
      check already guaranteed by the active query/table scope.
- [ ] One focused lifecycle test runs at a time with
      `MOONBIT_NEW_NATIVE=1`.
- [ ] `examples/stress_tests/many_buttons` is the only runtime example gate.
- [ ] The retained/rejected decision follows the `ISS-444` experiment protocol.
