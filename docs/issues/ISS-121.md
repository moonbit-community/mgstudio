## Description
`mgstudio-engine/examples/3d/deferred_rendering/main.mbt` is only a partial
source migration of `bevy/examples/3d/deferred_rendering.rs`.

The current example renders a deferred/prepass/forward comparison scene, but it
does not preserve Bevy's source shape. It uses global `DeferredState`, tracked
entities, direct world mutation, `Text2dBundle`, merged setup/parallax setup,
and tracked spin targets where Bevy uses ECS resources, `Local<T>`, command
buffers, queries, UI `Text`/`Node`, a separate `setup_parallax` startup system,
and a `Spin` component. It also changes several visible anchors: Bevy spheres
are cuboids, the emissive sphere loses its HDR color, and the directional light
uses an X-axis rotation instead of Bevy's Z-axis Euler rotation.

This is a local source-parity gap, not an external blocker.

## Design
Restore the example by following `bevy/examples/3d/deferred_rendering.rs`
symbol-by-symbol:

- Preserve `main` resource insertion order for
  `DefaultOpaqueRendererMethod::deferred()`, `DirectionalLightShadowMap`, and
  `Pause(true)`.
- Keep `setup` and `setup_parallax` as separate startup systems.
- Represent `Pause`, `Spin`, and the render-mode locals through Bevy-shaped ECS
  resource/component/local-state APIs rather than global tracked arrays.
- Preserve the Bevy camera tuple, directional light transform, FlightHelmet
  scene spawning, sky cuboid, parallax material fields, and UI text ownership.
- Use `Sphere::new(0.125).mesh().uv(32, 18)` for the emissive and colored
  spheres instead of cuboids.
- Preserve the HDR sphere color `Color::srgb(10.0, 4.0, 1.0)` and point-light
  color/default field semantics.
- Preserve `generate_tangents().unwrap()` for the parallax cube mesh.
- Make `switch_mode` source-shaped: use the same system parameters, mutate all
  cameras through a query, update `DefaultOpaqueRendererMethod` through
  `set_to_*`, keep the material-iteration invalidation hook, and preserve the
  exact Bevy help text.
- Remove local scaffolding that has no Bevy owner once equivalent ECS APIs are
  available.

If a required ECS API cannot express Bevy's system shape, record that as a
separate ECS blocker instead of silently keeping a workaround.

## Acceptance Criteria
- [ ] `deferred_rendering` keeps distinct `setup` and `setup_parallax` startup
      systems matching Bevy's source owner.
- [ ] The example uses ECS resource/component/local-state owners for `Pause`,
      `Spin`, render-mode state, and UI visibility instead of a global
      `DeferredState`.
- [ ] The directional light transform matches Bevy's
      `Quat::from_euler(EulerRot::ZYX, 0.0, 0.0, -FRAC_PI_4)` semantics.
- [ ] The emissive and colored objects use Bevy sphere geometry, not cuboids.
- [ ] The emissive material and point light preserve Bevy's HDR color and
      default-field semantics.
- [ ] The parallax cube mesh preserves tangent generation.
- [ ] `switch_mode` updates all camera entities, preserves the
      `DefaultOpaqueRendererMethod::set_to_*` calls, keeps the material
      iteration update trigger, and uses exact Bevy help text.
- [ ] A new reference screenshot is captured after the example first runs
      correctly.
