# ISS-405: Unblock fully qualified WGSL module function calls

## Description
Pinned Bevy shaders call functions by fully qualified composable-module path,
including `bevy_pbr::fog::linear_fog` in
`bevy_pbr/src/render/pbr_functions.wgsl` and
`irradiance_volume::irradiance_volume_light` in the same source owner. The
current `Milky2018/wgsl@0.16.0` and
`Milky2018/moon_wgsl_naga_oil@0.16.0` pipeline resolves a minimal qualified
module function call, but still misclassifies the corresponding call in the
complete pinned-Bevy deferred-lighting import graph as a WGSL type during IR
lowering. It reports `unsupported WGSL type` instead of resolving and
flattening `bevy_pbr::fog::linear_fog`.

This blocks both forward PBR and the real deferred-lighting pipeline whenever
the valid Bevy `DISTANCE_FOG` shader specialization is enabled. In
`examples/3d/deferred_rendering`, after the local false irradiance-volume key
was fixed, the valid Bevy distance-fog call fails every frame. In
`examples/3d/anti_aliasing`, the same specialization leaves only UI over the
clear color; removing only `DistanceFog` restores the complete scene.

## Design
Fix module-qualified function resolution in the external WGSL compose/IR
dependency. Do not edit copied Bevy WGSL, replace qualified calls with local
aliases, disable `DISTANCE_FOG`, or add an mgstudio-side preprocessing rewrite.
Those changes would hide the dependency gap and diverge from the pinned Bevy
source.

### EXT-405: Milky2018/wgsl lacks fully qualified module function lowering

- Dependency: `Milky2018/wgsl@0.16.0` with
  `Milky2018/moon_wgsl_naga_oil@0.16.0`.
- Missing capability: resolve the pinned-Bevy qualified function callee from
  the complete conditional composable-module graph and lower it as a function
  call. A two-module minimal call now succeeds, so that is no longer a valid
  reproduction of the remaining blocker.
- Bevy requirement: `bevy_pbr/src/render/pbr_functions.wgsl` calls
  `bevy_pbr::fog::linear_fog` and other module-qualified functions.
- Blocked Bevy source owner: `bevy_pbr/src/render/mesh.rs` forward mesh pipeline
  specialization and `bevy_pbr/src/deferred/mod.rs` deferred-lighting pipeline
  specialization and execution.
- Mgstudio implementation fragments affected:
  `mgstudio-engine/pbr/render/pbr_functions.wgsl`,
  `mgstudio-engine/pbr/material_pipeline_specializer.mbt`,
  `mgstudio-engine/pbr/deferred/deferred_lighting.wgsl`,
  `mgstudio-engine/render/renderer/mesh3d_pipeline_build.mbt`, and
  `mgstudio-engine/render/renderer/mesh3d_deferred_lighting.mbt`.
- Minimum local capability check:
  `moon -C mgstudio-engine test --target native --release --deny-warn
  shader/compile/namespace_function_external_blocker_test.mbt`; the test now
  requires successful composition and verifies that the qualified call is
  absent from emitted WGSL. The remaining runtime reproduction is the
  fixed-frame `examples/3d/deferred_rendering` capture with `DISTANCE_FOG`
  enabled.
- Verification expectation: update the reproduction to expect successful
  composition with no qualified callee left in the emitted WGSL; then capture
  both `examples/3d/anti_aliasing` with its complete fogged scene and
  `examples/3d/deferred_rendering` without a deferred-lighting shader fatal.
- Local substitute implementation: not allowed.
- Upstream/community link: not filed.
