## Description

World tables, archetypes, local component metadata, membership generations, and
several structural edges use `Map[Int, ...]` even though their IDs are dense and
monotonic. Replace only profile-proven hot dense-ID maps with direct indexed
arrays; signature-to-ID indexes remain maps.

## Acceptance Criteria

- [ ] Profiling identifies the exact map lookups on the selected hot path.
- [ ] Only dense-ID registries are converted; associative signature indexes are
      unchanged.
- [ ] Missing-ID and world-cleanup semantics remain explicit.
- [ ] One focused ECS structural test runs at a time with
      `MOONBIT_NEW_NATIVE=1`.
- [ ] `examples/stress_tests/transform_hierarchy` is the only runtime example
      gate.
- [ ] The retained/rejected decision follows the `ISS-444` experiment protocol.
