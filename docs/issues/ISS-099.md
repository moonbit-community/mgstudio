# ISS-099: Unblock strip-index-format render pipeline descriptors

## Description
Mgstudio needs Bevy-shaped indexed strip rendering for examples and render
parity work. Bevy stores the index format for strip topologies in the mesh
pipeline key and writes it into `PrimitiveState.strip_index_format`, allowing
`LineStrip` and `TriangleStrip` meshes to use primitive restart sentinels such
as `u16::MAX`.

`wgpu_mbt@0.14.2` exposes render pipeline descriptor builder setters for
topology and cull mode, but its C builder initializes
`WGPUPrimitiveState.stripIndexFormat` to `WGPUIndexFormat_Undefined` and does
not expose a setter. The official WebGPU C ABI has the field, so this is an
upstream binding gap rather than a wgpu-native limitation.

## Design
Do not add a project-local native stub in mgstudio. Keep mgstudio's mesh and
render descriptor data model source-shaped, then wire the final pipeline
builder call once wgpu_mbt exposes the field.

## Acceptance Criteria
- [x] wgpu_mbt exposes a safe builder API for setting strip index format to
      undefined, uint16, or uint32.
- [x] mgstudio passes `PrimitiveState.strip_index_format` into the wgpu_mbt
      render pipeline descriptor builder.
- [x] Indexed `LineStrip` with U16 primitive restart renders without a local
      native workaround.

## Notes
- 2026-06-14: Upstream request filed as moonbit-community/wgpu-mbt#28.
- 2026-06-14: Mgstudio now preserves 3D mesh index format and carries strip
  index format through `BaseMeshPipelineKey` and render `PrimitiveState`, but
  the final wgpu pipeline descriptor write remains blocked by wgpu_mbt.
- 2026-06-14: Native capture of `examples/3d/lines` confirms the blocker:
  wgpu validation aborts with "For indexed drawing with strip topology,
  RenderPipeline with '' label's strip index format None must match index
  buffer format Uint16".
- 2026-06-30: Rechecked against `wgpu_mbt@0.14.6`. The dependency now exposes
  `RenderPipelineDescBuilder::set_strip_index_format_u32`, and mgstudio writes
  `PrimitiveState.strip_index_format` into both render pipeline cache
  materialization and mesh2d descriptor pipeline creation. `moon -C
  mgstudio-engine check --target native --deny-warn` and `moon -C
  mgstudio-engine test --release render/renderer --deny-warn` pass. The native
  `examples/3d/lines` capture still failed to produce a blob and left an empty
  run log, so the issue is no longer an external binding blocker but is not
  visually closed yet.
- 2026-06-30: Final root cause was the 3D mesh pipeline builder path not
  passing `PrimitiveState.strip_index_format` into the native wgpu pipeline
  descriptor. After wiring the value through the mesh3d descriptor builder and
  removing an unrelated default shader define mismatch, native capture of
  `examples/3d/lines` renders both the line list and indexed U16 line strip.
  The run log is clean of WebGPU validation errors.
