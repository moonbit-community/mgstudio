# ISS-099: Unblock strip-index-format render pipeline descriptors

## Description
Mgstudio needs Bevy-shaped indexed strip rendering for examples and render
parity work. Bevy stores the index format for strip topologies in the mesh
pipeline key and writes it into `PrimitiveState.strip_index_format`, allowing
`LineStrip` and `TriangleStrip` meshes to use primitive restart sentinels such
as `u16::MAX`.

`wgpu_mbt@0.14.2` exposes render pipeline descriptor builder setters for
topology and cull mode, but its C builder initializes
`WGPUPrimitiveState.stripIndexFormat` to `WGPUIndexFormat_Undefined` and does
not expose a setter. The official WebGPU C ABI has the field, so this is an
upstream binding gap rather than a wgpu-native limitation.

## Design
Do not add a project-local native stub in mgstudio. Keep mgstudio's mesh and
render descriptor data model source-shaped, then wire the final pipeline
builder call once wgpu_mbt exposes the field.

## Acceptance Criteria
- [ ] wgpu_mbt exposes a safe builder API for setting strip index format to
      undefined, uint16, or uint32.
- [ ] mgstudio passes `PrimitiveState.strip_index_format` into the wgpu_mbt
      render pipeline descriptor builder.
- [ ] Indexed `LineStrip` with U16 primitive restart renders without a local
      native workaround.
