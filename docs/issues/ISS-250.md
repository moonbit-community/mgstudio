# ISS-250: Verify volumetric fog GpuLights host layout and byte packing

## Description
Bevy's volumetric fog shader reads directional-light data through the shared
mesh-view lights uniform. Mgstudio must pack `GpuLights3d`,
`GpuDirectionalLight3d`, and `GpuDirectionalCascade3d` with the same field
order, numeric encoding, padding, and fixed array sizes as Bevy's
`GpuLights`, `GpuDirectionalLight`, and `GpuDirectionalCascade`.

## Design
Compare Bevy `bevy_pbr/src/render/light.rs` host uniform structs and upload
path with mgstudio `pbr/render/light.mbt`. Fix local layout divergence
source-faithfully. If MoonBit lacks a layout feature, keep explicit byte packing
but make it mirror the Bevy struct shape exactly and cover it with tests.

## Acceptance Criteria
- [x] `GpuDirectionalCascade3d` packing matches Bevy's matrix, texel size, far
      bound, and padding semantics.
- [x] `GpuDirectionalLight3d` packing matches Bevy field order, flags, cascade
      count, depth texture base index, decal index, and sun-disk fields.
- [x] `GpuLights3d` packing matches Bevy directional-light array, ambient
      fields, cluster fields, directional count, shadow map offset, and rect
      light tail layout.
- [x] Existing renderer fallback paths do not silently replace the Bevy-shaped
      PBR lights uniform for volumetric fog.
- [x] Focused byte-layout tests cover at least one directional light with two
      cascades and non-default scalar fields.
