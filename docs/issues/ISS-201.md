## Description
`scrolling_fog` can only be accepted after mgstudio proves that the embedded
`volumetric_fog.wgsl` text and the shader specialization inputs match Bevy.
This issue covers the shader source, shader defs, pipeline keys, bind-group
layout selection, and hull vertex layout inputs that decide which WGSL path is
compiled and executed.

## Design
Compare Bevy `bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl` and
`bevy_pbr/src/volumetric_fog/render.rs` against mgstudio's embedded shader,
`VolumetricFogPipelineKey`, pipeline specialization, and renderer pipeline cache
inputs. Do not edit WGSL as a workaround; if a parser or backend rejects Bevy
source text, record a precise blocker.

## Acceptance Criteria
- [x] Mgstudio's embedded `volumetric_fog.wgsl` matches the Bevy source, or any
      unavoidable divergence is recorded as a blocker.
- [x] Shader defs for density textures, MSAA, atmosphere, and shadow filtering
      are derived from the same source-owned inputs as Bevy.
- [x] The volumetric fog pipeline key includes the Bevy-equivalent target
      format, mesh view key, hull vertex layout, and density-texture state.
- [x] Focused tests or audit notes identify the exact files and symbols checked.

## Close Notes
Closed on 2026-07-04.

Audited Bevy owner symbols in
`bevy/crates/bevy_pbr/src/volumetric_fog/render.rs`:
`VolumetricFogBindGroupLayoutKey`, `VolumetricFogPipelineKey`,
`SpecializedRenderPipeline for VolumetricFogPipeline`, and
`prepare_volumetric_fog_pipelines`. `diff -u
bevy/crates/bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl
mgstudio-engine/pbr/volumetric_fog/volumetric_fog.wgsl` produced no output, so
the embedded shader source remains Bevy-identical.

Fixed a local source-shape gap where mgstudio reduced Bevy's
`MeshVertexBufferLayoutRef` specialization input to `vertex_stride_bytes`.
`VolumetricFogPipelineKey` and the renderer pipeline cache now carry the
Bevy-equivalent `VertexBufferLayout`; the renderer derives the hull position
layout from `MeshVertexBufferLayout::get_layout([POSITION @ location 0])` and
applies all vertex attributes when creating the volumetric fog pipeline.
