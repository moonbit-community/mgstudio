# ISS-005: Make skinned mesh bounds dirty-driven and joint-cache backed

## Description
Dynamic skinned bounds currently cost about `8.587 ms/frame`. Every fox with a
skinned mesh walks joint bounds and fetches joint global transforms, which
duplicates part of the pressure already present in skin extraction.

## Design
Port the current Bevy skinned-bounds invalidation and recomputation behavior as
closely as possible. The target is a bounds path that uses maintained joint row
caches as the primary fetch route and recalculates only when source-equivalent
dirty conditions require it.

## Acceptance Criteria
- [ ] The bounds system reports skinned entities processed, joint bounds processed, joint cache hits/misses, and AABB writes.
- [ ] Joint table-row caches are the normal fetch path, not a fallback.
- [ ] Bounds are not recalculated when relevant joint transforms and mesh bounds are unchanged.
- [ ] Bounds remain visually and functionally correct for animated foxes.
- [ ] At `1000` foxes, skinned mesh bounds are reduced below `3 ms/frame` or a follow-up issue documents the remaining blocker.
- [ ] Relevant mesh and visibility tests pass with `--release`.
