## Description
The `scrolling_fog` light-shaft signal depends on Bevy's volumetric fog shader
combining density, directional light scattering, and directional shadow
visibility in the same way. If the shader text, imported helper functions,
specialization definitions, or texture sampling semantics diverge, the scene can
have valid inputs but still render without the reference diagonal shaft.

This issue is the aggregation point for that verification. The executable work
is split into smaller source-owner issues so the final result is not accepted
from a single plausible screenshot.

## Design
Audit Bevy `bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl` and every imported
helper used for directional shadow visibility against mgstudio's WGSL assets and
shader composition output. Keep WGSL assets in Bevy form. If a parser or
dependency prevents exact source shape, record the external blocker instead of
rewriting shader logic locally.
