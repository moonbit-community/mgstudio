## Description
Bevy's `volumetric_fog` example uses `AppSettings`, `create_text`, and
`adjust_app_settings` so `P` and `L` insert/remove `VolumetricLight` from
point and spot lights and update the displayed text.

## Design
Use the child issues for executable work:

- ISS-290 ports `AppSettings` and the Bevy-shaped help text construction.
- ISS-291 ports `adjust_app_settings` and `VolumetricLight` insertion/removal.
- ISS-292 validates that the toggles reach render-visible volumetric-light
  state.

Do not approximate toggles by changing light intensity, fog density, or
renderer flags.
