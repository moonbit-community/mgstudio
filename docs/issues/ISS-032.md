## Description
The `ScreenshotAndExit` bug exposed a real source-shape drift in
`mgstudio-engine/dev_tools/ci_testing`: it previously polled screenshot
components in a local pending list, while Bevy writes `AppExit::Success` from
the `ScreenshotCaptured` observer. That specific bug is fixed, but the owner is
still only partial compared with `bevy_dev_tools/src/ci_testing`.

Bevy's plugin loads `CiTestingConfig` from `CI_TESTING_CONFIG`/RON by default,
adds `EasyCameraMovementPlugin` when missing, conditionally adds screen
recording support, configures fixed frame time, registers
`CiTestingCustomEvent`, and schedules `systems::send_events` in `Update` before
`trigger_screenshots`, before `close_when_requested`, and before terminal
Ctrl-C exit handling. Mgstudio currently reads only a small set of environment
variables, has no event-sender set ordering equivalent, and lacks the
screen-recording event surface.

## Design
Audit `bevy/crates/bevy_dev_tools/src/ci_testing/{config.rs,mod.rs,systems.rs}`
and port every in-scope item. Keep the fixed-frame and screenshot exit behavior
that now works, but replace local-only configuration and scheduling shortcuts
with Bevy-shaped plugin build behavior. If RON parsing or screen recording needs
dependencies that do not exist in MoonBit, record those as blockers; otherwise
implement them directly.

## Acceptance Criteria
- [ ] `CiTestingConfig`, `CiTestingSetup`, `CiTestingEventOnFrame`, and `CiTestingEvent` cover Bevy's in-scope fields and variants, including start/stop screen recording or a recorded blocker.
- [ ] Plugin build reads config from an existing resource or default config file semantics equivalent to Bevy, with environment-only configuration kept only where it is explicitly documented as an additional mgstudio test convenience.
- [ ] `send_events` has Bevy-equivalent schedule ordering before screenshot triggering, window close handling, and terminal Ctrl-C handling.
- [ ] `ScreenshotAndExit` continues to save the screenshot and write `AppExit::Success` from the capture observer.
- [ ] Relevant `dev_tools` and screenshot tests pass with `--release`, and the motion_blur screenshot-exit gate remains green.
