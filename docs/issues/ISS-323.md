## Description
`ISS-302` is too broad as a single audit item because scene spawn and transform
propagation involve separate Bevy owners. This leaf issue proves the
`examples/3d/volumetric_fog` scene root, glTF node hierarchy, local transforms,
and propagated global transforms match the Bevy source shape before render-side
mesh extraction is blamed.

## Design
Audit Bevy scene spawn and transform propagation anchors, map the mgstudio
fragments that implement them, then add or update focused runtime evidence for
the real `VolumetricFogExample.glb` scene. Do not move the camera, edit assets,
or hide the divergence with culling or visibility tweaks.
