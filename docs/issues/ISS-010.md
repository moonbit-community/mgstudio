## Description
Mesh preparation costs about `3.096 ms/frame`. It is not the first optimization
target, but it remains large enough that it may become a blocker after transform,
animation, skinning, and render execution improve.

## Design
Do not prematurely rewrite mesh preparation. Re-profile after the higher-priority
issues are closed, then port any remaining differences from Bevy's mesh prepare
path directly.

## Acceptance Criteria
- [ ] Mesh preparation has counters for prepared meshes, buffer uploads, skipped unchanged meshes, and cache hits.
- [ ] The post-optimization profile states whether mesh preparation remains above `1 ms/frame`.
- [ ] Any remaining implementation changes are source-equivalent to Bevy's mesh preparation logic.
- [ ] Relevant mesh and render tests pass with `--release` if code changes are made.
