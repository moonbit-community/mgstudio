## Description

The updated MoonBit toolchain reports warning 83 (`type_param_method`) for
legacy method-call syntax whose receiver is a type parameter. A focused ECS
package check remains warning-free, but building `many_foxes` currently reports
these warnings in unrelated application, render, PBR, sprite, and animation
packages. This prevents a repository-level warning-zero gate from being used as
evidence for the dense ECS table experiment.

Migrate each affected call to the explicit defining-trait form without changing
runtime behavior or public interfaces. Keep this repository-wide syntax
migration separate from ISS-442 so the dense-storage branch remains easy to
evaluate or discard.

## Acceptance Criteria
- [ ] Every warning 83 reported by the updated MoonBit toolchain is removed.
- [ ] A focused test for each touched package passes before moving to the next
  package.
- [ ] `many_foxes` builds for native release with warnings denied and
  `MOONBIT_NEW_NATIVE=1`.
- [ ] Public interface output is unchanged.
- [ ] No runtime or scheduling behavior changes are introduced.
