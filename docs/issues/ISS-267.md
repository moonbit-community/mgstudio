## Description
Bevy `examples/3d/fog_volumes.rs` spawns a real `FogVolume` using
`volumes/bunny.ktx2`, with density and scattering values chosen for the
Stanford bunny fog volume.

## Design
Port the fog-volume entity directly. Remove proxy translucent bunny meshes,
distance-fog substitutions, or generated geometry from the parity path.

## Acceptance Criteria
- [ ] The example spawns `FogVolume { density_texture:
      Some("volumes/bunny.ktx2"), density_factor: 1.0, scattering: 1.0, .. }`.
- [ ] The transform matches Bevy's `(0.0, 0.5, 0.0)` placement.
- [ ] The bunny density texture resolves without missing-resource output.
- [ ] No proxy geometry is used to fake the fog-volume result.
