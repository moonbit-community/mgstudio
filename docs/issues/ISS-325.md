## Description
The `volumetric_fog` visual failure can still come from phase inclusion or
material/depth state after scene import and extraction are correct. This leaf
issue owns the Bevy-shaped queueing path for the frame-dominating `Cube`
contributor: which phase it enters, which pipeline/material state is selected,
and whether its depth/culling behavior matches Bevy.

## Design
Audit Bevy PBR phase queue and material specialization anchors that decide the
mesh's draw phase, depth writes/tests, culling, and alpha behavior. Compare the
mgstudio fragments and add focused evidence for the real example contributor.
Do not accept a plausible screenshot as proof for this issue.

## Acceptance Criteria
- [x] Bevy source anchors for phase queueing and relevant material/depth state
      selection are listed.
- [x] Mgstudio fragments implementing those anchors are listed.
- [x] Focused evidence proves the `Cube` primitive's phase inclusion,
      specialized material/depth state, and draw eligibility.
- [x] Any local divergence is fixed here or assigned to `ISS-305` with exact
      source-owner evidence.
