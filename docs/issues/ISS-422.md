# ISS-422: Release motion-vector resource owners

## Description
Motion-vector layouts, pipelines, view bind-group caches, mesh slots, uniform buffers, and instance-mesh resources own native handles independently from the main Mesh3d pass.

## Design
Add exact release operations for motion-vector cache entries and slots, replace frame-boundary raw clearing, and attach the complete motion-vector owner teardown to backend shutdown.

## Acceptance Criteria
- [x] Motion-vector layouts, fixed pipelines, specialized pipeline cache entries, and mesh layouts are released.
- [x] View bind-group caches and frame-boundary replacement release their owned bind groups.
- [x] Mesh slots, view/global/previous-view buffers, and instance-mesh resources are released.
- [x] Native WGPU report coverage returns representative motion-vector handles to baseline.

## Notes

`mesh3d_motion_vector_view_bg_cache` contains borrowed aliases to bind groups owned by the active frame's transient list. Frame retirement releases those handles; the cache must only discard its MoonBit aliases and is intentionally not released a second time.

## Close Notes

Integrated motion-vector fixed and specialized pipelines, specialized mesh layouts, base bind-group layouts, buffers, owning bind groups, mesh slots, and instance-mesh resources into backend shutdown. A native aggregate test verifies all exercised handle categories return to zero.
