## Description
Motion-vector layouts, pipelines, view bind-group caches, mesh slots, uniform buffers, and instance-mesh resources own native handles independently from the main Mesh3d pass.

## Design
Add exact release operations for motion-vector cache entries and slots, replace frame-boundary raw clearing, and attach the complete motion-vector owner teardown to backend shutdown.

## Acceptance Criteria
- [ ] Motion-vector layouts, fixed pipelines, specialized pipeline cache entries, and mesh layouts are released.
- [ ] View bind-group caches and frame-boundary replacement release their owned bind groups.
- [ ] Mesh slots, view/global/previous-view buffers, and instance-mesh resources are released.
- [ ] Native WGPU report coverage returns representative motion-vector handles to baseline.
