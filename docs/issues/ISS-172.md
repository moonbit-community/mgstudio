## Description
Bevy extracts and syncs `VolumetricFog`, `FogVolume`, and `VolumetricLight`
into render-world state before prepare/render systems consume them. Mgstudio
currently collects several of these inputs inside the camera render execution
path, which is behaviorally close for simple scenes but not source-shaped and
makes cleanup/lifecycle parity fragile.

## Design
Use this issue as the parent for the extraction/sync migration. The executable
work is split into smaller source-owner slices:

- ISS-175 defines the render-world volumetric fog storage and entity identity
  mapping.
- ISS-176 ports Bevy's `extract_volumetric_fog` copy and cleanup semantics.
- ISS-177 removes source-world discovery from camera prepare and consumes the
  extracted render-world state.

## Acceptance Criteria
- [ ] ISS-175, ISS-176, and ISS-177 are closed.
- [ ] Render-world state contains extracted volumetric fog view, volume, and light data before the camera render pass starts.
- [ ] Camera render execution no longer performs source-world volumetric fog discovery as a local side effect.
