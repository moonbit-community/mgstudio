## Description
Prove that the real `examples/3d/volumetric_fog` fog pass binds and samples the
same directional shadow depth texture and sampler assumptions that Bevy uses
for volumetric fog shadowing.

## Design
Use the source-anchor map from ISS-385. Compare Bevy's directional shadow
texture view, binding slot, sampler/filter assumptions, and shader sampling
path against mgstudio's real fog pass inputs. This issue should prove texture
and sampler identity/compatibility only; cascade record values belong to
ISS-387.

## Close Notes
Closed on 2026-07-05.

Bevy source evidence:

- `bevy/crates/bevy_pbr/src/render/light.rs::ShadowSamplers` owns distinct
  `point_light_comparison_sampler` and `directional_light_comparison_sampler`
  resources. `init_shadow_samplers` creates both comparison samplers with
  `CompareFunction::GreaterEqual`, clamp-to-edge addressing, linear min/mag
  filtering, and nearest mip filtering.
- `bevy/crates/bevy_pbr/src/render/mesh_view_bindings.rs` binds
  `shadow_bindings.directional_light_depth_texture_view` at view binding 5 and
  `shadow_samplers.directional_light_comparison_sampler` at view binding 6.
- `bevy/crates/bevy_pbr/src/render/mesh_view_bindings.wgsl` declares
  `directional_shadow_textures` at group 0 binding 5 and
  `directional_shadow_textures_comparison_sampler` at group 0 binding 6.
- `bevy/crates/bevy_pbr/src/render/shadow_sampling.wgsl::sample_shadow_map_hardware`
  samples the binding 5 directional shadow texture with the binding 6
  comparison sampler.
- `bevy/crates/bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl` computes
  `array_index = depth_texture_base_index + cascade_index` and calls
  `sample_shadow_map_hardware(light_local.xy, light_local.z, array_index)`.

Mgstudio source evidence and repair:

- `mgstudio-engine/pbr/render/mesh_view_bindings.wgsl`,
  `mgstudio-engine/pbr/render/shadow_sampling.wgsl`, and
  `mgstudio-engine/pbr/volumetric_fog/volumetric_fog.wgsl` match the Bevy
  shader binding and sampling anchors.
- `mgstudio-engine/render/renderer/mesh3d_volumetric_fog_pass.mbt` resolves the
  real `directional_shadow_texture_id` when the pass input is nonnegative and
  forwards the resolved texture into `mesh3d_frame_view_bg_cache_get_or_create`.
- `mgstudio-engine/render/renderer/mesh3d_bind_groups.mbt` now mirrors Bevy's
  source shape by owning separate point and directional comparison samplers.
  Binding 3 receives the point comparison sampler and binding 6 receives the
  directional comparison sampler, both using Bevy's comparison sampler
  descriptor.
- `mgstudio-engine/render/renderer/backend_state.mbt` and
  `mgstudio-engine/render/renderer/backend_init.mbt` now include a distinct
  `mesh3d_directional_shadow_compare_sampler` cache slot initialized to `None`.

Verification:

  passed with 1/1 tests.

No hard external blocker was found. The only divergence discovered by ISS-385,
