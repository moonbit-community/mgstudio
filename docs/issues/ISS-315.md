## Description
The `VolumetricFogExample.glb` Cube primitive must have the Bevy-equivalent
local transform and runtime AABB after mgstudio scene loading and spawning.
This issue adds focused runtime evidence so the source audit has an executable
guard.

## Design
Extend the volumetric fog example's focused tests or wbtests to locate the Cube
primitive contributor, then assert the imported local transform and AABB data
that correspond to the Bevy anchors from ISS-311. Keep the test tied to real
scene loading and ECS state, not screenshot color alone.

## Acceptance Criteria
- [x] A focused test locates the Cube primitive contributor in the spawned
      runtime scene.
- [x] The test asserts the local transform expected from Bevy mesh conversion
      semantics.
- [x] The test asserts the runtime AABB expected from the glTF primitive
      bounds.
- [x] `moon -C mgstudio-engine test examples/3d/volumetric_fog --target native
      --release` passes.
