## Description
Bevy's `adjust_app_settings` system toggles the point light and spotlight
volumetric state with `P` and `L` by inserting or removing `VolumetricLight`
components and updating `AppSettings`.

## Design
Port the key checks, resource mutation, command insertion/removal, and target
entity selection directly. Do not approximate disabled volumetric lighting by
changing light intensity, shadow flags, fog density, or renderer-local state.

## Acceptance Criteria
- [x] `P` toggles the point light's `VolumetricLight` component.
- [x] `L` toggles the spotlight's `VolumetricLight` component.
- [x] The stored `AppSettings` booleans stay in sync with the component
      insertion/removal behavior.
- [x] A focused test covers at least one enable and one disable path.
