## Description
The 2026-06-24 all-reference visual audit initially left already-captured
example executables running after `p0_visual_capture_native.sh` reported a
successful capture. The observed residual processes included completed 2D
examples under `mgstudio-engine/_build/native/release/build/examples/...`.

This makes broad visual auditing unsafe: every completed example can keep
owning a native window/process, consume resources, and interfere with later
captures.

## Design
The native capture script must make the background process identity match the
real example executable. The prior shell subshell launched the example as a
child and the cleanup path could terminate the wrapper without reliably
terminating the native example. Replace the wrapper command with exported
capture environment variables followed by `exec "${APP_EXE}"`, so `APP_PID`
tracks the native example process directly.

## Acceptance Criteria
- [x] Completed captures do not leave the captured example executable running.
- [x] A smoke capture of `examples/2d/2d_shapes` still matches its
      `reference.png`.
- [x] The process table contains no residual `2d_shapes.exe` after the smoke
      capture exits.
