## Description
The current `scrolling_fog` capture is brighter than the checked-in reference
and lacks strong pillar shadow/light-shaft structure. One high-risk input is the
view-depth texture sampled by `volumetric_fog.wgsl`: Bevy binds the current
view's `ViewDepthTexture`, while mgstudio must prove it is not accidentally
binding a stale, global, MSAA-incompatible, or otherwise wrong depth view.

## Design
Track the view-depth chain as small source-owner slices:

- ISS-206 verifies that volumetric-fog cameras request Bevy-equivalent sampled
  depth usage before depth target creation.
- ISS-207 verifies that the active camera's just-rendered main-pass depth view
  is preserved across the post-main volumetric fog boundary.
- ISS-208 verifies that the renderer's volumetric fog bind group consumes that
  active view depth texture instead of a stale or global fallback.
- ISS-209 verifies the MSAA/non-MSAA sampling semantics against Bevy and records
  a precise blocker if the backend cannot express the same path.
- ISS-210 verifies the WGSL reconstruction inputs and captures evidence that
  foreground depth changes the fog result.

Fix local ownership or binding divergence at the render-pass boundary rather
than altering shader math.

## Acceptance Criteria
- [x] ISS-206, ISS-207, ISS-208, ISS-209, and ISS-210 are closed.
- [x] The final child issue proves that foreground geometry depth affects

- [x] Any remaining non-local backend limitation is recorded as a blocker with
      an exact upstream dependency and missing capability.

## Close Notes
2026-07-04: Closed the view-depth texture parity group after all child slices
were completed.

  creation when render-world volumetric fog exists.
- ISS-207 fixed the real source-shape bug: volumetric fog no longer reads a
  renderer-global `backend.depth_view`; `GpuPassState` now carries the active
  pass `view_depth_texture_id` and `view_depth_view`.

  view at binding 1 and does not use a global fallback.
- ISS-209 verified non-MSAA/MSAA depth texture layout specialization matches
  Bevy and found no native backend blocker.
- ISS-210 collected runtime evidence from `examples/3d/scrolling_fog` proving
  foreground depth affects volumetric fog reconstruction.
