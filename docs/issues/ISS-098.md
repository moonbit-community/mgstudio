# ISS-098: Expose Bevy binding-array capability checks through wgpu_mbt

- Status: blocked

## Description
Bevy gates PBR binding arrays with
`binding_arrays_are_usable(RenderDevice, RenderAdapter)`, which checks adapter
info, render-device limits, and the device features
`TEXTURE_BINDING_ARRAY` plus
`SAMPLED_TEXTURE_AND_STORAGE_BUFFER_ARRAY_NON_UNIFORM_INDEXING`.
Clustered decals are then gated by `clustered_decals_are_usable`, which
currently delegates to the binding-array gate plus the clustered-decals feature.

Mgstudio cannot source-match this decision with the current `wgpu_mbt` surface.
Forcing the capability on produces native validation failures:

`Capability Capabilities(TEXTURE_AND_SAMPLER_BINDING_ARRAY) is not supported`

and invalid binding-array bind groups. Therefore mgstudio must keep
`Render3dMeshRuntimeState.binding_arrays_are_usable` and
`clustered_decals_are_usable` disabled until `wgpu_mbt` exposes enough feature
and limit queries, and the device request path can enable the required features
when available.

## Design
Do not hard-code binding-array support and do not keep local shader or renderer
fallbacks. The correct fix is a thin `wgpu_mbt` API surface that lets mgstudio
port Bevy's capability gate directly:

- render-device feature query for `TEXTURE_BINDING_ARRAY`;
- render-device feature query for
  `SAMPLED_TEXTURE_AND_STORAGE_BUFFER_ARRAY_NON_UNIFORM_INDEXING`;
- render-device limit query for `max_storage_textures_per_shader_stage`;
- adapter info access sufficient for the Bevy Adreno exclusion;
- device-request support for the required native features when available.

## Acceptance Criteria
- [ ] `wgpu_mbt` exposes the feature, limit, adapter-info, and device-request
      APIs needed to implement Bevy's `binding_arrays_are_usable` gate.
- [ ] Mgstudio computes `binding_arrays_are_usable` from the real device and
      adapter instead of using a fixed default.
- [ ] Mgstudio computes `clustered_decals_are_usable` from the binding-array
      gate and the clustered decal feature flag.
- [ ] `examples/3d/clustered_decal_maps` can enable Bevy's clustered decal
      shader path only on adapters that actually support the required
      capability.
