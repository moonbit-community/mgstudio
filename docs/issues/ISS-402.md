# ISS-402: Unblock meshlet example on MoonBit new native backend

## Metadata
- Type: bug
- Status: blocked
- Priority: 1
- Labels: meshlet, moonbit, native-backend, external-blocker, visual-gate
- Assignee: unassigned
- Created: 2026-07-06
- Updated: 2026-07-06
- External ref: MoonBit compiler issue not filed yet

## Description
`examples/3d/meshlet` cannot currently serve as the required
`MOONBIT_NEW_NATIVE=1` visual gate because the MoonBit compiler ICEs during the
native release build. The error happens before mgstudio runtime startup, so this
is a hard toolchain blocker rather than a Bevy parity bug in the meshlet render
path.

Observed command:

```sh
MOONBIT_NEW_NATIVE=1 MGSTUDIO_PARITY_CAPTURE_DELAY_FRAMES=90 \
  MGSTUDIO_PARITY_RUN_TIMEOUT_SECONDS=240 \
  mgstudio-engine/scripts/p0_visual_capture_native.sh \
  examples/3d/meshlet /tmp/mgstudio_iss394_meshlet.png
```

Observed compiler error:

```text
Machine_error(kind=unsupported; who="Machine_of_clam_lower.lower_scalar_runtime_pccall"; message="unit runtime pccall cannot be used as a scalar value"; function="@_M0MP49Milky20188mgstudio3pbr7meshlet18MeshletMeshManager25queue__upload__if__needed")
```

## Design
Keep the meshlet source path faithful to Bevy and do not add a mgstudio-side
workaround just to avoid this compiler path. Reduce the ICE to a minimal
MoonBit reproducer if needed, file it upstream against the MoonBit compiler, and
re-enable the meshlet visual gate only after the backend can compile the real
`MeshletMeshManager::queue_upload_if_needed` path.

## Acceptance Criteria
- [ ] A minimal MoonBit reproducer or the full meshlet build error is filed
      upstream for the new native backend ICE.
- [ ] `MOONBIT_NEW_NATIVE=1 moon -C mgstudio-engine run
      examples/3d/meshlet --target native --release` builds without compiler
      ICE.
- [ ] The standard meshlet visual capture command succeeds without switching to
      the old native backend or adding a local workaround.
- [ ] The meshlet screenshot is compared against the current local reference
      and Bevy baseline expectation.
