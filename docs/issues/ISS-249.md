# ISS-249: Map volumetric fog directional light WGSL reads

## Description
Before fixing host packing, identify the exact WGSL fields that Bevy's
`volumetric_fog.wgsl` reads for directional light scattering and shadow
visibility. The output must be a symbol-level map from WGSL read site to Bevy
producer and mgstudio producer.

## Design
Audit Bevy `bevy_pbr/src/volumetric_fog/volumetric_fog.wgsl` and the imported
mesh-view/light helper definitions it uses. Record each field read from
`lights`, each directional cascade field, each shadow texture/sampler binding,
and any dynamic-offset dependent uniform access. This issue is audit-only unless
a missing local owner is discovered; any discovered implementation gap should
be assigned to ISS-250, ISS-251, or ISS-252.

## Acceptance Criteria
- [x] Every directional-light field read by `volumetric_fog.wgsl` is listed
      with the Bevy producer symbol and mgstudio producer symbol.
- [x] Every cascade field read by `volumetric_fog.wgsl` is listed with field
      order, numeric type, and array indexing semantics.
- [x] Directional shadow texture and sampler binding reads are listed with the
      Bevy mesh-view bind group slot and mgstudio equivalent.
- [x] Any unmapped field becomes a follow-up implementation issue before this
      audit closes.

- 2026-07-04: Directional-light WGSL read map:
  `volumetric_fog.wgsl:189` reads `lights.n_directional_lights`.
  Bevy producer is `bevy_pbr/src/render/light.rs::prepare_lights`, which writes
  `GpuLights.n_directional_lights` and uploads it through
  `ViewLightsUniformOffset { offset: view_gpu_lights_writer.write(&gpu_lights) }`.
  Mgstudio producer is `pbr/render/light.mbt::render3d_collect_gpu_lights`,
  field `GpuLights3d.n_directional_lights`, serialized by
  `render3d_gpu_lights_uniform_bytes`.
- 2026-07-04: `volumetric_fog.wgsl:230-238` reads
  `lights.directional_lights[light_index].flags`, `.direction_to_light`, and
  `.shadow_depth_bias`. Bevy producers are
  `GpuDirectionalLight.flags`, `.dir_to_light`, and `.shadow_depth_bias` in
  `bevy_pbr/src/render/light.rs::prepare_lights`; flags use
  `DirectionalLightFlags::{VOLUMETRIC, SHADOW_MAPS_ENABLED,
  CONTACT_SHADOWS_ENABLED, AFFECTS_LIGHTMAPPED_MESH_DIFFUSE}` with the bit
  values mirrored by `mesh_view_types.wgsl`. Mgstudio producers are
  `GpuDirectionalLight3d.flags`, `.dir_to_light`, and `.shadow_depth_bias` in
  `pbr/render/light.mbt::render3d_collect_gpu_lights`, with bit constants
  `DIRECTIONAL_LIGHT_FLAG_*` matching the WGSL constants. ISS-250 owns byte
  layout verification for these fields.
- 2026-07-04: Cascade WGSL read map:
  `shadows.wgsl:get_cascade_index` reads `DirectionalLight.num_cascades` and
  `DirectionalLight.cascades[i].far_bound`; `world_to_directional_light_local`
  reads `DirectionalLight.cascades[cascade_index].clip_from_world`;
  `volumetric_fog.wgsl:301` reads
  `DirectionalLight.depth_texture_base_index`. The WGSL cascade field order is
  `clip_from_world: mat4x4<f32>`, `texel_size: f32`, `far_bound: f32`, with
  shader-layout padding supplied by the host packing. Bevy initializes
  `num_cascades`, `cascades_overlap_proportion`, and
  `depth_texture_base_index` in `prepare_lights`, then fills each
  `GpuDirectionalCascade { clip_from_world, texel_size, far_bound }` from the
  current view's cascade/frustum/bounds data. Mgstudio maps these to
  `GpuDirectionalLight3d.num_cascades`,
  `GpuDirectionalLight3d.cascades_overlap_proportion`,
  `GpuDirectionalLight3d.depth_texture_base_index`, and
  `GpuDirectionalCascade3d { clip_from_world, texel_size, far_bound }` in
  `pbr/render/light.mbt`. ISS-251 owns verification that current-frame shadow
  cascade data overrides the same light uniform path.
- 2026-07-04: Directional shadow binding map:
  `shadow_sampling.wgsl:11-27` samples
  `view_bindings::directional_shadow_textures` and
  `view_bindings::directional_shadow_textures_comparison_sampler`.
  Bevy declares these as mesh-view group 0 binding 5 and binding 6 in
  `mesh_view_bindings.wgsl`, populated from
  `ViewShadowBindings.directional_light_depth_texture_view` by the mesh-view
  bind group owner and reused by `volumetric_fog` through `MeshViewBindGroup`.
  Mgstudio declares the same WGSL slots and routes runtime resources through
  `pbr/render_execute_camera_main_pass.mbt::prepare_view_bind_group` and
  `render/renderer/mesh3d_volumetric_fog_pass.mbt`, where group 0 is set from
  the mesh-view bind-group cache. ISS-252 owns source-level verification of the
  binding slots and dynamic offsets.
- 2026-07-04: Atmosphere-dependent directional reads:
  inside the `ATMOSPHERE` block, `volumetric_fog.wgsl:321` reads
  `DirectionalLight.sun_disk_angular_size`; the atmosphere helper path also
  depends on the same `direction_to_light`. Bevy producers are
  `GpuDirectionalLight.sun_disk_angular_size` and `.sun_disk_intensity` from
  `prepare_lights`. Mgstudio producers are
  `GpuDirectionalLight3d.sun_disk_angular_size` and `.sun_disk_intensity` from
  `render3d_collect_gpu_lights`. ISS-250 owns byte-layout coverage for these
  tail fields.
- 2026-07-04: No new unmapped field or external blocker was found in this
  audit. The remaining executable work is already split into ISS-250 through
  ISS-253.
