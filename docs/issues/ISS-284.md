## Description
Bevy's volumetric fog pass binds the mesh-view group and per-volume fog group,
uses dynamic uniform offsets, selects plane or cube fog hull meshes, draws the
hull, and loads/blends into the main color target.

## Design
Audit bind group construction, dynamic offsets, optional density texture
branching, hull mesh selection, indexed/non-indexed draw range, color load, and
additive blend behavior against Bevy.

## Close Notes
Closed 2026-07-09. Bevy binds mesh-view group 0 with view dynamic offsets and
binds volumetric-fog group 1 with `[view_fog_volume.uniform_buffer_offset]`;
mgstudio mirrors this via `mesh3d_frame_view_bg_cache_get_or_create`,
`render_pass.set_bind_group(0U, view_bg, view_offsets)`, and
`mesh3d_volumetric_fog_dynamic_offsets(volume)`. Optional density textures
select the textured pipeline only when a render texture resolves to `Some(_)`;
missing density assets use the textureless branch. Interior volumes select the
plane hull and exterior volumes select the cube hull. Indexed draws use
`index_start`, `index_count`, and `vertex_start`; non-indexed draws use
`vertex_start` and `vertex_count`, matching Bevy's render-mesh buffer-info
branches.

Color attachment behavior is Bevy-shaped: the pass loads and stores the main
color target, has no resolve target, and has no depth attachment. Additive
alpha blend is owned by `VolumetricFogPipeline::specialize` and covered by the
pipeline descriptor tests.
