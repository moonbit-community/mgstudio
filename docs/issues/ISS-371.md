## Description
Record the Bevy-side baseline for `examples/3d/volumetric_fog` before making
any further mgstudio repairs. The current mgstudio audits prove many local
surfaces are Bevy-shaped, but the remaining visual divergence needs a stable
Bevy comparison packet that future diagnostic issues can cite.

## Design
Run the pinned `./bevy` example and capture the same camera frame used by the
mgstudio parity gate. Record the Bevy command, screenshot path, image hash,
pixel summary, and any runtime evidence needed to compare the major scene
contributors. Do not edit assets or mgstudio code in this issue.

## Acceptance Criteria
- [x] A fresh Bevy `volumetric_fog` screenshot path, hash, and command are
      recorded.
- [x] The Bevy capture is compared against the latest mgstudio capture at a
      high level: sky, fog volume, cube visibility, water/reflection area if
      present, and overall brightness.
- [x] Any exact Bevy runtime values collected for later parity checks are
      listed with their source owner.
- [x] No mgstudio production behavior is changed.
