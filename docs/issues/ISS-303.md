## Description
The near gray/white frame dominance could come from rendering a glTF surface
that Bevy would cull, make transparent, depth-sort differently, or assign a
different material/depth-write state.

## Design
Use this issue as the parent for the material/depth investigation. The
executable work is split into smaller source-owner slices:

- ISS-316 audits Bevy glTF material import state for the identified
  contributor.
- ISS-317 audits Bevy PBR material specialization for culling, alpha, and
  depth-write behavior.
- ISS-318 records runtime evidence for the identified contributor's material
  and depth state in mgstudio.

Do not hide the symptom by disabling the contributor or adding a local material
override. The answer must come from Bevy source semantics or a recorded
external blocker.
