## Description
Mgstudio now has the Bevy-shaped `AtmosphereEnvironmentMap` /
`GeneratedEnvironmentMapLight` main-world setup and a renderer-side atmosphere
environment compute pass, but the exact Bevy workload does not produce a
capturable frame in the standard native visual gate. The pass binds the
atmosphere buffers, view and lights buffers, atmosphere LUT textures, sampler,
and an `rgba16float` 2D-array storage view for the generated cubemap, then
dispatches `environment_width / 8`, `environment_height / 8`, and 6 cube faces
like Bevy's `bevy_pbr/src/atmosphere/environment.rs`.

The compute-path failure is not yet proven to be an external dependency
blocker. Current evidence proves that smaller environment dispatches can run,
but the current full example no longer reaches this boundary before the
standard capture gate times out: it is first blocked by ISS-165 while composing
the generic `pbr_opaque_mesh_pipeline` fragment shader.

## Design
Treat this as a diagnosis task, not a workaround task.

- Keep Bevy's source dispatch shape and WGSL source intact while diagnosing.
- Do not replace the pass with smaller dispatches, frame-sliced dispatch,
  precomputed cubemaps, fallback lighting, edited WGSL, or increased visual-gate
  timeouts as the solution.
- Compare the mgstudio owner against Bevy's source owners:
  `bevy/crates/bevy_pbr/src/atmosphere/environment.rs` and
  `bevy/crates/bevy_pbr/src/light_probe/generate.rs`.
- Instrument the boundary enough to distinguish shader composition time,
  pipeline creation, bind-group creation, compute dispatch execution, command
  submission, and first-frame scheduling.
- If the cause is local owner shape, port the missing Bevy owner directly. If
  the cause is a real backend or dependency capability/performance defect,
  record a precise upstream blocker with reproduction and expected behavior.

## Acceptance Criteria
- [ ] The exact standard capture failure is reproducible and documented with
      command, timeout, and run-log behavior.
- [ ] Smaller-dispatch probes are documented only as diagnosis evidence, not as
      an accepted render path.
- [ ] Instrumentation identifies whether time is spent in WGSL composition,
      pipeline creation, bind-group/view creation, compute dispatch execution,
      command submission, or another render schedule boundary.
- [ ] The implementation remains Bevy-shaped: source WGSL unchanged, dispatch
      dimensions unchanged, and no local fallback or approximation path added.
- [ ] `examples/3d/atmosphere` completes the standard 90-frame native capture
      with the real environment cubemap dispatch enabled, or a precise external
      blocker is filed and linked.
- [ ] `moon -C mgstudio-engine check --target native`, `moon -C
      mgstudio-engine fmt`, `moon -C mgstudio-engine info`, and focused
      atmosphere/light-probe tests pass after the final fix.

  It must remain `CAUSE_UNVERIFIED` until instrumentation separates GPU compute
