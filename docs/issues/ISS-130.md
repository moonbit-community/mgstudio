## Description
`mgstudio-engine/examples/3d/spotlight/main.mbt` is not a symbol-level port of
`bevy/examples/3d/spotlight.rs`.

The render-side spot-light path exists and the example preserves many visible
constants: ambient brightness, light intensity, grid dimensions, cone angles,
camera placement, HDR, instruction text, movement keys, and light-sway math.
The strict source gaps are local:

- Bevy's `Movable` marker component is replaced by a global tracked entity
  array;
- Bevy's deterministic `ChaCha8Rng::seed_from_u64(19878367467713)` is replaced
  by a local LCG seeded with a truncated value;
- Bevy's `setup`, `light_sway`, `movement`, and `rotation` system parameters
  are replaced by direct world systems and tracked entity ids;
- Bevy's UI `Text` + absolute `Node` tuple is replaced by a world-space
  `Text2dBundle`;
- Bevy's `rotate_around` camera mutation is approximated by recomputing a
  look-at transform;
- local helper geometry replaces the Bevy primitive-builder owner shape;
- the direction marker writes its `Parent` component twice.

These are local source-parity gaps, not backend blockers.

## Design
Port the example directly from `bevy/examples/3d/spotlight.rs`:

- define and use a real `Movable` component;
- use source-equivalent ChaCha8 deterministic RNG or record a precise RNG API
  blocker if no equivalent exists;
- keep setup data flow through `Commands`, mesh assets, and material assets;
- preserve marker mesh construction from Bevy's `Sphere` primitive builder as
  closely as the primitive API permits;
- spawn marker children once, including `NotShadowCaster` on the direction
  marker;
- preserve UI as `Text` plus absolute `Node` rather than world-space `Text2d`;
- implement `light_sway`, `movement`, and `rotation` with source-shaped query
  ownership;
- use source-equivalent camera `rotate_around` semantics.

If the current ECS cannot express a required system-param or query shape,
record the exact ECS blocker rather than keeping global tracked arrays as the
parity implementation.

## Acceptance Criteria
- [ ] `Movable` is a component and movement uses a `With<Movable>` query.
- [ ] The cube positions are generated from a source-equivalent ChaCha8 seeded
      RNG, or a precise RNG API blocker is recorded.
- [ ] `setup` uses Bevy-shaped commands/assets parameters where possible.
- [ ] Marker meshes preserve `Sphere::new(...).mesh().uv(32, 18)` semantics or
      record a precise primitive-builder blocker.
- [ ] Spot-light child marker entities are parented once and the direction
      marker has `NotShadowCaster`.
- [ ] UI uses source-shaped `Text` and absolute `Node`.
- [ ] `light_sway` mutates `Transform` and `SpotLight` through a query rather
      than tracked entity ids.
- [ ] `movement` mutates movable transforms through a query.
- [ ] `rotation` uses source-equivalent `rotate_around` semantics.
- [ ] `SpotlightState`, tracked arrays, local LCG helpers, duplicate parent
      writes, and direct-world helper paths are removed unless precise blockers
      are recorded.
- [ ] A fresh `examples/3d/spotlight/reference.png` is captured after the
      source-shaped port still renders correctly.
