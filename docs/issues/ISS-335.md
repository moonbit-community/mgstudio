by `fog_volumes` with the expected dimensions, layer/depth count, and texture
format.

## Design

This issue stops at decoded asset data. GPU upload, texture view dimension, and
bind-group readiness are owned by ISS-336.

## Acceptance Criteria

      recorded.
- [ ] Mgstudio resolves the same path without missing-resource output.
- [ ] Focused evidence proves decoded dimensions/depth and texture format.
- [ ] Any missing decoder support is recorded as an external blocker only if it
      cannot be represented locally.
