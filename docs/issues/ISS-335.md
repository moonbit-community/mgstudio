## Description
Prove mgstudio resolves and decodes the exact Bevy density texture asset used
by `fog_volumes` with the expected dimensions, layer/depth count, and texture
format.

## Design
Compare Bevy asset usage with mgstudio's asset loader and KTX2 decode path.
This issue stops at decoded asset data. GPU upload, texture view dimension, and
bind-group readiness are owned by ISS-336.

## Acceptance Criteria
- [x] The Bevy density texture asset path and expected decoded shape are
      recorded.
- [x] Mgstudio resolves the same path without missing-resource output.
- [x] Focused evidence proves decoded dimensions/depth and texture format.
- [x] Any missing decoder support is recorded as an external blocker only if it
      cannot be represented locally.

## Close Notes
Closed 2026-07-06. Bevy source usage:
`bevy/examples/3d/fog_volumes.rs` loads
`asset_server.load("volumes/bunny.ktx2")` for `FogVolume.density_texture`.

Asset identity and decoded shape:
- Bevy asset: `bevy/assets/volumes/bunny.ktx2`.
- Mgstudio asset: `mgstudio-engine/assets/volumes/bunny.ktx2`.
- SHA-256 for both files:
  `64e2b45c6b01fab61c702602a1af01b3a89c260cfe79b269f264ffd505bdb2fd`.
- KTX2 header: `pixelWidth = 64`, `pixelHeight = 64`, `pixelDepth = 64`,
  `layerCount = 0`, `faceCount = 1`, `levelCount = 1`,
  `supercompressionScheme = 0`.
- Vulkan format `100` maps to mgstudio/wgpu `TEXTURE_FORMAT_R32_FLOAT`.
- Decoded level-0 payload length is `1048576` bytes
  (`64 * 64 * 64 * 4`).

Implementation evidence:
`mgstudio-engine/asset/host_io_wbtest.mbt` now contains a focused
`volumes/bunny.ktx2` decode regression test that resolves the mgstudio asset
path, validates the KTX2 header, decodes the 3D payload, and checks dimensions,
depth, format, and payload length.

No missing decoder support or external blocker was found in this issue's
scope. GPU upload, texture view dimension, and bind-group readiness remain
owned by ISS-336.

Verification:
`MOONBIT_NEW_NATIVE=1 moon -C mgstudio-engine test asset/host_io_wbtest.mbt --target native --release --filter '*bunny ktx2*'`.
