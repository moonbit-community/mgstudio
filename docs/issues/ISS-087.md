## Description
`examples/3d/pbr/reference.png` can now serve as a nontransparent visual
baseline, but the capture does not show Bevy's UI labels and cannot be counted
as full example source or visual parity. Bevy's `examples/3d/pbr.rs` spawns UI
`Text` with `Node` positioning for "Perceptual Roughness", "Metallic", and
"Loading Environment Map...", then despawns the environment-map loading label
after both environment textures are loaded.

Mgstudio currently uses `Text2dBundle` screen-like placement instead of the
Bevy UI `Text` + `Node` source shape. The refreshed capture shows the PBR sphere
grid but not the expected Bevy labels, so the example's UI overlay and
environment-map loading-label behavior remain incomplete.

## Design
Audit and port Bevy `examples/3d/pbr.rs` as the source owner:

- preserve the sphere grid, metallic/roughness material values, unlit sphere,
  directional light, orthographic camera, and `EnvironmentMapLight`;
- use Bevy-shaped UI `Text` + `Node` label ownership instead of `Text2d`
  placement for the labels;
- preserve the `EnvironmentMapLabel` component and despawn behavior once both
  environment maps report loaded;
- verify the labels are visible in the standard reference capture.

Do not count a sphere-only capture as complete example parity. If the missing
UI source shape depends on a broader mgstudio UI/text blocker, link that exact
blocker instead of keeping the local Text2d overlay as parity.

## Acceptance Criteria
- [ ] Every source-shape anchor in Bevy `examples/3d/pbr.rs` is classified as
      complete, partial, facade, blocked, or intentionally excluded.
- [ ] The three Bevy UI labels are implemented through Bevy-shaped UI text/node
      owners or a precise UI/text blocker is linked.
- [ ] `EnvironmentMapLabel` is despawned only after both environment map assets
      are loaded.
- [ ] `examples/3d/pbr/reference.png` shows the PBR grid and expected label
      state for the capture frame.
- [ ] The standard native capture command succeeds without validation, fatal,
      or missing-resource output.
