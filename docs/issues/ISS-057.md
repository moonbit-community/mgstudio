## Description
`Milky2018/gamepad@0.4.5` fails to build on the current MoonBit toolchain because it still declares a struct constructor with `fn new(..)` inside the `GamepadId` struct body. Many examples import `Milky2018/mgstudio`, which pulls in the default input/gamepad stack, so stale `reference.png` files cannot be regenerated until this dependency is fixed upstream and published.

## Design
Do not patch `.mooncakes` or add a local compatibility layer. Wait for an upstream `Milky2018/gamepad` release that uses current MoonBit top-level constructor methods, then update `mgstudio-engine/moon.mod` normally.

## Acceptance Criteria
- [ ] A fixed `Milky2018/gamepad` version is available in the MoonBit registry.
- [ ] `mgstudio-engine/moon.mod` uses the fixed version.
- [ ] A package importing the default input stack builds with `moon -C mgstudio-engine build --target native --release`.
