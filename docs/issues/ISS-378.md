`examples/3d/volumetric_fog` directional shadow cascade data and depth texture
inputs consumed by volumetric fog match Bevy's source expressions.

## Design
Use the owner map from ISS-376. Complete the leaf issues in source-owner
order:

- ISS-385 maps the Bevy and mgstudio source anchors for cascade and shadow
  texture data.
- ISS-386 proves the real example cascade count, ordering, and depth texture
  base index.

  cascade records.

This issue should only conclude after the leaves produce enough evidence to
decide whether directional shadow data can explain the visual divergence.
