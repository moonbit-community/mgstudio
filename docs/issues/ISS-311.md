## Description
Record the exact Bevy source anchors that define glTF primitive child creation,
mesh conversion transforms, and primitive AABB insertion for the
`VolumetricFogExample.glb` Cube contributor.

the source-owner facts needed by the mgstudio port: primitive child transform,
mesh asset conversion, `primitive.bounding_box()`, and `Aabb::from_min_max`
insertion behavior.

- 2026-07-05: Bevy source anchors:
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:725-781` builds primitive mesh
    assets, calls `convert_attribute(..., convert_coordinates.rotate_meshes)`,
    and inserts converted vertex attributes into `Mesh`.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:794-806` reads morph targets with
    `PrimitiveMorphAttributesIter { convert_coordinates:
    convert_coordinates.rotate_meshes, ... }`.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:865-880` registers the primitive
    `Mesh` asset and `GltfPrimitive`; the `GltfPrimitive` asset does not carry
    primitive bounds.
  - `bevy/crates/bevy_gltf/src/assets.rs:160-205` defines `GltfPrimitive` with
    index, parent mesh index, computed name, mesh handle, material handle, and
    extras only.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1657-1674` creates the scene
    primitive child entity, reads `primitive.bounding_box()`, obtains
    `mesh_conversion_transform_inverse()`, and spawns `(Mesh3d(handle),
    mesh_entity_transform)`.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:1694-1705` converts the primitive
    bounds when `rotate_meshes` is enabled and inserts
    `Aabb::from_min_max(bounds_min, bounds_max)` on the primitive child entity.
  - `bevy/crates/bevy_gltf/src/convert_coordinates.rs:8-30` defines coordinate
    conversion for `Vec3`, `[f32; 3]`, and `[f32; 4]` as `(-x, y, -z)` with
    tangent/quaternion-compatible handling for four-component values.
  - `bevy/crates/bevy_gltf/src/convert_coordinates.rs:63-121` defines
    `GltfConvertCoordinates`, `rotate_scene_entity`, `rotate_meshes`,
    `mesh_conversion_transform()`, `mesh_conversion_transform_inverse()`, and
    `mesh_conversion_mat4()`.
  - `bevy/crates/bevy_gltf/src/vertex_attributes.rs:278-352` makes coordinate
    conversion apply only to positions, normals, and tangents in
    `convert_attribute`; colors, UVs, joints, weights, and custom attributes do
    not receive glTF coordinate conversion.
  - `bevy/crates/bevy_gltf/src/loader/mod.rs:2032-2080` defines
    `PrimitiveMorphAttributesIter`, which converts morph position, normal, and
    tangent displacements when requested.
  - `bevy/crates/bevy_camera/src/primitives.rs:62-80` defines `Aabb` as
    `center` and `half_extents`; `Aabb::from_min_max` computes both from
    minimum and maximum vectors.
