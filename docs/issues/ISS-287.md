## Description
Bevy's `move_directional_light` system rotates all directional lights in the
`volumetric_fog` example from `W/A/S/D` and arrow-key input using a fixed
per-frame angular delta and `EulerRot::XZY`.

## Design
Port the input checks, sign conventions, fixed speed
`DIRECTIONAL_LIGHT_MOVEMENT_SPEED = 0.02`, early return for zero input, and
quaternion construction directly from Bevy. Do not scale this movement by
frame time unless Bevy does.

## Acceptance Criteria
- [x] `W`/`ArrowUp`, `S`/`ArrowDown`, `A`/`ArrowLeft`, and `D`/`ArrowRight`
      map to Bevy's exact `delta_theta` signs.
- [x] The rotation delta uses `Quat::from_euler(EulerRot::XZY, y, 0.0, x)`.
- [x] The system rotates every directional-light transform selected by the
      Bevy-shaped query.
- [x] A focused test covers the key-to-quaternion mapping.
